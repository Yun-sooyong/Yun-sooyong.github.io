# yun-sooyong.github.io

이 저장소는 GitHub Pages 주소만 유지합니다. 포트폴리오는 아래 주소로 옮겼습니다.

- 포트폴리오: https://programmer-ysy-portfolio.vercel.app ([portfolio-site](https://github.com/Yun-sooyong/portfolio-site))
- 블로그: https://yun-sooyong.github.io/blog/ ([blog](https://github.com/Yun-sooyong/blog))

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 루트 주소로 오면 새 포트폴리오로 보냅니다. |
| `404.html` | 예전 블로그 주소(`/글이름`)로 오면 `/blog/글이름`으로 보냅니다. |
| `.github/workflows/pages.yml` | `main`에 push하면 GitHub Pages로 배포합니다. |
