# ⭐⭐⭐ 클래스(Class) ⭐⭐⭐

## 클래스란?
클래스(Class)는 ==**데이터와 동작을 하나로 묶어 표현하는 사용자 정의 자료형**==
현실 세계의 개념을 프로그램 안에서 표현하기 위한 **설계도(템플릿)**

예를 들어 `학생`, `사람`, `자동차`, `은행 계좌` 현실 세계의 대상을 코드로 표현할 때 클래스를 사용

클래스는 보통 다음 요소들로 구성
- 멤버 변수(속성, 데이터)
- 메서드(동작,기능)
- 생성자(Constructor)

---

## 클래스를 사용하는 이유
- 관련 있는 데이터와 기능을 하나로 묶을 수 있다.
- 코드의 의미를 더 분명하게 표현할 수 있다.
- 재사용성이 높아진다.
- 유지보수가 쉬워진다.
- 객체지향 프로그래밍(OOP)을 구현할 수 있다.

---

# OOP(Object-Oriented Programming)

객체지향 프로그래밍은 **객체를 중심으로 프로그램을 설계하는 방식** 
대표적인 특징
- 추상화
- 캡슐화
- 상속
- 다형성

---

# ⭐ 클래스의 특징

## 1. 추상화(Abstraction)

현실 세계의 복잡한 개념에서 필요한 정보만 뽑아 코드로 표현하는 것

예: `학생`, `자동차`, `사람`, `은행 계좌`

## 2. 캡슐화(Encapsulation)

데이터의 보호를 위해 외부에서의 접근, 수정을 막거나 제한하는 개념 

파이썬은 다른 언어처럼 접근 지정자를 엄격히 강제하지 않지만, 관례적으로 아래처럼 표현
- `public` : 누구나 접근 가능
- `_protected` : 내부용이라는 의미의 관례
- `__private` : 이름 변형(name mangling)으로 직접 접근을 어렵게 만듦

```
class Test:  
    def __init__(self):  
        self.public_var = 10  
        self._protected_var = 20  
        self.__private_var = 30
```

> [!tip] 파이썬의 private, protected 는 완전히 접근을 제한하는게 아니라 ***해당 내용은 내부전용이라는 관례적인 표현***에 가깝다

## 3. 상속성(Inheritance)

기존 클래스의 속성과 메서드를 물려받아 새로운 클래스를 만드는 기능
코드 중복을 줄이고 공통 기능을 재사용할 수 있다.

```python
class Animal:  
    def speak(self):  
        print("소리를 낸다")  
  
class Dog(Animal):  
    pass  
  
dog = Dog()  
dog.speak()
```

## 4. 다형성(Polymorphism)

같은 이름의 기능이 객체에 따라 다르게 동작하는 성질 
대표적으로 **오버라이딩**이 있다.
```python
class Animal:  
    def speak(self):  
        print("동물 소리")  
  
class Dog(Animal):  
    def speak(self):  
        print("멍멍")  
  
class Cat(Animal):  
    def speak(self):  
        print("야옹")
```

# 객체(Object)와 인스턴스(Instance)
클래스로부터 만들어진 실제 대상을 **인스턴스(Instance)**라고 한다.

```python
class Student:  
    pass  
  
s1 = Student()
```
- `Student` → 클래스
- `s1` → `Student` 클래스의 인스턴스(객체)

즉,
- **클래스 = 설계도**
- **인스턴스 = 설계도로부터 실제로 만들어진 것**

### 참고
파이썬에서 클래스도 객체이므로 변수에 저장하거나 리스트에 넣을 수 있다.

```python
class A:  
    pass  
  
lst = [A]  
print(lst)
```

# 클래스와 메모리
클래스를 호출를 인스턴스화 한다고 함
클래스가 인스턴스화 하면 클래스의 **멤버 변수**를 heap 영역에 저장

```python
class Person:  
    def __init__(self, name):  
        self.name = name

p1 = Person("Tom")  
p2 = Person("Jane")
```
- `p1.name` 과 `p2.name` 은 서로 다른 값이다.
- 즉, 인스턴스 변수는 객체마다 따로 존재한다.

---

# 클래스와 리스트의 비교

|항목|리스트|클래스|
|---|---|---|
|데이터 접근|인덱스 (`s[0]`)|이름 (`s.kor`)|
|의미 표현|낮음|높음|
|함수 위치|외부|내부|
|확장성|낮음|높음|
|유지보수|어려움|쉬움|
|코드 가독성|낮음|높음|

### 리스트 사용
```python
student = ["홍길동", 90, 80]  
print(student[0], student[1], student[2])
```

### 클래스 사용
```python
class Student:  
    def __init__(self, name, kor, eng):  
        self.name = name  
        self.kor = kor  
        self.eng = eng  
  
student = Student("홍길동", 90, 80)  
print(student.name, student.kor, student.eng)
```

# self란?

파이썬에서 인스턴스 메서드의 첫 번째 매개변수는 보통 `self`를 사용  
`self`는 **현재 객체 자기 자신**을 의미

```python
class Person:  
    def __init__(self, name):  
        self.name = name  
  
    def introduce(self):  
        print("내 이름은", self.name)
```
여기서 `self.name` 은  
“이 객체의 name” 이라는 뜻이다.

즉, `self`를 통해 현재 인스턴스의 변수와 메서드에 접근할 수 있다.

---

# 클래스의 구성 요소

## 1. 멤버 변수

인스턴스마다 각각 따로 가지는 변수

```python
class Student:  
    def __init__(self, name, kor):  
        self.name = name  
        self.kor = kor
```
- `self.name`
- `self.kor`

## 2. 멤버 함수 (메서드)

클래스 내부에 정의된 함수로, 객체의 동작을 나타낸다.
```python
class Student:  
    def __init__(self, name, kor):  
        self.name = name  
        self.kor = kor  
  
    def show(self):  
        print(self.name, self.kor)
```
`show()` 는 `Student` 객체의 동작이다.

## 3. 생성자(Constructor)

인스턴스가 생성될 때 자동으로 호출되는 특별한 메서드
파이썬에서는 `__init__()` 메서드를 생성자로 사용
```python
class Student:  
    def __init__(self, name, kor):  
        self.name = name  
        self.kor = kor

객체를 만들 때 초기값을 설정하는 역할을 한다.

s1 = Student("홍길동", 95)
```

## 4. 클래스 변수(Class Variable)

클래스 전체가 공유하는 변수
모든 인스턴스가 같은 값을 함께 사용
```python
class Student:  
    school = "Seoul High School"   # 클래스 변수  
  
    def __init__(self, name):  
        self.name = name

s1 = Student("A")  
s2 = Student("B")  
  
print(s1.school)  
print(s2.school)  
print(Student.school)
```

### 클래스 변수의 특징

- 클래스에 소속된 변수
- 모든 인스턴스가 공유
- 인스턴스마다 따로 생성되지 않음
- 공통 데이터 저장에 적합

# 접근 지정자

파이썬은 Java, C++처럼 접근 지정자를 강하게 강제하지 않는다.  
하지만 관례적으로 다음과 같이 구분

## public

기본 형태이며, 어디서든 접근 가능하다.
```python
class A:  
    def __init__(self):  
        self.name = "홍길동"
```

## protected

앞에 밑줄 1개 `_` 를 붙인다.  
“외부에서 직접 건드리지 말고 내부 또는 상속 관계에서 사용하라”는 의미의 관례
```python
class A:  
    def __init__(self):  
        self._age = 20
```

## private

앞에 밑줄 2개 `__` 를 붙인다.  
직접 접근을 어렵게 만들지만, 완전히 막는 것은 아니다.
```python
class A:  
    def __init__(self):  
        self.__pw = "1234"
```

# 위임(Delegation)

위임은 **다른 객체에게 작업을 맡기는 방식**
상속처럼 기능을 물려받는 것이 아니라, 필요한 기능을 가진 객체를 포함하고 그 객체에게 일을 넘긴다.

```python
class Engine:  
    def start(self):  
        print("엔진 시동")  
  
class Car:  
    def __init__(self):  
        self.engine = Engine()  
  
    def start(self):  
        self.engine.start()
```

### 상속 vs 위임

- **상속**: 부모의 기능을 물려받음
- **위임**: 다른 객체에게 일을 맡김

# 오버로딩(Overloading)과 오버라이딩(Overriding)

## 오버로딩(Overloading)

이름은 같지만, **매개변수의 개수나 타입이 다른 메서드를 여러 개 정의하는 것**

**파이썬은 전통적인 의미의 메서드 오버로딩을 직접 지원하지 않는다.**  
같은 이름의 함수를 여러 번 사용 하면 가장 마지막에 만든 함수가 실행됨
```python
class Test:  
    def add(self, a, b):  
        return a + b  
  
    def add(self, a, b, c):  
        return a + b + c
```
위 코드에서는 첫 번째 `add`는 덮어써진다.

따라서 파이썬에서는 보통 **가변 인자**를 활용해 비슷하게 구현한다.

```python
def add(*args):  
    return sum(args)  
  
print(add(1, 2))  
print(add(1, 2, 3, 4))
```
---

## 오버라이딩(Overriding)

부모 클래스의 메서드를 자식 클래스에서 **같은 이름으로  재정의하는 것**
상속 관계에서 사용
```python
class Animal:  
    def speak(self):  
        print("소리를 낸다")  
  
class Dog(Animal):  
    def speak(self):  
        print("멍멍")  
  
dog = Dog()  
dog.speak()
```

### `super()` 사용

부모 클래스의 기능도 함께 사용하고 싶을 때 `super()`를 사용
```python
class Animal:  
    def speak(self):  
        print("동물 소리")  
  
class Dog(Animal):  
    def speak(self):  
        super().speak()  
        print("멍멍")
```
---

## 오버로딩 vs 오버라이딩 비교

|구분|오버라이딩 (Overriding)|오버로딩 (Overloading)|
|---|---|---|
|뜻|부모 메서드를 자식이 재정의|같은 이름의 메서드를 여러 형태로 정의|
|관계|상속 관계|동일 클래스 내|
|목적|부모 기능을 자식에 맞게 변경|인자에 따라 다르게 동작|
|파이썬 지원|지원 O|직접 지원 X|

# 메서드 체이닝(Method Chaining)

**클래스 내부의 메서드에서 `self`를 반환하여 메서드를 연속해서 호출하는 방식**
한 메서드 실행 후 다시 자기 자신 객체를 돌려주기 때문에 다음 메서드를 바로 이어서 호출할 수 있다.

## 예시

```python
class Person:  
    def __init__(self):  
        self._name = ""  
        self._age = 0  
  
    def name(self, name):  
        self._name = name  
        return self  
  
    def age(self, age):  
        self._age = age  
        return self  
  
    def introduce(self):  
        print(f"이름: {self._name}, 나이: {self._age}")  
        return self

person = Person()  
person.name("Tom").age(21).introduce()

```
이 코드는 아래처럼 순서대로 실행하는 것과 비슷하다.

```python
person.name("Tom")  
person.age(21)  
person.introduce()
```

## 장점

- 코드가 간결해진다.
- 설정 작업을 자연스럽게 연결할 수 있다.

## 주의점

- 체이닝을 하려면 메서드가 `return self`를 해야 한다.
- 너무 길게 연결하면 오히려 가독성이 떨어질 수 있다.

# static 함수(정적 메서드)
**클래스나 인스턴스화를 필요로 하지 않는 함수**
- 호출은 클래스 이름으로 호출한다
- 인스턴스를 만들지 않아도 호출 가능
- `self`를 받지 않음
- 클래스 자체와 관련은 있지만, 특정 객체 데이터가 필요 없는 기능에 사용

## 만드는 방법

1. `@staticmethod` 데코레이터를 사용
```python
class Calculator:  
    @staticmethod  
    def add(a, b):  
        return a + b  
  
print(Calculator.add(3, 5))
```

2. staticmethod(func)
```python
class Calculator:
    def add(a, b):
        return a + b

    # 메서드를 정적 메서드로 수동 변환
    add = staticmethod(add)

print(Calculator.add(5, 10))  # 결과: 15
```

## 특징
- `self`를 사용하지 않는다.
- `cls`도 사용하지 않는다.
- 클래스 밖 일반 함수처럼 동작하지만, 의미상 클래스 내부에 넣어 관리할 수 있다.

예:
```python
class Person:  
    @staticmethod  
    def is_adult(age):  
        return age >= 20  
  
print(Person.is_adult(21))
```

### 참고
“정적 메서드는 인스턴스화 전에 사용할 수 있다”는 표현은 맞지만,  
정확히는 **인스턴스 상태가 필요 없기 때문에 클래스 이름으로 바로 호출할 수 있다**고 이해하면 된다.

# class 함수(클래스 메서드)

클래스 메서드(class method)는 **인스턴스가 아니라 클래스 자체를 다루는 메서드**이다.

즉,

- 첫 번째 매개변수로 `self` 대신 `cls`를 받는다.
- `cls`는 현재 클래스를 가리킨다.
- 클래스 변수에 접근하거나, **대체 생성자(alternative constructor)** 를 만들 때 자주 사용된다.

## 만드는 방법

`@classmethod` 데코레이터를 사용한다.

class Person:  
    count = 0  
  
    def __init__(self, name):  
        self.name = name  
        Person.count += 1  
  
    @classmethod  
    def show_count(cls):  
        print("총 인원 수:", cls.count)  
  
Person.show_count()

---

## 클래스 메서드와 `cls`

- `self` → 인스턴스 자신
- `cls` → 클래스 자신

class Test:  
    value = 100  
  
    @classmethod  
    def show(cls):  
        print(cls.value)

---

## 대체 생성자로 사용하는 예시

클래스 메서드는 `cls(...)` 형태로 객체를 생성할 수 있다.  
이때 내부적으로 해당 클래스의 `__init__()` 이 호출된다.

class Person:  
    def __init__(self, name, age):  
        self.name = name  
        self.age = age  
  
    @classmethod  
    def from_string(cls, data):  
        name, age = data.split(",")  
        return cls(name, int(age))

p = Person.from_string("Tom,21")  
print(p.name, p.age)

여기서:

- `cls(name, int(age))`
- 결국 `Person(name, int(age))` 와 비슷하게 동작
- 이 과정에서 `__init__()` 가 실행된다

### 정리

클래스 메서드는 **오버로딩을 대신하기 위한 함수라기보다는**,  
**클래스 수준의 동작을 만들거나 다양한 방식의 객체 생성을 지원하기 위해 사용하는 기능**이라고 이해하는 것이 더 정확하다.

---

# staticmethod 와 classmethod 비교

|구분|staticmethod|classmethod|
|---|---|---|
|첫 번째 인자|없음|`cls`|
|인스턴스 접근|불가|불가|
|클래스 접근|직접 참조 가능|`cls`로 가능|
|주요 용도|보조 함수|클래스 변수 제어, 대체 생성자|

# 함수 없이 데이터만 가진 클래스

클래스는 함수 없이 **데이터만 저장하는 용도**로도 사용할 수 있다.

즉, 메서드 없이 멤버 변수만 두고 자료를 묶어 관리할 수도 있다.

class Student:  
    def __init__(self, name, kor, eng):  
        self.name = name  
        self.kor = kor  
        self.eng = eng

이 클래스는 특별한 메서드 없이도 데이터를 정리하는 데 사용할 수 있다.

s1 = Student("홍길동", 90, 80)  
print(s1.name, s1.kor, s1.eng)

즉, 클래스는

- 동작까지 포함한 객체 설계에도 사용 가능하고
- 단순히 관련 데이터를 묶는 구조로도 사용 가능하다

### 참고

파이썬에서는 이런 목적에 더 간단하게 `dataclass`를 쓰는 경우도 많다.

from dataclasses import dataclass  
  
@dataclass  
class Student:  
    name: str  
    kor: int  
    eng: int

# 수업에 사용된 함수 정리

## `copy()`

얕은 복사(Shallow Copy)를 수행한다.

import copy  
  
a = [1, 2, [3, 4]]  
b = copy.copy(a)

- 바깥 객체는 새로 복사
- 내부 객체는 공유될 수 있음

---

## `deepcopy()`

깊은 복사(Deep Copy)를 수행한다.

import copy  
  
a = [1, 2, [3, 4]]  
b = copy.deepcopy(a)

- 내부 객체까지 모두 새로 복사
- 원본과 완전히 독립적

---

## `copy()` 와 `deepcopy()` 비교

|구분|`copy()`|`deepcopy()`|
|---|---|---|
|복사 방식|얕은 복사|깊은 복사|
|내부 객체|공유 가능|새로 복사|
|원본 영향|받을 수 있음|없음|

---

## `time()`

현재 시간을 **초 단위 숫자(float)** 로 반환한다.

import time  
  
print(time.time())

주로 실행 시간 측정에 사용한다.

---

## `ctime()`

시간을 사람이 읽기 쉬운 문자열 형태로 반환한다.

import time  
  
print(time.ctime())

---

## `shuffle()`

리스트 요소의 순서를 무작위로 섞는다.

import random  
  
arr = [1, 2, 3, 4, 5]  
random.shuffle(arr)  
print(arr)

### 주의

`shuffle()` 은 새 리스트를 반환하지 않고 **원본 리스트를 직접 바꾼다.**

# 생성자에 대한 쉬운 비유

클래스를 **면허증 양식**이라고 생각하면 이해하기 쉽다.

- **클래스** = 면허증 서식
- **인스턴스** = 실제 발급된 면허증
- **멤버 변수** = 이름, 주소, 성별, 고유번호
- **클래스 변수** = 발급 기관처럼 모두가 공유하는 정보
- **메서드** = 면허 확인, 정보 출력 같은 동작

즉,

- 클래스는 틀
- 인스턴스는 그 틀로 만들어진 실제 결과물
