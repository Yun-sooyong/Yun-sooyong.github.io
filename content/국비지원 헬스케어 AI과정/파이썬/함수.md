# 함수

## 함수란?
함수(function)란, **반복적으로 재사용되는 기능을 하나로 묶어 입력을 받고 결과를 반환하는 구조**
즉, 자주 사용하는 코드를 매번 다시 작성하지 않고, 필요한 순간에 호출해서 사용할 수 있도록 만든 코드의 묶음

---

## 함수를 사용하는 이유
- 반복되는 코드를 줄여서 **불필요한 낭비를 줄일 수 있다**
- 기능 단위로 프로그램을 작성할 수 있어 **흐름 파악이 쉬워진다**
- 코드 수정이 필요한 경우 함수만 고치면 되므로 **유지보수가 쉬워진다**
- 같은 기능을 여러 곳에서 재사용할 수 있어 **생산성이 높아진다**

---

## 메모리 구조

> [!tip] 메모리 구조
> - **HEAP** : 동적 메모리 영역 (객체가 저장됨)
> - **STACK** : 함수 호출 정보, 지역 변수 등이 저장됨
> - **Static / Global** : 전역 변수, 정적 데이터 영역
> - **CODE** : 실행할 코드가 저장되는 영역

---

## 함수의 기본 구조

```python
def 함수이름(매개변수):  
    함수부  
    return 반환값
```

### 예제

```python
def factorial(n):  
    result = 1  
    for i in range(n, 1, -1):  
        result *= i  
    return result
```

---

## 함수의 특징
1. 값을 반환할 수 있다
	+ 함수는 실행 결과를 `return`으로 돌려줄 수 있다.
2. 여러 값을 동시에 반환할 수 있다
	+ 파이썬에서는 여러 값을 한 번에 반환할 수 있으며,  **tuple 형태로 묶여서 반환** 됨
```python
def calc(a, b):  
    return a + b, a - b  
  
result = calc(10, 3)  
print(result)   # (13, 7)
```

3. 함수를 변수처럼 다룰 수 있다
	+ 파이썬에서 함수는 **일급 객체(first-class object)** 이므로 변수에 저장하거나, 다른 함수의 인자로 넘기거나, 리스트에 담을 수 있다.
```python
def add(x, y):  
    return x + y  
  
def sub(x, y):  
    return x - y  
  
func_list = [add, sub]  
print(func_list[0](10, 5))  # 15  
print(func_list[1](10, 5))  # 5
```
4. `lambda` 함수도 리스트에 넣을 수 있다
```python
func_list = [  
    lambda x: x + 1,  
    lambda x: x * 2,  
    lambda x: x ** 2  
]  
  
print(func_list)  # 4  
print(func_list)  # 6  
print(func_list)  # 9
```

# 매개변수(Parameter)
함수에서 입력값을 받기 위해 사용하는 변수를 **매개변수**라고 한다.

## 1. 필수 매개변수 (required parameter)
- 반드시 전달해야 하는 매개변수이다.
```python
def greet(name):  
    print(f"안녕하세요, {name}님")
```

## 2. 기본값 매개변수 (default parameter)
- 값을 전달하지 않으면 미리 정해둔 기본값이 사용된다.
```python
def greet(name="손님"):  
    print(f"안녕하세요, {name}님")
```

## 3. 키워드 매개변수 (keyword argument)
- 매개변수 이름을 직접 지정하여 값을 전달하는 방식이다.  
- 순서와 상관없이 입력할 수 있다.
```python
def introduce(name, age):  
    print(name, age)  
  
introduce(age=20, name="Tom")
```
## 4. 가변 매개변수 (variable length arguments)
- 입력 개수가 고정되지 않을 때 사용한다.
	+ `*args` : 여러 인자를 **tuple**로 받음
	+ `**kwargs` : 여러 키워드 인자를 **dict**로 받음
```python
def func(*args, **kwargs):  
    print(args)  
    print(kwargs)  
  
func(1, 2, 3, name="Alice", age=20)

출력:

(1, 2, 3)  
{'name': 'Alice', 'age': 20}
```

# 지역 변수 / 전역 변수

## 지역 변수 (local variable)
함수 내부에서 생성되는 변수
함수가 종료되면 일반적으로 더 이상 접근할 수 없다.
```python
def test():  
    x = 10  # 지역 변수
```

## 전역 변수 (global variable)
함수 외부에서 생성되어 프로그램 전체에서 접근 가능한 변수
```python
x = 100  # 전역 변수
```

## 이름이 같을 때 우선순위
같은 이름의 변수가 여러 범위에 존재하면, 일반적으로 더 가까운 범위의 변수가 우선
파이썬의 이름 탐색 순서는 보통 **LEGB 규칙**으로 설명한다.
- **L**ocal : 지역 영역
- **E**nclosing : 바깥 함수 영역
- **G**lobal : 전역 영역
- **B**uilt-in : 내장 영역

**지역 변수 > 바깥 함수 변수(클로저) > 전역 변수 > 내장 함수**

> [!tip] 전역 변수 사용  
> 함수 내부에서 전역 변수의 값을 변경하려면 `global` 키워드가 필요하다.
```python
count = 0  
  
def increase():  
    global count  
    count += 1
```

# 내부 함수
함수 내부에 또 다른 함수를 정의할 수 있다. 
이를 **내부 함수(inner function)** 또는 **중첩 함수(nested function)** 라고 한다
내부 함수는 보통 **외부 함수 내부에서만 호출 가능**하다.

```python
def outer():  
    def inner():  
        print("내부 함수 실행")  
    inner()  
  
outer()
```

# 클로저 (Closure)

클로저란, ==**함수 안에 함수를 정의할 때 내부 함수가 외부 함수의 변수를 기억하고 있다가 나중에도 그 변수를 사용하는 구조**==를 말한다.
내부 함수가 자신이 만들어질 당시의 환경(Context)을 캡슐화 

```python
def outer_func(x):  
    def inner_func(y):  
        return x + y  
    return inner_func  
    
add_ten = outer_func(10)  
  
print(add_ten(5))   # 15  
print(add_ten(20))  # 30
```

## 클로저 성립 조건
1. **중첩 함수**일 것 
2. 내부 함수가 외부 함수의 **지역 변수를 참조**해야 한다
3. 외부 함수가 내부 함수 **자체를 반환**해야 한다

# 재귀 함수
재귀 함수(recursive function)란 ==**자기 자신을 다시 호출하는 함수**==
단, 반드시 **종료 조건(base case)** 이 있어야 함
종료 조건이 없으면 무한 루프가 발생한다.

## 재귀 함수의 기본 구조
```python
def func(매개변수):  
    if 종료조건:  
        return 결과  
    return func(더 작은 문제)
```

## 예제 : 팩토리얼
```python
def factorial(n):  
    if n == 1:  
        return 1  
    return n * factorial(n - 1)  
  
print(factorial(5))  # 120
```

# Overriding / Overloading

## 오버라이딩 (Overriding)

**부모 클래스의 메서드를 자식 클래스에서 같은 이름으로 ==재정의==하는 것**
- 상속 관계에서 사용
- 부모의 기능을 자식에게 맞게 변경하거나 확장할 때 사용
- `super()`를 사용해 부모 메서드를 함께 호출할 수 있다

```python
class Animal:  
    def speak(self):  
        print("소리를 낸다")  
  
class Dog(Animal):  
    def speak(self):  
        print("멍멍")  
  
dog = Dog()  
dog.speak()  # 멍멍
```

## 오버로딩 (Overloading)
**이름은 같지만 매개변수의 타입이나 개수가 다른 메서드를 여러 개 정의하는 것**
- **파이썬은 전통적인 의미의 오버로딩을 직접 지원하지 않음**
- 같은 이름으로 함수를 여러 번 정의하면 **가장 마지막 정의만 남는다**
- 대신 기본값, 가변인자(`*args`, `**kwargs`) 등을 이용해 비슷하게 구현할 수 있다
```python
def add(*args):  
    return sum(args)  
  
print(add(1, 2))        # 3  
print(add(1, 2, 3, 4))  # 10
```

## 오버라이딩과 오버로딩 비교표
|구분|오버라이딩 (Overriding)|오버로딩 (Overloading)|
|---|---|---|
|뜻|부모의 메서드를 자식이 재정의|같은 이름의 메서드를 중복 정의|
|관계|상속 관계 (부모 ↔ 자식)|동일 클래스/동일 영역 내|
|목적|부모 기능을 상황에 맞게 변경|인자에 따라 다르게 동작|
|파이썬 지원|지원함|직접 지원하지 않음|

# Call by Reference / Call by Value

파이썬은 **객체 참조에 의한 전달(Call by Object Reference)** 또는
 **Pass by Assignment** 라고 설명하는 것이 가장 정확
즉, **객체에 대한 참조가 전달된다**고 이해하면 된다.

## 핵심 정리
- 함수에 전달되는 것은 **객체 자체가 아니라 객체를 가리키는 참조**
- **mutable(변경가능한 객체)** 
	- 함수 내부 수정이 원본에 영향을 줄 수 있다
- **immutable(변경불가능한 객체)**  
	- 수정이 불가능하므로 새로운 객체가 만들어진다

---

## 1. 변경 가능한 객체 (mutable)

예: `list`, `dict`, `set`

```python
def modify(lst):  
    lst.append(100)  
  
data = [1, 2, 3]  
modify(data)  
print(data)  # [1, 2, 3, 100]
```
함수 안에서 같은 객체를 직접 수정했기 때문에 원본도 바뀐다.

---

## 2. 변경 불가능한 객체 (immutable)

예: `int`, `float`, `str`, `tuple`

```python
def modify(x):  
    x += 10  
    print("함수 내부:", x)  
  
num = 5  
modify(num)  
print("함수 외부:", num)

출력:

함수 내부: 15  
함수 외부: 5

```
`x += 10`은 원래 객체를 바꾸는 것이 아니라 **새 객체를 만들어 재할당**하는 것이므로, 바깥 변수에는 영향이 없다.

> [!tip] 중요  
> 함수 내부에서 매개변수에 **새로운 값을 대입**하면, 바깥 변수를 직접 바꾸는 것이 아니라 지역 이름이 새로운 객체를 가리키게 되는 것**이다.

---

## 비교표

|구분|Call by Value|Call by Reference|
|---|---|---|
|전달 방식|값의 복사본 전달|참조(주소) 전달|
|원본 영향|없음|있음|
|파이썬과의 관계|정확히 일치하지 않음|정확히 일치하지 않음|

# 커링 (Currying)
커링이란, **여러 개의 인자를 받는 함수를 단일 인자를 받는 함수들의 연속으로 바꾸는 기법**이다.
파이썬에서는 순수한 커링보다는 **부분 적용(partial application)** 을 위해 `functools.partial`을 더 자주 사용

## 예제: 클로저를 이용한 커링 형태
```python
def curried_multiply(x):  
    def inner(y):  
        return x * y  
    return inner  
  
double = curried_multiply(2)  
print(double(5))  # 10
```

## 사용 목적
- 함수의 재사용성 향상
- 지연 실행
- 가독성과 유지보수 향상

# 검색(Search)

## 1. 순차 검색 (Linear Search)
앞에서부터 하나씩 비교하며 찾는 방식

특징
- 구현이 단순함
- 데이터가 정렬되어 있지 않아도 사용 가능
- 데이터가 많으면 느릴 수 있음
```python
def linear_search(arr, target):  
    for i, value in enumerate(arr):  
        if value == target:  
            return i  
    return -1
```

## 2. 이진 검색 (Binary Search)
정렬된 데이터에서 가운데 값을 기준으로 탐색 범위를 반씩 줄여가며 찾는 방식이다.

특징
- 반드시 **정렬된 상태**에서 실행되야 함 
- 순차 검색보다 빠름
```python
def binary_search(arr, target):  
    left, right = 0, len(arr) - 1  
  
    while left <= right:  
        mid = (left + right) // 2  
  
        if arr[mid] == target:  
            return mid  
        elif arr[mid] < target:  
            left = mid + 1  
        else:  
            right = mid - 1  
  
    return -1
```

### `bisect` 모듈
파이썬에서는 `bisect` 모듈을 사용하면 이진 탐색을 쉽게 할 수 있다.
```python
import bisect  
  
arr = [1, 3, 5, 7, 9]  
idx = bisect.bisect_left(arr, 5)  
print(idx)  # 2
```
