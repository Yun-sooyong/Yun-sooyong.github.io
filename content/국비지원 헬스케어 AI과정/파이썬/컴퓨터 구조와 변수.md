# 컴퓨터 구조 

## 컴퓨터의 기본 구조 
- 입력장치
	+ 마우스, 키보드, 마이크 등 사용자의 입력을 받는 장치
- 출력장치 
	+ 스피커, 모니터 등 결과를 보여주는 장치
- 기억장치 
	+ 메모리나 보조 저장장치에 데이터가 저장
- 연산장치 
	+ CPU가 데이터를 계산하고 처리
- 제어장치
	+ 명령어의 실행순서를 관리

## 컴퓨터 기본 동작 흐름 
	컴퓨터는 사용자의 입력을 받아 컴퓨터가 이해할 수 있는 언어로 변환한 뒤 연산을 처리하고, 
	다시 사람이 이해할 수 있는 언어로 변환해서 출력한다 
- 입력도구 => encoding => 연산/제어/기억 => decoding => 출력도구

	- Encoding
		- encoding : 사용자가 입력한 내용을 컴퓨터가 이해할 수 있게 변환(mapping)하는 과정
			ex> 입력한 문자를 아스키 코드나 유니코드로 변환
	- Decoding
		- decoding : 컴퓨터가 처리한 내용을 사용자가 이해할 수 있게 변환(mapping)하는 과정
			 ex> 그래픽 데이터를 모니터에 표시, 소리 데이터를 스피커로 출력 

## 컴퓨터의 동작 단위

- 컴퓨터는 작은 여러 명령어 단위로 나뉘어서 실행됨
- 이런 작은 명령어를 모아 함수(Function)단위로 묶어 사용

# 메모리 구조 
메모리는 크게 Heap과 Stack 영역으로 나눌 수 있다

## Stack 
	stack에는 주로 함수 호출, 변수 등 관련된 정보가 저장되는 메모리 영역

### Stack 에 저장되는 내용 
- 함수의 매개변수
- 지역 변수
- 반환 주소 
- 함수 실행에 필요한 임시 데이터

### 특징
- 후입선출(LIFO) 구조 
- 함수가 호출되는 순서대로 stack에 쌓이고, 종료되면 stack에서 제거됨
- 함수 호출 정보를 관리

## Heap
	프로그램 실행 중 필요한 데이터를 동적으로 할당하는 메모리 영역

### Heap에 저장되는 내용
- 동적으로 생산된 객체 
- 가변 크기를 가지는 데이터
- 실행 중 생성되는 자료구조

### 특징 
- 런타임(runtime)에 필요한 만큼의 메모리를 동적으로 할당 
- 크기가 런타임에서 정해지는 동적 데이터를 저장하는데 적합
- 사용 후 메모리에서 사라지는 휘발성을 가짐 

## Heap과 Stack 비교 
| 구분 | Stack | Heap |  
|------|-------|------|  
| 사용 목적 | 함수 호출 정보, 지역 변수 저장 | 동적 데이터 저장 |  
| 할당 방식 | 자동 할당 / 자동 해제 | 수동 할당 또는 자동 관리(GC) |  
| 데이터 관리 | 호출 순서에 따라 관리 | 필요 시점에 생성 / 해제 |  
| 구조 | 후입선출(LIFO) | 순차 구조 아님 |  
| 속도 | 비교적 빠름 | stack보다 상대적으로 느릴 수 있음 |  
| 사용 예 | 함수 실행 정보, 지역 변수 | 객체, 동적 배열, 큰 데이터 |

# 파이썬 
	파이썬은 동적 타입의 언어로 변수에 직접 타입을 명시하지 않고 
	대입된 값에 따라 타입이 정해진다 
```python 
a = 10      # int 타입
a = "hello" # str 타입
```

## 참조(Reference)와 변수 
파이썬의 변수는 값을 직접 담는 상자보다는 객체를 보는 이름에 더 가까움 

### 참조(Reference)
어떤 데이터를 직접 저장하는게 아니라, 해당 객체(데이터)를 ==가리키는 것==

### 변수 
파이썬의 변수는 객체를 참조함
- 다른 언어와 다르게 변수에 직접 값을 저장하지 않음
- 변수 안에 값이 저장된 주소를 가리키는 포인터 방식에 가까움 
- 참조되지 않는 객체는 '가비지 컬렉터'가 메모리에서 정리


```python 
a = 10 
b = a 
a = 20 

print(a)
print(b)
```

```python
20
10
# a != b
```
즉, 파이썬의 변수는 값이 변하는게 아니라 참조하는 대상이 바뀌는 방식 

## 가비지 컬렉션(Garbage Collection)
더 이상 참조되지 않는 객체를 찾아 메모리에서 제거하는 메모리 관리 기법

## 파이썬 자료형

### int 
정수형(Inteager) 데이터 타입 
```python
a = 10
```

### float 
실수형(Float) 데이터 타입 
```python
a = 10.0
```
> [!tip] float 타입의 오차 
> float 타입은 실수를 부동소수점 으로 변환해 데이터를 저장하는 과정에서 발생하는 정밀도 문제
> 의료, 금융, 과학 분야에서는 주의 해야함 
> 파이썬에서는 decimal 을 사용해 해결할 수 있음 

```python
print(0.1 + 0.2)

# 출력
0.30000000000000004
```

### decimal 
정확한 소수점 단위의 계산이 필요할 때 사용되는 타입
```python
from decimal import Decimal 

a = Decimal("0.1")
b = Decimal("0.2")
print(a + b)

# 출력
0.3
```

decimal 특징
- 정확한 소수 계산이 가능 
- 문자열 형태로 값을 넣어야함 
- 연산속도가 느리고 메모리 사용량도 큼 
- 금융, 회계, 과학 등 오차를 허용하지 않는 분야에서 사용

### str 
문자열(String) 자료형 
따옴표로 둘러싸인 문자 집합
```python
a = 'Hello World'
```
특징 
- 불변성(Immutable) : 생성 후에는 변경 할 수 없음 
	- 문자열 연산을 하면 연산 후 결과값을 새로운 문자열로 만들어 참조하는 방식
- 시퀀스 자료형(Sequence Type) : 순서가 있는 자료형으로 인덱싱과 슬라이스를 사용가능
- '', "", """ """ 사용 가능 
- 문자열 끼리 연산이 가능 


### bool 
오직 True(참)과 False(거짓) 두 값을 가지는 자료형 
```python
a = True 
b = False 
```

### List
파이썬의 기본 자료구조 
```python
ls = [1, 2, 3, 4]
ls1 = [1, 2, '가', True]
```

list 특징 
- 순서가 있는 자료구조 
- 가변성(Mutable)
- 동적 배열 (Dynamic Array)
- 다양한 자료형을 혼합해서 저장 가능 
- 인덱스를 사용해 값에 접근하며, 슬라이싱을 지원 
- \[](대괄호)로 생성

|구분|list|array|
|---|---|---|
|자료형|다양한 타입 사용가능|단일 자료형|
|가변성|크기 조절 가능|고정된 크기|
|속도|비교적 느림(참조형)|빠름(메모리연속)|

### Tuple
```python
tp = (1, 2, 3)
# 튜플도 list와 같이 다양한 자료형을 담을 수 있음 
```
- list 와는 비슷하지만 조금 다른 자료구조 
- 불변성을 가져 저장된 값이 변경되면 안되는 고정된 데이터(예: 좌표)에서 주로 사용
- 함수에서 여러 값을 동시에 반환하면 튜플처럼 묶여 return 한다 

| 차이점   | list          | tuple           |
| ------ | ------------- | --------------- |
| 가변성 | 가변(mutable) | 불변(immutable) |
| 표현식 | 대괄호 []     | 소괄호 ()       | 

### Dict (Dictionary)
- 중괄호 {} 를 사용해 생성하는 변경가능한 자료형
- key:value 쌍을 저장하는 hash 테이블 기반의 자료형 
- key는 불변성과 고유성을 가진다 (불변성을 가지는 자료형만 key에 사용가능, 중복 허용안함)
- value는 중복이 가능하고 list같은 자료형 데이터도 저장할 수 있다 
- key값을 사용해 데이터를 찾기 때문에 속도가 가장 빠르다 (O(1))


### Set
- 중복을 허용하지 않음
- 순서가 없음(unordered)
- 가변성을 가짐(mutable)
- 집합연산에 최적화 
- 불변성을 가지는 자료형을 값으로 받음 


## 오늘 수업에서 사용한 함수 

### id()
- 변수에 있는 값의 주소를 확인 할 때 사용
- 객체의 식별값 확인
 
### type()
- 변수에 값의 타입을 확인 할 때 사용
- 객체의 타입을 확인
 
### eval()
- 문자열을 입력받은 명령어나 수식을 인식해 실행하는 함수 
- 입력받은 문자열을 그대로 실행하기 때문에 원하지 않은 동작이 발생할 가능성이 높아 보안상 좋지 않음

###  format()
- 문자열 포맷팅 함수 
- format을 사용하면 문자열에 변수의 값을 넣을 수 있게 된다 
- 최근에는 f-string을 많이 사용

### split()
- 문자열에서 입력받은 문자를 기준으로 나누고 list로 만들어 반환
- csv 문자열 처리, 입력 문자열 분리 등에 사용

### join()
- list, tuple을 하나의 문자열로 만드는 함수   
- ‘구분자’.join(list) 를 사용해서 구분자를 list 사이에 넣어 하나의 문자열로 만듦
