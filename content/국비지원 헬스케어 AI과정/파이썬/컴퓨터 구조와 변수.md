# 컴퓨터 구조 

## 컴퓨터의 기본 구조 
- 입력장치
	+ 마우스, 키보드, 마이크 등 사용자의 입력을 받는 장치
- 출력장치 
	+ 스피커, 모니터 등 결과를 보여주는 장치
- 기억장치 
	+ 메모리나 보조 저장장치에 데이터가 저장
- 연산장치 
	+ CPU가 데이터를 계산하고 처리
- 제어장치
	+ 명령어의 실행순서를 관리

## 컴퓨터 기본 동작 흐름 
	컴퓨터는 사용자의 입력을 받아 컴퓨터가 이해할 수 있는 언어로 변환한 뒤 연산을 처리하고, 다시 사람이 이해할 수 있는 언어로 변환해서 출력한다 
- 입력도구 => encoding => 연산/제어/기억 => decoding => 출력도구

	Encoding / Decoding
		- encoding : 사용자가 입력한 내용을 컴퓨터가 이해할 수 있게 변환(mapping)하는 과정
			- ex> 입력한 문자를 아스키 코드나 유니코드로 변환
		- decoding : 컴퓨터가 처리한 내용을 사용자가 이해할 수 있게 변환(mapping)하는 과정
			- ex> 그래픽 데이터를 모니터에 표시, 소리 데이터를 스피커로 출력
