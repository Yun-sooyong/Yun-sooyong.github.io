# 제어문
프로그램의 **실행순서와 흐름을 조절하는 문장**

제어문의 종류
- 조건문 : 조건에 따라 실행할 코드 블록을 선택
	+ `if`, `elif`, `else`
- 반복문 : 조건이 만족될 때까지 코드 블록을 반복 실행
	+ `for`, `while`
- 반복 제어문 : 반복문의 흐름을 강제로 바꾸거나 조절
	+ `break`, `continue`, `pass`
- 예외 처리문 : 프로그램 실행 도중 발생하는 문제(Exception)를 처리
	+ `try`, `except`, `finally`, `else`
---
## 조건문 
조건에 따라 실행할 코드 블록을 선택

- 기본 구조
```python
if [조건식] :
	[실행문]
elif [조건식2] :
	[실행문2]
else :
	[실행문3]
```

- 종류 
	- `if` :  조건이 True 일 때 내부 코드를 실행 
	- `elif` : if의 조건이 False 일 때 새로운 조건식을 확인
	- `else` : 앞의 모든 조건이 False 일 때 실행 

### 조건식 
결과가 항상 `True(참)`또는 `False(거짓)`으로 나오는 식

1. 존재론적 조건
	- False : `None`, `0`, `""`, `[]`, `()`, `{}`, `set()` (텅 빈 상태)
	- True : 값이 하나라도 들어있는 모든 상태
2. 포함 관계 조건
	 - 특정 데이터의 존재 여부 : `in`, `not in` 
3. 상등성, 동일성 조건
	- 값 비교 : `==`
	- 참조 비교 : `is`
	- None 비교 : `is`
4. 복합 논리 조건 
	-  **`and`**: 모든 조건이 True 면 통과
	- **`or`**: 하나라도 Ture면 통과
	- **`not`**: 조건의 답을 거꾸로 뒤집음

### 삼항 연산자 
피연산자가 3개인 연산자(조건 표현식)
`[참일 때의 값] if [조건] else [거짓일 때의 값]`
- 예시
```python
result = '짝수' if x % 2 == 0 else '홀수'
```

### match ~ case 
값이나 패턴의 일치를 확인하는 문법
python 3.1 이상에서 사용가능 

- 기본 구조
```python
match 변수:  
	case 값1:  
		실행문  
	case 값2:  
		실행문  
	case _:  
		실행문
```
- 예시
```python
command = "save"  
  
match command:  
	case "add":  
		print("추가")  
	case "save":  
		print("저장")  
	case "delete":  
		print("삭제")  
	case _:  
		print("알 수 없는 명령")
```

## 반복문 
같은 코드 블록을 여러번 반복해서 실행

- 반복문의 종류 
	- `for`
	- `while`

### for 문
순회 가능한 객체(Iterable)를 하나씩 꺼내면서 반복

- 기본 구조
```python
for 변수 in 반복가능객체:  
	실행문
```

- 예제 
```python
for i in [1, 2, 3]:  
	print(i)
```


### while 문 
조건이 True(참)인 동안 반복

- 기본 구조
```python
while 조건문:
    실행문
```

- 예제
```python
i = 0  
  
while i < 5:  
    print(i)  
    i += 1
```
