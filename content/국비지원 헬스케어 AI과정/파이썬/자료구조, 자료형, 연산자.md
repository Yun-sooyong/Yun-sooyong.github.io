# 자료 구조 (Data Structure)
문자열, 리스트, 튜플, 딕셔너리, 집합 등을 자주 사용한다 

## 자료 구조 분류

1.  순서가 있는(ordered)  자료구조 
	- list 
	- str
	- tuple
	- dict(삽입 순서를 유지)

2. 순서가 없는(unordered) 자료구조 
	- set

3.  수정 가능한(mutable) 자료구조
	- list 
	- set 
	- dict

4.  수정 불가능한(immutable) 자료구조
	- tuple
	- str

## 순서가 있는 자료 구조의 표준 연산
- indexing
인덱스를 이용해 특정 위치 값에 접근
```python
list = [1,2,3]
list[0] # 1
```
- slicing
일부 구간만 잘라 접근
```python
list = [1,2,3]
list[0:2] # 1,2
list[-1]  # 3, 가장 마지막을 반환
list[start:end:step]
```
- concatenation : 
두 자료구조를 이어 붙여 새로운 순서를 만듦
```python
[1,2] + [3,4]
# = [1,2,3,4]
```
- repetition 
동일한 데이터를 지정 횟수 만큼 반복
```python
[0]*3 # [0,0,0]
```
- membership test : 
in, not in 연산자로 포함, 비포함 여부 확인
	+ 비순서형 자료구조도 membership test가 있고 오히려 비순서형이 더 빠름 
	+ 비순서 자료구조의 특징 중 하나 
```python
3 in [1,2,3] # True
```

## String
- 문자열을 저장하는 자료형
- 수정 불가능(immutable)
	+ 문자열은 수정 불가능 하기 때문에 변경이 필요하면 새로운 객체를 만들어 진다
- 순서가 있는 자료형 (sequence)
	+ 인덱싱, 슬라이싱, 반복 가능
- +/* 연산자 사용 가능
	+ + : 문자열 이어 붙이기 
	+ \* : 문자열 반복 

## ⭐ List ⭐ 
- ==파이썬의 대표적인 자료구조==
- 수정 가능(mutable)
- 순서가 있음 
	- 인덱싱, 슬라이싱 가능 
- 크기 변경가능
- 요소 추가 삭제 가능 
- 여러 타입의 값을 함께 저장가능 
- ==객체를 참조하는 정보를 순서대로 담은 기능==

List 와 Array 차이점 

|    비교    | Array                          | List                             |
| --------- | ------------------------------ | -------------------------------- |
| 타입      | 단일 타입 저장                 | 여러 타입 같이 저장              |
| 크기      | 고정 크기                      | 가변 크기                        |
| 저장 방식 | 연속된 메모리 공간에 직접 저장 | 객체에 대한 참조를 순서대로 저장 |
| 속도      | 빠름                           | 비교적 느림                      |
| 장단점    | 삽입, 삭제 비효율적            | 사용편리, 확장성 좋음            |
