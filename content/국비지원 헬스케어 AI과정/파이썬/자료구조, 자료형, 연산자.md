# 자료 구조 (Data Structure)
문자열, 리스트, 튜플, 딕셔너리, 집합 등을 자주 사용한다 

## 자료 구조 분류

1.  순서가 있는(sequence)  자료구조 
	- list 
	- str
	- tuple
	- dict(삽입 순서를 유지)

2. 순서가 없는(unordered) 자료구조 
	- set

3.  수정 가능한(mutable) 자료구조
	- list 
	- set 
	- dict

4.  수정 불가능한(immutable) 자료구조
	- tuple
	- str
---
## 순서가 있는 자료 구조의 표준 연산

- indexing
인덱스를 이용해 특정 위치 값에 접근
```python
list = [1,2,3]
list[0] # 1
```

- slicing
일부 구간만 잘라 접근
```python
list = [1,2,3]
list[0:2] # 1,2
list[-1]  # 3, 가장 마지막을 반환
list[start:end:step]
```

- concatenation
두 자료구조를 이어 붙여 새로운 순서를 만듦
```python
[1,2] + [3,4]
# = [1,2,3,4]
```

- repetition 
동일한 데이터를 지정 횟수 만큼 반복
```python
[0]*3 # [0,0,0]
```

- membership test
in, not in 연산자로 포함, 비포함 여부 확인
	+ 비순서형 자료구조도 membership test가 있고 오히려 비순서형이 더 빠름 
	+ 비순서 자료구조의 특징 중 하나 
```python
3 in [1,2,3] # True
```

- len()
길이를 반환, 내장 함수
```python
list = [1,2,3]
len(list) # 3
```

- enumerate()
순서가 있는 객체의 인덱스와 데이터를 동시에 꺼내오기 위해 사용
```python
fruits = ['apple', 'banana', 'cherry']

for index, value in enumerate(fruits):
    print(f"{index}번 과일: {value}")
	# 1번 과일 : 'apple'
	# 2번 과일 : 'banana'
	# 3번 과일 : 'cherry'
```

- sort()
데이터를 기준에 따라 순서대로 정렬하는 기능 
순서형 자료 구조 중 변경가능한 자료구조에서만 사용됨 
tuple / str은 변경이 불가능한 자료구조이기 때문에 정렬된 새로운 리스트를 만들어서 반환
```python
list = [1,4,2,3,6,5]
list.sort() # 리스트 자체를 정렬
list.sort(reverse = True) # 내림차순 정렬
list.sort()
sorted(list) # 원본과 별개로 정렬된 새 객체를 반환

rows = [[1, 10], [2, 30], [3, 20]]  
rows.sort(key=lambda row: row[1], reverse=True)
# [[2, 30], [3, 20], [1, 10]]
# 기준점을 lambda식으로 정해줄 수 있음 
```

## String
- 문자열을 저장하는 자료형
- 수정 불가능(immutable)
	+ 문자열은 수정 불가능 하기 때문에 변경이 필요하면 새로운 객체를 만들어 진다
- 순서가 있는 자료형 (sequence)
	+ 인덱싱, 슬라이싱, 반복 가능
- \+ / * 연산자 사용 가능
	+ \+ : 문자열 이어 붙이기 
	+ \* : 문자열 반복 

## ⭐ List ⭐ 
- ==파이썬의 대표적인 자료구조==
- 수정 가능(mutable)
- 순서가 있음 (sequence)
- 크기 변경가능
- 요소 추가 삭제 가능 
- 여러 타입의 값을 함께 저장가능 
- ==객체를 참조하는 정보를 순서대로 담은 기능==

List 와 Array 차이점 

|    비교    | Array                          | List                             |
| --------- | ------------------------------ | -------------------------------- |
| 타입      | 단일 타입 저장                 | 여러 타입 같이 저장              |
| 크기      | 고정 크기                      | 가변 크기                        |
| 저장 방식 | 연속된 메모리 공간에 직접 저장 | 객체에 대한 참조를 순서대로 저장 |
| 속도      | 빠름                           | 비교적 느림                      |
| 장단점    | 삽입, 삭제 비효율적            | 사용편리, 확장성 좋음            |

## Tuple
리스트와 비슷하지만 수정이 불가능 함(immutable)
```python
tpl = (1,2,3)
```
- 수정 불가
- 고정된 데이터 표현에 적합
- 가변 함수 인자와 반환에 사용
```python
def func(*agrs) : # 함수의 인자로 가변값을 받음
	print(*agrs)  # 받은 가변인자는 tuple 형식으로 들어옴 
func('a', 'b')    # ('a', 'b')

def get_user():
    name = "Alice"
    age = 25
    return name, age  # 여러 값을 반환
    
print(get_user())     # ('Alice', 25) 
					  # tuple 형식으로 묶어서 반환됨
```

## Dict 
```python
student = {'name': 'kail', 'age': 24}
```
`key:value` 형식으로 데이터를 저장하는 자료구조 
키를 통해 빠르게 데이터를 찾을 수 있음 
- key는 중복되지 않은 불변 객체(문자열, 숫자, 튜블)을 사용함 
- value 는 중복 가능하고 다양한 값을 넣을 수 있음 (함수는 lambda형식을 사용)
- hash 기반 탐색을 사용해서 속도가 매우 빠름 (O(1))
- 파이썬의 dict은 삽입 순서성을 유지

## Set (집합)
수학의 집합 개념을 프로그래밍으로 옮겨놓은 자료구조 
- 중복 불가능 
- 순서 없음
- hash 기반 탐색을 사용해 속도가 매우 빠름 
- list 의 중복 제거에 사용 가능 
- 집합 연산 지원
	+ 합집합(`|` ) : 두 집합의 모든 원소 
	+ 교집합( `&` ) : 두 집합의 공통된 원소 
	+ 차집합( `-` ) : 한 쪽에만 존재하는 원소 
	+ 대칭 차집합( `^` ) : 공통되지 않은 나머지 원소

## 선형 자료구조 / 비선형 자료구조 
1. 선형 자료구조 
데이터가 한 줄로 순차적으로 이루어진 구조 
- List
- Tuple
- Str
- Queue
	+ 선입선출(FIFO)구조
	+ 작업 대기열 등 순서대로 처리가 필요할 때 사용
- Stack
	+ 후입선출(FILO)구조
	+ 함수 호출 구조 등 에서 사용
1. 비선형 자료구조 
데이터가 순차적으로만 이어지지 않는 구조
- Tree
	+ 그래프의 한 종류
	+ 계층 구조를 표현하는 자료구조 
- Graphic
	+ 노드와 간선을 하나로 모아놓은 구성
	+ 트리보다 더 일반적인 연결 구조
	+ 방향 그래프, 양방향 그래프, 무방향 그래프 등으로 나뉨

# 연산자
==프로그램에서 데이터를 가공하기 위해 사용하는 **약속된 기호**==
자료 구조에 따라 작동 방식이 달라지기도 함 

## 단항 연산자 
피연산자 1개를 대상으로 하는 연산자 
- 부호 연산자 : +x / -x (양수/음수 표시)
- 논리 부정 연산자 : not (참 -> 거짓으로)
- 비트 반전 연산자 : ~x (비트 단위 반전 )

## 이항 연산자 
피연사자 2개를 대상으로 하는 연산자 
- 산술 연산자 : `+`, `-`, `*`, `/`, `//`, `%`, `**`
- 비교 연산자 : `<`, `<=`, `>`, `>=`, `==`, `!=`
- 논리 연산자 : `and`, `or`
- 비트 연산자 :  `&`, `|`, `^`, `>>`, `<<`
- 연결 연산자 : `list1 + list2`
- 멤버십 : `item in group`
