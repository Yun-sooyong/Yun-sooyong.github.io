# 자료 구조 (Data Structure)
문자열, 리스트, 튜플, 딕셔너리, 집합 등을 자주 사용한다 

## 자료 구조 분류

### 순서가 있는(ordered)  자료구조 
- list 
- str
- tuple
- dict(삽입 순서를 유지)

### 순서가 없는(unordered) 자료구조 
- set

### 수정 가능한(mutable) 자료구조
- list 
- set 
- dict

### 수정 불가능한(immutable) 자료구조
- tuple
- str


## String
- 문자열을 저장하는 자료형
- 수정 불가능(immutable)
	+ 문자열은 수정 불가능 하기 때문에 변경이 필요하면 새로운 객체를 만들어 진다
- 순서가 있는 자료형 (sequence)
	+ 인덱싱, 슬라이싱, 반복 가능
- +/* 연산자 사용 가능
	+ + : 문자열 이어 붙이기 
	+ \* : 문자열 반복 

## ⭐ List ⭐ 
- ==파이썬의 대표적인 자료구조==
- 수정 가능(mutable)
- 순서가 있음 
	- 인덱싱, 슬라이싱 가능 
- 크기 변경가능
- 요소 추가 삭제 가능 
- 여러 타입의 값을 함께 저장가능
