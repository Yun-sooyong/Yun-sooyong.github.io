# 파이썬 기초 

## 파이썬? 
	데이터 분석, 머신러닝, 웹, 자동화 등 다양한 분야에서 사용되는 프로그래밍 언어 
	데이터 분석에서는 아래의 라이브러리들과 함께 사용됨
		- numpy : 수치 계산
		- pandas : 데이터 처리 
		- matplotlib : 데이터 시각화 
		- scikit-learn : 머신러닝
		- pytorch, tensorflow : 딥러닝

---

## 파이썬 자료형 
	 - 문자열 : str
	 - 정수 : int
	 - 실수  : float
	 - 불리언(논리자료형) : bool
	 - 리스트 : list
	 - 딕셔너리 : dict

### 리스트 
```python
number = [1, 2, 3, 4, 5]
print(number[0]) # index 0번 출력 = 1
```
