# 벡터(Vector)

## 벡터란?

크기와 방향을 함께 가지는 값 

예시 >
2차원 벡터 (3, 4)는 
x축으로 3, y 축으로 4 만큼 이동한 점의 위치로 
어느 방향으로 얼마나 이동하는가를 나타냄 

## 점이 하나인 벡터 
점이 하나인 벡터는 원점(0,0)을 기준으로 그 점의 위치를 본다 
즉, 위의 예시의 벡터인 (3,4)도 사실상 (0,0)과 (3,4) 두 점의 벡터를 계산한것이다

## 점이 두 개인 벡터 
A = (1, 2)
B = (3, 4)
이라면 
```python
A = (1, 2)
B = (3, 4)

AB = (B[0] - A[0], B[1] - A[1])

print(AB)

```
 
즉, 점 두개가 있을 때의 벡터는 끝점 - 시작점으로 계산

## 벡터의 크기 

벡터의 크기는 벡터의 길이와 같다 (크기 = 길이)  
2차원 벡터(x,y)의 크기는 피타고라스 정리를 이용해서 구한다 

$크기 = \sqrt{x^2 + y^2}$

이므로 (3,4)의 크기는

$\sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$

이다 

```python
import math

v = (3, 4)

size = math.sqrt(v[0] * v[0] + v[1] * v[1])

print(size)

```

점 하나의 벡터 크기(=길이)는 원점과의 거리라고 이해하면 된다 

### 점이 하나 일 때 크기 구하기 

원점 부터 주어진 (3,4) 까지의 거리와 같다 

```python

import math

P = (3, 4)
size = math.sqrt(P[0] * P[0] + P[1] * P[1])

print("점:", P)
print("크기:", size)

```

점 하나 = 원점 과 주어진 점과의 거리 


### 점이 두 개일 때 거리 구하기

```python

import math

A = (1, 2)
B = (4, 6)

dx = B[0] - A[0]
dy = B[1] - A[1]
  
distance = math.sqrt(dx * dx + dy * dy)

print("두 점 사이 거리:", distance)

```

두 점의 벡터의 크기 = 두 점의 거리

## 정규화 
벡터의 크기를 1로 만드는 작업


### 정규화를 하는 이유 

벡터는 보통 (크기)와 (방향)을 같이 가지고 있다 
이 중 벡터의 방향이 필요할 때 크기를 나눠서 1로 만들고 방향만을 사용하기 위해 사용

벡터들은 길이가 다르지만 같은 방향을 가지는 경우가 있음 
- (`3,4)` 
- `(6,8)` 
- `(30,40)` 
이 벡터들의 길이는 전부 다르지만 같은 방향을 가지며 이렇게 정규화된 벡터를 ***‘단위 벡터’***라고 한다

### 정규화 공식

$$\left(\frac{x}{\|크기\|}, \frac{y}{\|크기\|}\right)$$


```python
import math

v = (3,4)

size = math.sqrt(v[0] * v[0] + v[1] * v[1])
normalized = (v[0] / size, v[1] / size)

print(‘벡터 : ‘, v)
print(‘정규화 : ‘normalize)

# 출력결과
# 벡터 : (3,4)
# 정규화 : (0.6, 0.8)
```

> [!tip] 벡터 (0,0) 은 크기가 0이기에 정규화 할 수 없다

## 내적 (dot product) 
**두 벡터의 방향관계를 계산하는 방법**
**크기 정보와 방향 정보가 같이 들어있는 값**

### 계산식 
$$ a \cdot b = a1 \times b1 + a2 \times b2 $$

### 내적의 의미 
내적은 두 벡터가 얼마나 같은 방향인지도 알려준다 

$$a \cdot b = {\|a\|}{\|b\|}cos(\theta) $$

- $${\|a\|}$$ : 벡터 a의 크기 
- $${\|b\|}$$ : 벡터 b의 크기 
- $$\theta$$ : 두 벡터 사이의 각도 

### 내적의 결과 
1. 양수일 때
> 두 벡터가 비슷한 방향 
2. 0 일때 
> 두 벡터는 직각
3. 음수일 때 
> 두 벡터가 반대 방향 

---

## 코사인 유사도 
내적에서 크기를 제거하고 **방향만 비교한 값 **

### 계산식
내적을 두 벡터 크기의 곱으로 나눈 값

$$cos(\theta) = \frac{a \cdot b}{\|a\|\|b\|} $$

### 의미 
코사인 유사도는  `[-1 ~ 1] `사이의 값을 가짐

- 1 에 가까울수록 방향이 완전히 같음 
- 0 에 가까울수록 서로 직각, 관련성이 낮음 
- -1 에 가까울수록 방향이 완전히 반대

### 사용
- 문서 유사도 비교 
- 추천 시스템 
- 임베딩 벡터 비교
- 머신러닝 특징 벡터 비교 

### 정규화와 코사인 유사도
정규화한 벡터는 크기가 1이기 때문에 

$$a \cdot b = {\|a\|}{\|b\|}cos(\theta) $$

에서 a = 1, b = 1 
따라서 
$$a \cdot b = cos(\theta) $$ 
가 된다 

즉, **정규화된 벡터끼리의 내적은 코사인 유사도**이다

## 다차원 벡터 

다차원 벡터도 계산식은 다르지 않다 
- 벡터는 숫자의 묶음이기 때문에 각 항에서 n칸씩 추가해주면 된다 
- 차원이 커져도 계산방식은 달라지지 않는다
