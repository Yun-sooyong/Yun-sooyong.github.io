# 제어문
프로그램의 **실행순서와 흐름을 조절하는 문장**

제어문의 종류
- 조건문 : 조건에 따라 실행할 코드 블록을 선택
	+ `if`, `elif`, `else`
- 반복문 : 조건이 만족될 때까지 코드 블록을 반복 실행
	+ `for`, `while`
- 반복 제어문 : 반복문의 흐름을 강제로 바꾸거나 조절
	+ `break`, `continue`, `pass`
- 예외 처리문 : 프로그램 실행 도중 발생하는 문제(Exception)를 처리
	+ `try`, `except`, `finally`, `else`
---
## 조건문 
조건에 따라 실행할 코드 블록을 선택

- 기본 구조
```python
if [조건식] :
	[실행문]
elif [조건식2] :
	[실행문2]
else :
	[실행문3]
```

- 종류 
	- `if` :  조건이 True 일 때 내부 코드를 실행 
	- `elif` : if의 조건이 False 일 때 새로운 조건식을 확인
	- `else` : 앞의 모든 조건이 False 일 때 실행 

### 조건식 
결과가 항상 `True(참)`또는 `False(거짓)`으로 나오는 식

1. 존재론적 조건
	- False : `None`, `0`, `""`, `[]`, `()`, `{}`, `set()` (텅 빈 상태)
	- True : 값이 하나라도 들어있는 모든 상태
2. 포함 관계 조건
	 - 특정 데이터의 존재 여부 : `in`, `not in` 
3. 상등성, 동일성 조건
	- 값 비교 : `==`
	- 참조 비교 : `is`
	- None 비교 : `is`
4. 복합 논리 조건 
	-  **`and`**: 모든 조건이 True 면 통과
	- **`or`**: 하나라도 Ture면 통과
	- **`not`**: 조건의 답을 거꾸로 뒤집음

### 삼항 연산자 
피연산자가 3개인 연산자(조건 표현식)
`[참일 때의 값] if [조건] else [거짓일 때의 값]`
- 예시
```python
result = '짝수' if x % 2 == 0 else '홀수'
```

### match ~ case 
값이나 패턴의 일치를 확인하는 문법
python 3.1 이상에서 사용가능 

- 기본 구조
```python
match 변수:  
	case 값1:  
		실행문  
	case 값2:  
		실행문  
	case _:  
		실행문
```
- 예시
```python
command = "save"  
  
match command:  
	case "add":  
		print("추가")  
	case "save":  
		print("저장")  
	case "delete":  
		print("삭제")  
	case _:  
		print("알 수 없는 명령")
```

## 반복문 
같은 코드 블록을 여러번 반복해서 실행

- 반복문의 종류 
	- `for`
	- `while`

### for 문
순회 가능한 객체(Iterable)를 하나씩 꺼내면서 반복

- 기본 구조
```python
for [변수] in [반복가능객체]:  
	[실행문]
```

- 예제 
```python
for i in [1, 2, 3]:  
	print(i)
```


### while 문 
조건식이 True(참)인 동안 반복

- 기본 구조
```python
while [조건식]:
    [실행문]
```

- 예제
```python
i = 0  
  
while i < 5:  
    print(i)  
    i += 1
```

> [!tip] 무한 루프
> `while`을 사용할 때 조건식이 계속 True인 상태면 코드를 반복하는 '무한 루프'에 빠짐 
> `while`을 사용할 때는 `break` 등 반복 제어문을 사용하거나, 조건식을 False로 만들어야함  

### 포함 연산자 `in`
`in`은 어떤 값이 포함되어 있는 지 확인하는 연산자
반복문에서 반복가능객체(Iterator)와 자주 사용된다 

```python
for [변수] in [반복가능객체] :
	[실행문]
```

#### 순회 가능 객체 
`in`뒤에 사용가능 한 객체들을 모두 '**순회 가능 객체**'(iterator)라고 함 

1. 표준 자료 구조 (Collections)
	- 순서형 : `list`, 'tuple', `str`
	- 비순서형 : 'dict', `set`
2. 범위 및 수치 생성
	- `range`: 규칙에 따라 숫자를 하나씩 생성하면서 순회
3. 순회 도구
	- `iterator` : `next()` 함수를 통해 순서대로 다음 요소를 반환하는 객체 
	- `generator` : `yield`를 사용해서 데이터를 생성하며 순회, 대용량 데이터에서 필수
4. 순회 보조 함수 
	- `enumerate()` : index 와 value 를 같이 묶어 리턴
	- `zip()` : 두 개 이상의 순회 가능 객체를 병렬로 묶어 한 쌍식 리턴

## 반복 제어문
반복문의 흐름을 변경하는 문장

- 반복 제어문의 종류
	+ `break` : 반복문을 즉시 종료
	+ `continue` : 현재 반복문에서 아래 코드를 건너 뛰고, 다음으로 넘어감 
	+ `pass` : 아무 동작도 하지 않음, 주로 문법상 자리는 있지만 내용을 작성하기 전에 사용
	+ `else` : 반복문이 정상적으로 종료되면 `else`의 코드 블록이 실행됨.  break나 error 로 종료되면 실행되지 않음

## 예외 처리문 
프로그램 실행 중 예기치 못한 에러가 발생 시, 프로그램이 갑자기 멈추지 않도록 흐름을 제어함 

- 예외 처리문의 종류
	+ `try` : 에러 발생 가능성이 높은 코드 블록을 넣을 곳 
	+ `except` : 에러가 발생 시 처리할 내용을 넣는 곳 
	+ `else` : `try`에서 에러가 나지 않으면 실행
	+ `finally` : 에러 발생 여부에 상관없이 반드시 실행 (주로 파일 닫기, 연결 종료 처럼 무조건 실행되어야 하는 내용이 들어감 )

- 예시
```python
my_dict = {"apple": 1000}

try:
    # 1. 존재하지 않는 키에 접근 시도 (KeyError 발생 가능성)
    price = my_dict["banana"]
except KeyError:
    # 2. 에러 발생 시 대처법
    print("해당 과일이 사전에 없습니다.")
else:
    # 3. 성공했을 때만 실행
    print(f"가격은 {price}원입니다.")
finally:
    # 4. 무조건 실행 (정리 작업)
    print("조회를 종료합니다.")
```

[파이썬 에러 코드 정리 문서](https://docs.python.org/ko/3/library/exceptions.html)

## List Comprehension
파이썬에서 리스트를 간결하게 생성하기 위해 사용하는 문법

- 기본 구조
```python
# [반복 가능 객체]를 순회하면서 [조건]에 맞는 값을 [항목]에 담아 [표현식]에서 사용한다 
[표현식 for 항목 in 반복가능객체 if 조건]
```

- 예제
```python
# 일반적인 방식
squares = []
for x in range(10):
    squares.append(x**2)

# 리스트 컴프리핸션
even_numbers = [x for x in range(10) if x % 2 == 0]
# 결과: [0, 2, 4, 6, 8]
```

- 코드가 너무 길 경우 가독성이 떨어짐 
- 코드가 짧아 가독성이 좋고, 일반 루프보다 속도가 약간 좋음

## 수업에서 사용된 함수

### `isdigit()`
문자열이 **숫자로만 이루어져 있는지** 확인
```python
print("123".isdigit())   # True  
print("12a".isdigit())   # False

# 음수 부호나 소수점이 있으면 `False` 입니다.
print("-3".isdigit())    # False  
print("3.14".isdigit())  # False
```
---
### `index()`
문자열이나 리스트에서 **특정 값의 위치(인덱스)** 를 리턴
```python
text = "python"  
print(text.index("t"))   # 2

# 찾는 값이 없으면 오류가 발생합니다.
text.index("z")  # ValueError

```
비슷한 함수로 `find()` 가 있음

- `find()` : 없으면 `-1`
- `index()` : 없으면 오류 발생

---

### `upper()`
문자열을 모두 대문자로 변환합니다.
```python
print("python".upper())   # PYTHON
```
관련 함수
- lower() : 소문자 변환  
- title() : 각 단어 첫 글자 대문자  
- strip() : 양쪽 공백 제거

## 랜덤한 정수 생성
`random` 은 함수가 아니라 **모듈**
랜덤한 정수를 만들 때는 보통 `random.randint()` 를 사용

- 예제
```python
import random # 랜덤을 사용하기 위한 모듈을 import 해줘야 한다 
  
num = random.randint(1, 10)  
print(num)

# 1~10 사이의 무작위 정수를 반환 
```
