# 자료 구조 (Data Structure)
문자열, 리스트, 튜플, 딕셔너리, 집합 등을 자주 사용한다 

## 자료 구조 분류

1.  순서가 있는(sequence)  자료구조 
	- list 
	- str
	- tuple
	- dict(삽입 순서를 유지)

2. 순서가 없는(unordered) 자료구조 
	- set

3.  수정 가능한(mutable) 자료구조
	- list 
	- set 
	- dict

4.  수정 불가능한(immutable) 자료구조
	- tuple
	- str
---
## 순서가 있는 자료 구조의 표준 연산

- indexing
인덱스를 이용해 특정 위치 값에 접근
```python
list = [1,2,3]
list[0] # 1
```

- slicing
일부 구간만 잘라 접근
```python
list = [1,2,3]
list[0:2] # 1,2
list[-1]  # 3, 가장 마지막을 반환
list[start:end:step]
```

- concatenation
두 자료구조를 이어 붙여 새로운 순서를 만듦
```python
[1,2] + [3,4]
# = [1,2,3,4]
```

- repetition 
동일한 데이터를 지정 횟수 만큼 반복
```python
[0]*3 # [0,0,0]
```

- membership test
in, not in 연산자로 포함, 비포함 여부 확인
	+ 비순서형 자료구조도 membership test가 있고 오히려 비순서형이 더 빠름 
	+ 비순서 자료구조의 특징 중 하나 
```python
3 in [1,2,3] # True
```

- len()
길이를 반환, 내장 함수
```python
list = [1,2,3]
len(list) # 3
```

- enumerate()
순서가 있는 객체의 인덱스와 데이터를 동시에 꺼내오기 위해 사용
```python
fruits = ['apple', 'banana', 'cherry']

for index, value in enumerate(fruits):
    print(f"{index}번 과일: {value}")
	# 1번 과일 : 'apple'
	# 2번 과일 : 'banana'
	# 3번 과일 : 'cherry'
```

- sort()
데이터를 기준에 따라 순서대로 정렬하는 기능 
순서형 자료 구조 중 변경가능한 자료구조에서만 사용됨 
tuple / str은 변경이 불가능한 자료구조이기 때문에 정렬된 새로운 리스트를 만들어서 반환
```python
list = [1,4,2,3,6,5]
list.sort() # 리스트 자체를 정렬
list.sort(reverse = True) # 내림차순 정렬
list.sort()
sorted(list) # 원본과 별개로 정렬된 새 객체를 반환

rows = [[1, 10], [2, 30], [3, 20]]  
rows.sort(key=lambda row: row[1], reverse=True)
# [[2, 30], [3, 20], [1, 10]]
# 기준점을 lambda식으로 정해줄 수 있음 
```

## String
- 문자열을 저장하는 자료형
- 수정 불가능(immutable)
	+ 문자열은 수정 불가능 하기 때문에 변경이 필요하면 새로운 객체를 만들어 진다
- 순서가 있는 자료형 (sequence)
	+ 인덱싱, 슬라이싱, 반복 가능
- \+ / * 연산자 사용 가능
	+ \+ : 문자열 이어 붙이기 
	+ \* : 문자열 반복 

## ⭐ List ⭐ 
- ==파이썬의 대표적인 자료구조==
- 수정 가능(mutable)
- 순서가 있음 (sequence)
- 크기 변경가능
- 요소 추가 삭제 가능 
- 여러 타입의 값을 함께 저장가능 
- ==객체를 참조하는 정보를 순서대로 담은 기능==

List 와 Array 차이점 

|    비교    | Array                          | List                             |
| --------- | ------------------------------ | -------------------------------- |
| 타입      | 단일 타입 저장                 | 여러 타입 같이 저장              |
| 크기      | 고정 크기                      | 가변 크기                        |
| 저장 방식 | 연속된 메모리 공간에 직접 저장 | 객체에 대한 참조를 순서대로 저장 |
| 속도      | 빠름                           | 비교적 느림                      |
| 장단점    | 삽입, 삭제 비효율적            | 사용편리, 확장성 좋음            |

## Tuple
리스트와 비슷하지만 수정이 불가능 함(immutable)
```python
tpl = (1,2,3)
```
- 수정 불가
- 고정된 데이터 표현에 적합
- 가변 함수 인자와 반환에 사용
```python
def func(*agrs) : # 함수의 인자로 가변값을 받음
	print(*agrs)  # 받은 가변인자는 tuple 형식으로 들어옴 
func('a', 'b')    # ('a', 'b')

def get_user():
    name = "Alice"
    age = 25
    return name, age  # 여러 값을 반환
    
print(get_user())     # ('Alice', 25) 
					  # tuple 형식으로 묶어서 반환됨
```

## Dict 
```python
student = {'name': 'kail', 'age': 24}
```
`key:value` 형식으로 데이터를 저장하는 자료구조 
키를 통해 빠르게 데이터를 찾을 수 있음 
- key는 중복되지 않은 불변 객체(문자열, 숫자, 튜블)을 사용함 
- value 는 중복 가능하고 다양한 값을 넣을 수 있음 (함수는 lambda형식을 사용)
- hash 기반 탐색을 사용해서 속도가 매우 빠름 (O(1))
- 파이썬의 dict은 삽입 순서성을 유지

## Set (집합)
수학의 집합 개념을 프로그래밍으로 옮겨놓은 자료구조 
- 중복 불가능 
- 순서 없음
- hash 기반 탐색을 사용해 속도가 매우 빠름 
- list 의 중복 제거에 사용 가능 
- 집합 연산 지원
	+ 합집합(`|` ) : 두 집합의 모든 원소 
	+ 교집합( `&` ) : 두 집합의 공통된 원소 
	+ 차집합( `-` ) : 한 쪽에만 존재하는 원소 
	+ 대칭 차집합( `^` ) : 공통되지 않은 나머지 원소

# 연산자
==프로그램에서 데이터를 가공하기 위해 사용하는 **약속된 기호**==
자료 구조에 따라 작동 방식이 달라지기도 함 
---
## 단항 연산자 
피연산자 1개를 대상으로 하는 연산자 
- 부호 연산자 : `+x` / `-x` (양수/음수 표시)
- 논리 부정 연산자 : `not` (참 -> 거짓으로)
- 비트 반전 연산자 : `~x` (비트 단위 반전 )

## 이항 연산자 
피연사자 2개를 대상으로 하는 연산자 
- 산술 연산자 : `+`, `-`, `*`, `/`, `//`, `%`, `**`
- 비교 연산자 : `<`, `<=`, `>`, `>=`, `==`, `!=`
- 논리 연산자 : `and`, `or`
- 비트 연산자 :  `&`, `|`, `^`, `>>`, `<<`
- 연결 연산자 : `list1 + list2`
- 멤버십 : `item in group`

## 삼항 연산자 
피연산자가 3개인 연산자, 조건부 표현식으로 하나 존재
`[참일 때의 값] if [조건] else [거짓일 때의 값]`
- 예시
```python
result = '짝수' if x % 2 == 0 else '홀수'
```
---

## 대입 표현식(바다 코끼리 연산자)
표현식 안에서 값을 대입하면서 동시에 그 값을 반환하는 연산자 
```python
if (n := len(data)) > 10:
    print(f"너무 깁니다: {n}개")
```

## 관계 연산자
값의 대소, 상등 관계를 나타내는 연산자 
결과로 `True`,`False` 라는 논리값을 반환

|연산자|의미|예시 (`a=10, b=20`)|
|---|---|---|
|**`==`**|같다 (상등)|`a == b` → `False`|
|**`!=`**|같지 않다|`a != b` → `True`|
|**`>`**|크다 (초과)|`a > b` → `False`|
|**`<`**|작다 (미만)|`a < b` → `True`|
|**`>=`**|크거나 같다 (이상)|`a >= 10` → `True`|
|**`<=`**|작거나 같다 (이하)|`b <= 15` → `False`|

> [!tip] `==` 과 `is` 의 차이 
> `==` (상등) : 두 객체의 값이 같은지 확인  
> `is` (동일성) : 두 객체의 참조가 같은지 확인
---

## 논리 연산자 
논리값(True / False)을 조합, 반전 하는 연산자 

|연산자|기능|설명|
|---|---|---|
|**`and`**|논리곱|양쪽 조건이 **모두 True**일 때만 결과가 True가 됩니다.|
|**`or`**|논리합|양쪽 중 **하나라도 True**면 결과가 True가 됩니다.|
|**`not`**|논리부정|결과를 반대로 뒤집습니다. (True → False, False → True)|

- 파이썬의 논리연산자는 앞의 조건으로 결과를 알 수 있으면 뒤는 실행하지 않음 
	- `False and ...` : False가 앞에 있으므로 뒤는 상관없이 무조건 False
	- `True or ...` : True가 앞에 있으므로 뒤는 상관없이 무조건 True
---

## 비트 연산자 
데이터를 이진수(0과 1) 단위에서 직접 조작하는 연산자 

|연산자|명칭|기능|예시 (5: `101`, 3: `011`)|
|---|---|---|---|
|**`&`**|AND|둘 다 1이면 1|`5 & 3` → `001` (1)|
|**`\|`**|OR|하나라도 1이면 1|`5 \| 3` → `111` (7)|
|**`^`**|XOR|서로 다르면 1|`5 ^ 3` → `110` (6)|
|**`~`**|NOT|0은 1로, 1은 0으로 반전|`~5` → `-6` (보수 관계)|
|**`<<`**|왼쪽 시프트|비트를 왼쪽으로 이동 (2배씩 증가)|`5 << 1` → `1010` (10)|
|**`>>`**|오른쪽 시프트|비트를 오른쪽으로 이동 (2배씩 감소)|`5 >> 1` → `10` (2)|

- **`and` vs `&`**: `and`는 값 전체가 0이 아니면 참으로 보지만, `&`는 각 자릿수별로 비교
- **결과값**: 논리 연산자는 항상 `True/False`를 내놓지만, 비트 연산자는 **계산된 정수값**을 내놓음

## 연산자 우선순위

1. 괄호 `()`
2. 거듭제곱 `**`
3. 단항 연산자 `+x`, `-x`, `~x`
4. 곱셈, 나눗셈, 몫, 나머지 `*`, `/`, `//`, `%`
5. 덧셈, 뺄셈 `+`, `-`
6. 비교 연산자 `<`, `<=`, `>`, `>=`, `==`, `!=`
7. `not`
8. `and`
9. `or`
10. 대입 연산자 `=`, `+=`, `-=`
