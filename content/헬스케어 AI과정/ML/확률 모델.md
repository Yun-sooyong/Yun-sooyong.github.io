# 확률 모델과 로지스틱 회귀

---

## 1. 확률의 기본 개념

### 이산 확률 vs 연속 확률

확률은 다루는 데이터가 **셀 수 있는가(이산)** 인지 **측정되는가(연속)** 인지에 따라 다르게 처리한다.

#### 이산 확률 (Discrete Probability)

셀 수 있는 유한한 값들을 다룬다. **확률질량함수(PMF, Probability Mass Function)** 로 표현한다.

$$P(X = k) = f(k), \quad \sum_k P(X=k) = 1$$

```
주사위 한 번 굴리기:
  P(X=1) = 1/6, P(X=2) = 1/6, ..., P(X=6) = 1/6
  모든 확률의 합 = 1

이산 분포의 예:
  이항 분포 (Binomial): n번 중 성공 k번
  포아송 분포 (Poisson): 단위 시간에 사건이 k번 발생
  베르누이 분포 (Bernoulli): 성공/실패 한 번
```

```python
from scipy import stats
import numpy as np

# 이항 분포: n=10번 시도, p=0.3 성공률
binom = stats.binom(n=10, p=0.3)
print(f'P(X=3) = {binom.pmf(3):.4f}')   # 정확히 3번 성공할 확률
print(f'P(X≤3) = {binom.cdf(3):.4f}')   # 3번 이하 성공할 확률

# 포아송 분포: λ=5 (평균 5번 발생)
poisson = stats.poisson(mu=5)
print(f'P(X=5) = {poisson.pmf(5):.4f}')
```

#### 연속 확률 (Continuous Probability)

실수 범위의 연속적인 값을 다룬다. **확률밀도함수(PDF, Probability Density Function)** 로 표현한다.

$$\int_{-\infty}^{\infty} f(x) dx = 1$$

연속 확률에서 특정 값 하나의 확률은 정확히 0이다. 의미 있는 것은 **구간의 확률**이다.

$$P(a \leq X \leq b) = \int_a^b f(x) dx$$

```
정규 분포, 지수 분포, 균일 분포 등이 연속 분포다.
키가 정확히 175.000...cm일 확률 = 0
키가 174~176cm 사이일 확률 = 어떤 양수값
```

#### PDF, CDF, PPF, RVS — 확률 분포의 네 가지 함수

어떤 분포든 이 네 가지 함수로 모든 것을 계산할 수 있다.

|함수|이름|의미|예시|
|---|---|---|---|
|**PDF**|확률밀도함수|특정 값에서의 밀도|"x=100에서 얼마나 집중되어 있나?"|
|**CDF**|누적분포함수|$P(X \leq x)$|"X가 100 이하일 확률은?"|
|**PPF**|백분위수함수 (CDF의 역함수)|확률 → 값|"상위 5%의 기준값은?"|
|**RVS**|난수 생성|분포에서 무작위 표본 추출|"이 분포에서 100개 샘플 뽑기"|

```python
from scipy import stats

dist = stats.norm(loc=100, scale=15)  # 평균 100, 표준편차 15

print(f'PDF(100): {dist.pdf(100):.4f}')    # 100에서의 밀도 (최댓값)
print(f'CDF(115): {dist.cdf(115):.4f}')    # P(X ≤ 115) ≈ 0.84
print(f'PPF(0.95): {dist.ppf(0.95):.2f}') # 상위 5% 기준값 ≈ 124.7
samples = dist.rvs(size=1000, random_state=42)  # 난수 1000개
```

### 주변 확률, 결합 확률, 조건부 확률

확률을 이해하는 세 가지 시각이다. 아래 표를 예시로 보자.

||사과|포도|행의 합|
|---|---|---|---|
|남|9|1|10|
|여|15|5|20|
|열의 합|24|6|30|

**주변 확률 (Marginal Probability)**  
한 변수만 고려한 확률이다. 다른 변수를 무시하고 합산한다.

$$P(\text{남}) = \frac{10}{30} = 0.33, \quad P(\text{사과}) = \frac{24}{30} = 0.80$$

**결합 확률 (Joint Probability)**  
두 사건이 동시에 일어날 확률이다.

$$P(A \cap B) = \frac{n(A \cap B)}{n(S)}$$

$$P(\text{남} \cap \text{사과}) = \frac{9}{30} = 0.30$$

**조건부 확률 (Conditional Probability)**  
한 사건이 주어졌을 때 다른 사건이 일어날 확률이다.

$$P(B|A) = \frac{P(A \cap B)}{P(A)} = \frac{n(A \cap B)}{n(S) \cdot P(A)}$$

$$P(\text{사과} | \text{남}) = \frac{P(\text{남} \cap \text{사과})}{P(\text{남})} = \frac{9/30}{10/30} = \frac{9}{10} = 0.90$$

"남성 중에서 사과를 선택한 비율"이 조건부 확률이다.

---

### 확률의 덧셈·곱셈 법칙

**덧셈 법칙**: 두 사건 중 하나라도 일어날 확률

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

- $A$와 $B$가 서로 배타적이면: $P(A \cup B) = P(A) + P(B)$

**곱셈 법칙**: 두 사건이 동시에 일어날 확률

$$P(A \cap B) = P(A) \cdot P(B|A) = P(B) \cdot P(A|B)$$

- $A$와 $B$가 독립이면: $P(A \cap B) = P(A) \cdot P(B)$

---

### 전확률 정리 (Law of Total Probability)

사건 $B$가 일어날 확률을 상호 배타적이고 전체를 덮는 사건 $A_1, A_2, \ldots, A_k$로 분해한다.

$$P(B) = P(B \cap A_1) + P(B \cap A_2) = P(B|A_1)P(A_1) + P(B|A_2)P(A_2)$$

$$P(A) = \sum_{i=1}^{k} P(B_i) P(A|B_i) \quad (\text{단, } P(B_i) > 0)$$

```
직관:
  P(B)는 전체 공간에서 B의 넓이
  A₁과 A₂로 공간을 나누면:
  P(B) = "A₁ 안에서 B" + "A₂ 안에서 B"
       = P(B|A₁)P(A₁) + P(B|A₂)P(A₂)
```

## 2. 우도 (Likelihood)와 로그우도

### 확률 vs 우도의 차이

같은 공식이지만 **무엇이 고정되어 있느냐**가 다르다.

```
확률 P(데이터 | 파라미터):  파라미터가 고정, 데이터가 변함
  → "이 동전(p=0.7)을 10번 던졌을 때 앞면 7번이 나올 확률은?"

우도 L(파라미터 | 데이터):  데이터가 고정, 파라미터가 변함
  → "앞면이 7번 나왔을 때, 이 동전의 앞면 확률 p가 0.7일 가능성은?"
```

우도는 "이 데이터가 관측되었을 때, 파라미터 $\theta$가 얼마일 가능성이 있는가"를 수치화한다.

### 연속형 데이터에서 우도 계산 흐름

```
히스토그램을 만든다
   ↓
분포를 추정한다 (정규분포? 지수분포? ...)
   ↓
확률밀도를 계산한다
   ↓
각 데이터 포인트의 밀도를 모두 곱하면 우도
```

분포를 아느냐 모르느냐에 따라 방법이 나뉜다.

```
분포를 아는가?
   ├─ Yes → Parametric
   │         우도 계산 가능
   │         → MLE (최대우도추정)
   │         → Bayes (사전확률 활용)
   │
   └─ No  → Nonparametric
             분포 자체를 추정
             → KDE (커널 밀도 추정)
             → EDF (경험적 분포 함수)
```

### 로그우도 (Log-Likelihood)

우도는 확률의 곱이라 매우 작은 값이 된다. 수치 계산에서 언더플로우가 발생하고 미분도 복잡해진다. 로그를 취하면 곱셈이 덧셈으로 바뀌어 계산이 안정적이 된다.

$$\ln L(\theta) = \sum_{i=1}^{n} \ln p(x_i | \theta)$$

로그는 단조증가 함수이므로 로그우도를 최대화하는 $\theta$는 우도를 최대화하는 $\theta$와 동일하다.

## 3. 베이즈 정리 (Bayes' Theorem)

$$P(H|E) = \frac{P(H) \cdot P(E|H)}{P(E)}$$

|용어|설명|
|---|---|
|**Prior** $P(H)$|사전 확률. 증거를 보기 전 가설의 믿음|
|**Likelihood** $P(E\|H)$|우도. 가설이 참일 때 이 증거가 나올 확률|
|**Posterior** $P(H\|E)$|사후 확률. 증거를 본 후 업데이트된 믿음|
|**Normalising Constant** $P(E)$|전확률. 사후 확률이 0~1이 되도록 정규화|

$$\underbrace{P(H|E)}_{\text{Posterior}} = \frac{\underbrace{P(H)}_{\text{Prior}} \cdot \underbrace{P(E|H)}_{\text{Likelihood}}}{\underbrace{P(E)}_{\text{Normalising Constant}}}$$

```
직관:
  스팸 메일 분류 예시

  Prior P(스팸) = 0.3      ← 경험상 이메일의 30%는 스팸
  Likelihood P("무료"|스팸) = 0.9  ← 스팸에 "무료"가 들어올 확률
  Evidence P("무료") = 전확률 계산

  "무료"라는 단어가 있을 때 스팸일 확률
  = 0.3 × 0.9 / P("무료")

  → 데이터(증거)가 많아질수록 Prior의 영향이 줄고
    Posterior가 실제에 수렴함
```

## 4. MLE (Maximum Likelihood Estimation, 최대우도추정)

관측된 데이터를 가장 잘 설명하는 **파라미터를 역으로 추정**하는 방법이다.

$$\hat{\theta} = \arg\max_\theta L(\theta | \text{data})$$

로그우도를 파라미터로 미분해서 기울기가 0이 되는 지점을 찾는다.

$$\frac{d}{d\theta} \ln L(\theta) = 0$$

로지스틱 회귀에서 MLE:

$$L(w) = \prod_{i=1}^{n} p_i^{y_i} (1-p_i)^{1-y_i}$$

- $y_i = 1$인 샘플: $p_i$ 가 최대가 되는 방향
- $y_i = 0$인 샘플: $(1-p_i)$ 가 최대가 되는 방향
- 모든 샘플이 맞을 확률의 곱을 최대화하는 $w$를 찾는다

로그를 취하면 곱셈이 덧셈으로 바뀐다.

$$\ln L(w) = \sum_{i=1}^{n} \left[ y_i \ln p_i + (1-y_i) \ln(1-p_i) \right]$$

이것이 바로 **이진 교차 엔트로피(Binary Cross-Entropy)** 손실 함수다.

## 5. 로지스틱 회귀 (Logistic Regression)

### Odds와 Logit 변환

로지스틱 회귀는 **선형 결합의 출력을 확률(0~1)로 변환**하는 모델이다.

**Odds**: "이길 확률 / 질 확률"의 비율

$$\text{odds} = \frac{\pi}{1-\pi} \quad \Leftrightarrow \quad \pi = \frac{\text{odds}}{1 + \text{odds}}$$

Odds의 범위: $(0, +\infty)$. 이것도 아직 선형 모델에 쓰기 불편하다.

**Logit**: Odds에 로그를 취해 $(-\infty, +\infty)$로 확장한다.

$$\text{logit}(\pi) = \log\left(\frac{\pi}{1-\pi}\right) = \beta_0 + \beta_1 X$$

이제 선형 회귀처럼 오른쪽에 선형 모델을 놓을 수 있다.

**Probability form**: Logit을 다시 확률로 변환하면 **시그모이드 함수**가 된다.

$$\pi = \frac{e^{\beta_0 + \beta_1 X}}{1 + e^{\beta_0 + \beta_1 X}} = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$

```
변환 흐름:
  선형 결합 (-∞ ~ +∞)
       ↓ Logit 역변환
     Odds (0 ~ +∞)
       ↓ Odds → 확률
    확률 (0 ~ 1)
```

### 계수 해석

$\beta_1$은 $x$가 1 증가할 때 **Odds가 $e^{\beta_1}$배** 변함을 의미한다.

```
β₁ = 0.5이면:
  x가 1 증가 → Odds가 e^0.5 ≈ 1.65배 증가
  → "이길 확률이 65% 더 높아진다"
```

이것이 로지스틱 회귀 계수의 직관적 해석이다.

```python
from sklearn.linear_model import LogisticRegression
import numpy as np

model = LogisticRegression(C=1.0, penalty='l2', solver='lbfgs', max_iter=1000)
model.fit(X_train, y_train)

# 계수 해석
coef = model.coef_[0]
odds_ratio = np.exp(coef)   # Odds Ratio

for name, beta, OR in zip(feature_names, coef, odds_ratio):
    print(f'{name:20s}: β={beta:+.3f}, OR={OR:.3f}')
# OR > 1: 해당 변수 증가 시 클래스 1 확률 증가
# OR < 1: 해당 변수 증가 시 클래스 1 확률 감소
```

## 6. sklearn의 분류 모델

### LogisticRegression

|파라미터|설명|
|---|---|
|`penalty`|정규화 종류: `'l1'`, `'l2'`(기본), `'elasticnet'`, `None`|
|`C`|정규화 강도의 **역수**. 작을수록 강한 정규화. (기본값 1.0)|
|`solver`|최적화 방법 (아래 표 참고)|
|`max_iter`|최대 반복 횟수|
|`multi_class`|다중 분류 전략 (`'auto'`, `'ovr'`, `'multinomial'`)|

```python
from sklearn.linear_model import LogisticRegression, LogisticRegressionCV

# 기본 사용
lr = LogisticRegression(
    penalty='l2',
    C=1.0,          # 작을수록 강한 정규화 (C = 1/λ)
    solver='lbfgs',
    max_iter=1000,
    random_state=42
)
lr.fit(X_train, y_train)

# predict_proba: 클래스별 확률 반환 (MLE의 결과)
proba = lr.predict_proba(X_test)   # [[P(0), P(1)], ...]
print(f'확률 (상위 3개):\n{proba[:3]}')

# C와 정규화 강도의 관계
# C = 0.01: 매우 강한 정규화 → 계수가 0에 가까워짐 → 단순 모델
# C = 100:  매우 약한 정규화 → 계수 자유롭게 학습 → 복잡 모델

# CV로 최적 C 자동 선택
lr_cv = LogisticRegressionCV(
    Cs=10,              # 탐색할 C 값 수
    cv=5,
    penalty='l2',
    solver='lbfgs',
    max_iter=1000
)
lr_cv.fit(X_train, y_train)
print(f'최적 C: {lr_cv.C_}')
```

---

### Solver 선택 가이드

|Solver|최적화 방식|다중 분류|특징|
|---|---|---|---|
|`lbfgs`|준뉴턴법 (BFGS)|✅|기본값. 대부분의 경우 좋은 성능|
|`liblinear`|Coordinate Descent|❌ (OvR만)|소규모 데이터에 빠름. L1 지원|
|`newton-cg`|Newton-CG|✅|중간 규모. L2만 지원|
|`newton-cholesky`|Full Newton|✅|소규모 + 정밀도 높음|
|`sag`|확률경사하강법|✅|대량 데이터에 빠름. L2만 지원|
|`saga`|SAG + L1|✅|대량 데이터 + L1/Elasticnet 지원|

```
선택 기준:

데이터 양이 많다?          → sag, saga
L1 정규화가 필요하다?      → liblinear(소규모), saga(대규모)
Elasticnet이 필요하다?    → saga
기본 상황?                 → lbfgs
```

각 Solver의 수학적 배경을 간단히 이해하면 선택이 쉬워진다.

**lbfgs**: 헤시안 행렬을 직접 계산하지 않고 최근 몇 번의 기울기로 근사 (메모리 효율적 준뉴턴법)

**liblinear**: 좌표 하강법. 한 번에 하나의 파라미터만 최적화. 수렴이 느릴 수 있지만 구현이 단순

**sag/saga**: 매 스텝마다 전체 데이터가 아닌 무작위 샘플 하나(또는 일부)로 기울기 계산. 대량 데이터에서 훨씬 빠름

### RidgeClassifier

Ridge 회귀의 분류 버전이다. 클래스를 정수(0, 1, 2...)로 인코딩한 뒤 Ridge 회귀를 적용하고, 예측값이 가장 가까운 클래스를 선택한다. `predict_proba()`를 지원하지 않지만 빠르다.

```python
from sklearn.linear_model import RidgeClassifier, RidgeClassifierCV

rc = RidgeClassifier(alpha=1.0)   # alpha는 정규화 강도 (LogisticRegression의 C 역수와 반대)
rc.fit(X_train, y_train)

# CV 버전
rc_cv = RidgeClassifierCV(alphas=[0.01, 0.1, 1, 10, 100])
rc_cv.fit(X_train, y_train)
print(f'최적 alpha: {rc_cv.alpha_}')
```

**LogisticRegression vs RidgeClassifier 차이**:

|구분|LogisticRegression|RidgeClassifier|
|---|---|---|
|손실 함수|Cross-Entropy (확률 기반)|MSE (회귀 기반)|
|출력|확률 (0~1)|클래스 레이블만|
|해석|확률적 (Odds, 베이즈)|결정적|
|속도|보통|빠름 (선형대수로 해석적 풀이)|

### SGDClassifier

경사하강법(Gradient Descent)으로 선형 분류기를 학습한다. 데이터를 미니배치로 나눠 순차적으로 파라미터를 업데이트하므로 **대량 데이터**에 적합하다.

```python
from sklearn.linear_model import SGDClassifier

sgd = SGDClassifier(
    loss='log_loss',    # 손실 함수: 'log_loss'→로지스틱, 'hinge'→SVM
    penalty='l2',       # 정규화
    alpha=0.0001,       # 정규화 강도 (클수록 강함)
    learning_rate='optimal',  # 학습률 감소 방식
    max_iter=1000,
    random_state=42
)

# 미니배치 학습 (메모리에 다 안 들어오는 대량 데이터)
for epoch in range(10):
    for X_chunk, y_chunk in generate_chunks(X_train, y_train, size=1000):
        sgd.partial_fit(X_chunk, y_chunk, classes=[0, 1])
```

`loss='log_loss'`이면 LogisticRegression과 동일한 모델이지만, 최적화 방식이 경사하강법이라 수렴이 더 느릴 수 있다. 데이터가 메모리에 다 들어오면 LogisticRegression을, 들어오지 않으면 SGDClassifier를 쓰는 것이 일반적이다.

## 7. 다중 분류 전략

### OvR (One vs Rest, 일대다)

클래스마다 "이 클래스 vs 나머지" 이진 분류기를 만든다.

```

  분류기 1: A vs (B, C)
  분류기 2: B vs (A, C)
  분류기 3: C vs (A, B)

3개 분류기 중 가장 높은 확률의 클래스 선택
```

$$P(y=k|x) = \frac{e^{w_k^T x}}{\sum_j e^{w_j^T x}} \quad \text{(Softmax)}$$

## 10. 정규분포 (Normal Distribution)

### 왜 정규분포가 중요한가

통계와 머신러닝에서 가장 많이 가정하는 분포다. 자연 현상과 측정값의 오차가 이 분포를 따르는 경우가 많고, **중심극한정리**에 의해 표본 평균의 분포가 원래 분포와 무관하게 정규분포에 수렴한다.

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

- $\mu$: 평균 (분포의 중심)
- $\sigma$: 표준편차 (분포의 폭)
- 표기: $X \sim N(\mu, \sigma^2)$

```
핵심 특성:
  - 평균에 대해 좌우 대칭
  - 평균 = 중위수 = 최빈값 (세 대표값이 일치)
  - 종 모양 (Bell curve)
  - 면적의 합 = 1 (확률이므로)
```

---

### 표준 정규분포와 Z-점수 (Z-Score)

**표준 정규분포**: 평균 0, 표준편차 1인 특수한 정규분포 $N(0, 1)$

어떤 정규분포든 **Z-점수(표준화)** 로 표준 정규분포로 변환할 수 있다.

$$Z = \frac{X - \mu}{\sigma}$$

Z-점수는 "이 값이 평균에서 표준편차 몇 개만큼 떨어져 있는가"를 나타낸다.

```
예: 시험 점수가 평균 70점, 표준편차 10점일 때
    내 점수 85점의 Z-점수 = (85 - 70) / 10 = 1.5
    → "평균보다 1.5 표준편차 위에 있다"
    → 상위 약 6.7%

Z가 표준화되면 어떤 분포든 같은 표에서 확률을 조회할 수 있다.
```

```python
from scipy import stats
import numpy as np
import matplotlib.pyplot as plt

# 표준화
mu, sigma = 70, 10
score = 85
z = (score - mu) / sigma
print(f'Z-점수: {z:.2f}')

# 표준 정규분포로 확률 계산
dist = stats.norm(0, 1)
p_above = 1 - dist.cdf(z)
print(f'상위 {p_above*100:.1f}%')   # ≈ 6.7%

# 역으로: 상위 10%의 원점수는?
z_top10 = dist.ppf(0.90)            # Z-점수
score_top10 = mu + z_top10 * sigma  # 원점수로 변환
print(f'상위 10% 기준: {score_top10:.1f}점')
```

---

### 68-95-99.7 법칙 (3-시그마 법칙)

정규분포에서 평균을 중심으로 특정 범위 안에 데이터가 포함될 확률이다.

|범위|확률|의미|
|---|---|---|
|$\mu \pm 1\sigma$|**68.3%**|데이터의 약 2/3이 이 안에 있음|
|$\mu \pm 2\sigma$|**95.4%**|데이터의 약 95%가 이 안에 있음|
|$\mu \pm 3\sigma$|**99.7%**|데이터의 거의 전부가 이 안에 있음|

```
응용:
  이상치 탐지: 평균에서 3σ 이상 벗어나면 이상치로 판단
  가설검정:   95% 신뢰수준 → 2σ 범위 밖이면 유의미
  품질 관리:  6σ 품질 → 백만 개 중 3.4개 불량
```

```python
from scipy import stats

dist = stats.norm(0, 1)

# 3-시그마 법칙 검증
for k in [1, 2, 3]:
    prob = dist.cdf(k) - dist.cdf(-k)
    print(f'±{k}σ: {prob*100:.2f}%')

# 이상치 탐지: 3σ 기준
mu, sigma = np.mean(data), np.std(data)
outliers = data[np.abs(data - mu) > 3 * sigma]
print(f'이상치 수: {len(outliers)}개')
```

### 정규분포와 머신러닝의 연결

정규분포는 여러 ML 알고리즘의 기반 가정이다.

|알고리즘|정규분포 가정|
|---|---|
|**선형 회귀**|잔차가 $N(0, \sigma^2)$를 따른다고 가정|
|**Gaussian Naive Bayes**|각 특성이 클래스 내에서 정규분포를 따른다|
|**Gaussian Process**|함수 자체를 정규분포의 확장인 가우시안 프로세스로 모델링|
|**LDA**|각 클래스의 특성이 정규분포, 공분산 행렬이 같다|
|**표준화 (Z-score)**|데이터를 $N(0,1)$로 변환해 스케일 통일|

```python
from sklearn.naive_bayes import GaussianNB
from sklearn.preprocessing import StandardScaler

gnb = GaussianNB()
gnb.fit(X_train, y_train)

# 학습된 각 클래스의 평균과 분산
print('클래스별 평균:')
print(gnb.theta_)    # 각 클래스의 특성별 평균
print('클래스별 분산:')
print(gnb.var_)      # 각 클래스의 특성별 분산

# StandardScaler: 데이터를 N(0,1)로 표준화
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_train)
print(f'표준화 후 평균: {X_scaled.mean(axis=0)[:3]}')
print(f'표준화 후 표준편차: {X_scaled.std(axis=0)[:3]}')
```

### 정규성 검정 (Normality Test)

데이터가 정규분포를 따르는지 통계적으로 검정한다. 많은 통계 방법이 정규성을 가정하기 때문에 분석 전에 확인하는 것이 중요하다.

|검정 방법|특징|적합한 경우|
|---|---|---|
|**Shapiro-Wilk**|가장 많이 사용. 검정력 높음|소표본 (n < 50)|
|**Anderson-Darling**|꼬리 부분에 더 민감|중간 표본|
|**Kolmogorov-Smirnov**|두 분포 비교에도 사용|대표본|
|**Q-Q Plot**|시각적 확인|표본 크기 무관|

```python
from scipy import stats
import matplotlib.pyplot as plt
import numpy as np

data = np.random.normal(0, 1, 100)  # 정규분포에서 추출

# Shapiro-Wilk 검정
stat, p_value = stats.shapiro(data)
print(f'Shapiro-Wilk: 통계량={stat:.4f}, p-value={p_value:.4f}')
print(f'정규성 {"만족" if p_value > 0.05 else "불만족"} (p > 0.05 이면 정규분포)')

# Q-Q Plot: 직선에 가까울수록 정규분포
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# 히스토그램 + 정규분포 곡선
axes[0].hist(data, bins=20, density=True, alpha=0.7, color='steelblue')
x = np.linspace(data.min(), data.max(), 100)
axes[0].plot(x, stats.norm.pdf(x, data.mean(), data.std()),
             'r-', linewidth=2, label='정규분포 PDF')
axes[0].set_title('히스토그램 vs 정규분포')
axes[0].legend()

# Q-Q Plot
stats.probplot(data, dist='norm', plot=axes[1])
axes[1].set_title('Q-Q Plot (직선에 가까울수록 정규분포)')

plt.tight_layout()
plt.show()
```

## 12. MCMC (Markov Chain Monte Carlo)

### 왜 MCMC가 필요한가

베이즈 정리에서 사후 확률을 계산하려면 분모인 정규화 상수 $P(E)$를 구해야 한다.

$$P(H|E) = \frac{P(H) \cdot P(E|H)}{P(E)}$$

$$P(E) = \int P(H) \cdot P(E|H) , dH$$

이 적분은 파라미터가 조금만 많아져도 **해석적으로 풀 수 없다**. 예를 들어 신경망의 수백만 개 파라미터에 대해 이 적분을 직접 계산하는 것은 불가능하다.

MCMC는 이 분포를 직접 계산하지 않고 **분포에서 샘플을 뽑는 방법**으로 우회한다.

```
목표: P(H|E)에서 샘플을 뽑고 싶다
문제: P(H|E)의 정규화 상수 P(E)를 모른다

해결: "정규화 상수를 모르더라도 사후 분포에서 샘플링하는 방법"
     = MCMC (Markov Chain Monte Carlo)
```

---

### 두 가지 핵심 아이디어의 결합

**Monte Carlo**: 무작위 샘플링으로 적분/기댓값을 근사하는 방법  
**Markov Chain**: 현재 상태가 이전 상태에만 의존하는 확률 과정

MCMC는 이 두 개념을 결합해서 **목표 분포로 수렴하는 마르코프 체인을 설계**하고, 그 체인에서 나온 샘플을 사후 분포의 샘플로 사용한다.

```
마르코프 체인의 핵심 성질:
  X₁ → X₂ → X₃ → X₄ → ...
  
  현재 상태 Xₜ는 이전 상태 Xₜ₋₁에만 의존
  (그 이전 X₁, X₂, ...는 상관없음)

  충분히 많은 스텝 후에 체인은 목표 분포로 수렴
  → 이후 샘플들을 목표 분포에서 온 것처럼 사용 가능
```

---

### 작동 원리: Metropolis-Hastings 알고리즘

가장 기본적인 MCMC 알고리즘이다. 핵심은 "새 제안을 받아들일지 말지"를 확률적으로 결정한다.

```
알고리즘:

1. 임의의 초기 파라미터 θ₀에서 시작

2. 현재 θₜ에서 새 후보 θ* 제안
   (예: θ* = θₜ + 정규분포 노이즈)

3. 수락 확률 계산:
              P(θ* | 데이터)   ← 사후 확률 (정규화 상수 없이 비율만 계산!)
   α = min(1, ──────────────)
              P(θₜ| 데이터)

4. α 확률로 θ* 수락 → θₜ₊₁ = θ*
   (1-α) 확률로 거부 → θₜ₊₁ = θₜ

5. 충분히 반복 → θₜ들이 사후 분포를 따르게 됨
```

**핵심 통찰**: 수락 확률에서 정규화 상수 $P(E)$가 분자와 분모에서 약분된다. 그래서 계산할 수 없는 정규화 상수 없이도 샘플링이 가능하다.

$$\alpha = \min\left(1, \frac{P(H^_|E)}{P(H_t|E)}\right) = \min\left(1, \frac{P(H^_) \cdot P(E|H^*)}{P(H_t) \cdot P(E|H_t)}\right)$$

```python
import numpy as np
import matplotlib.pyplot as plt

# ── 예시: 정규분포 평균 μ 추정 (Metropolis-Hastings) ──

# 관측 데이터 (평균=5인 정규분포에서 생성)
np.random.seed(42)
observed = np.random.normal(5, 1, 30)

def log_likelihood(mu, data, sigma=1):
    """로그우도: 데이터가 N(mu, sigma^2)에서 나올 로그 확률"""
    return -0.5 * np.sum(((data - mu) / sigma)**2)

def log_prior(mu, prior_mean=0, prior_std=10):
    """로그 사전 확률: μ ~ N(0, 10^2)"""
    return -0.5 * ((mu - prior_mean) / prior_std)**2

def log_posterior(mu, data):
    """로그 사후 확률 (정규화 상수 제외)"""
    return log_likelihood(mu, data) + log_prior(mu)

# Metropolis-Hastings 샘플링
n_samples = 10_000
proposal_std = 0.5   # 제안 분포의 표준편차 (튜닝 파라미터)

samples = np.zeros(n_samples)
samples[0] = 0.0   # 초기값

n_accepted = 0
for i in range(1, n_samples):
    current = samples[i-1]

    # 1. 새 후보 제안
    proposed = current + np.random.normal(0, proposal_std)

    # 2. 수락 확률 계산 (로그 스케일로 계산 후 exp)
    log_alpha = log_posterior(proposed, observed) - log_posterior(current, observed)
    alpha = np.exp(min(0, log_alpha))   # min(1, ratio)

    # 3. 수락/거부
    if np.random.rand() < alpha:
        samples[i] = proposed
        n_accepted += 1
    else:
        samples[i] = current

print(f'수락률: {n_accepted / n_samples:.2%}')  # 20~50%가 적정
print(f'추정 평균: {samples[2000:].mean():.3f}')  # Burn-in 후 평균
print(f'실제 평균: 5.000')

# 시각화
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# Trace plot: 체인이 수렴했는지 확인
axes[0].plot(samples, alpha=0.5, linewidth=0.3)
axes[0].axvline(x=2000, color='red', linestyle='--', label='Burn-in 경계')
axes[0].set_title('Trace Plot (수렴 확인)')
axes[0].set_xlabel('MCMC 스텝')
axes[0].legend()

# Burn-in 제거 후 사후 분포
burned_samples = samples[2000:]
axes[1].hist(burned_samples, bins=50, density=True, alpha=0.7, color='steelblue')
axes[1].axvline(x=burned_samples.mean(), color='red', linewidth=2, label=f'추정 평균={burned_samples.mean():.2f}')
axes[1].axvline(x=5, color='green', linewidth=2, linestyle='--', label='실제 평균=5.0')
axes[1].set_title('사후 분포 (Posterior)')
axes[1].legend()

# 자기상관: 샘플 간 독립성 확인
from statsmodels.graphics.tsaplots import plot_acf
plot_acf(burned_samples, lags=30, ax=axes[2])
axes[2].set_title('자기상관 (낮을수록 좋음)')

plt.tight_layout()
plt.show()
```

### Burn-in과 Thinning

MCMC에서 초기 샘플은 시작점에 의존적이라 신뢰하기 어렵다. 이를 처리하는 두 가지 기법이 있다.

**Burn-in (번인)**: 초기 수렴 전 샘플을 버린다.

```
체인이 수렴하기 전 구간을 "Burn-in period"라 하고
이 구간의 샘플은 분석에서 제외한다.

규칙: 전체 샘플의 10~50%를 버림 (trace plot으로 수렴 확인)
```

**Thinning (씨닝)**: 연속된 샘플 간 자기상관을 줄이기 위해 일정 간격으로 샘플을 추출한다.

```
자기상관이 높다 = 연속 샘플들이 비슷하다 = 사실상 독립 샘플이 적다
→ 10개 중 1개씩만 사용 (thinning=10)

주의: 최근에는 thinning이 항상 좋은 것은 아니라는 연구도 있음
     자기상관이 높아도 많은 샘플을 쓰는 것이 더 나을 수 있음
```

```python
# Burn-in 제거 + Thinning
burn_in = 2000
thinning = 5

final_samples = samples[burn_in::thinning]
print(f'최종 샘플 수: {len(final_samples)}개')
print(f'95% 신뢰구간: [{np.percentile(final_samples, 2.5):.2f}, {np.percentile(final_samples, 97.5):.2f}]')
```

### Gibbs Sampling — 다변수 MCMC

Metropolis-Hastings의 변형으로, **조건부 분포를 알 때** 더 효율적이다. 여러 파라미터를 한 번에 제안하지 않고 **하나씩 번갈아 업데이트**한다.

$$\theta_1^{(t+1)} \sim P(\theta_1 | \theta_2^{(t)}, \theta_3^{(t)}, \ldots)$$ $$\theta_2^{(t+1)} \sim P(\theta_2 | \theta_1^{(t+1)}, \theta_3^{(t)}, \ldots)$$ $$\vdots$$

```
장점: 수락/거부 단계가 없음 (수락률 100%)
단점: 각 파라미터의 조건부 분포를 알아야 함
     파라미터 간 상관이 높으면 수렴이 느림
```

```python
import numpy as np

# Gibbs Sampling: 이변량 정규분포 N([0,0], [[1, ρ], [ρ, 1]])
rho = 0.8   # 두 변수 간 상관계수
n_samples = 5000

samples_x = np.zeros(n_samples)
samples_y = np.zeros(n_samples)
samples_x[0], samples_y[0] = 0, 0

for i in range(1, n_samples):
    # X | Y ~ N(ρy, 1-ρ²)
    mu_x = rho * samples_y[i-1]
    samples_x[i] = np.random.normal(mu_x, np.sqrt(1 - rho**2))

    # Y | X ~ N(ρx, 1-ρ²)
    mu_y = rho * samples_x[i]
    samples_y[i] = np.random.normal(mu_y, np.sqrt(1 - rho**2))

print(f'샘플 상관계수: {np.corrcoef(samples_x, samples_y)[0,1]:.3f}')
print(f'실제 상관계수: {rho}')
```

### MCMC의 종류와 발전

|알고리즘|특징|사용 시기|
|---|---|---|
|**Metropolis-Hastings**|가장 기본. 제안 분포 선택 필요|저차원, 이해 목적|
|**Gibbs Sampling**|조건부 분포 활용. 수락률 100%|조건부 분포를 알 때|
|**HMC (Hamiltonian MC)**|물리 시뮬레이션으로 효율적 탐색. 자기상관 낮음|고차원, 복잡한 분포|
|**NUTS (No-U-Turn Sampler)**|HMC의 자동화. 스텝 수 자동 결정|Stan, PyMC 기본 알고리즘|
|**SGLD (Stochastic Gradient LD)**|미니배치로 경사도 계산|딥러닝에서의 베이즈 추론|

## 13. EM 알고리즘 (Expectation-Maximization)

### 왜 EM이 필요한가

MLE는 "관측 데이터가 모두 있을 때" 파라미터를 추정한다. 하지만 실제로는 **데이터의 일부가 숨겨져 있거나(잠재 변수)** 결측값이 있는 경우가 많다.

```
문제 상황:
  시험 점수 데이터가 있는데, 학생이 어느 그룹(우수/보통/미흡)에 속하는지는 모름
  → 그룹 레이블 = 잠재 변수 (Latent Variable)
  → 그룹을 모르니 그룹별 파라미터도 모름
  → 파라미터를 모르니 그룹도 알 수 없음 → 닭과 달걀 문제

  또는: 결측값이 있는 데이터에서 분포 파라미터 추정
  또는: 혼합 분포(Mixture Model)에서 각 성분 분리
```

EM 알고리즘은 이 닭과 달걀 문제를 **번갈아 추정하는 방식**으로 해결한다.

---

### EM의 핵심 원리

잠재 변수를 $Z$, 관측 데이터를 $X$, 파라미터를 $\theta$라 하면, 완전 로그우도는 다음과 같다.

$$\log L(\theta; X, Z) = \log P(X, Z | \theta)$$

$Z$를 모르므로 직접 최대화할 수 없다. 대신 $Z$의 **기댓값**으로 대체한다.

$$\text{E-step}: \quad Q(\theta | \theta^{(t)}) = E_{Z|X,\theta^{(t)}}[\log P(X, Z | \theta)]$$

$$\text{M-step}: \quad \theta^{(t+1)} = \arg\max_\theta Q(\theta | \theta^{(t)})$$

```
알고리즘 흐름:

1. 파라미터 θ를 임의로 초기화

2. E-step (Expectation):
   현재 θ로 잠재 변수 Z의 기댓값(확률) 계산
   → "지금 θ가 맞다면, 각 데이터가 어디 속할까?"

3. M-step (Maximization):
   E-step에서 구한 Z의 기댓값을 고정하고 θ를 최대화
   → "이 소속 확률이 맞다면, 최적 θ는?"

4. 수렴할 때까지 2~3 반복

핵심: 매 반복마다 로그우도가 단조증가함이 수학적으로 보장됨
      (감소하는 일이 없음 → 안정적으로 극값에 수렴)
```

---

### 가장 직관적인 예시: GMM (Gaussian Mixture Model)

데이터가 여러 개의 정규분포가 섞인 혼합 분포에서 왔다고 가정하고, 각 성분의 파라미터와 데이터의 소속을 동시에 추정한다.

```
관측: 키 데이터 [155, 158, 170, 173, 185, 188, ...]
가정: 두 그룹의 혼합 (예: 여성 그룹, 남성 그룹)
잠재: 각 데이터가 어느 그룹에 속하는지 모름

→ EM으로 각 그룹의 (평균, 분산)과 소속 확률을 동시에 추정
```

**E-step**: 현재 $(\mu_1, \sigma_1, \mu_2, \sigma_2, \pi)$로 각 데이터가 각 그룹에 속할 **책임(responsibility)** $r_{ik}$ 계산

$$r_{ik} = \frac{\pi_k \cdot N(x_i | \mu_k, \sigma_k^2)}{\sum_j \pi_j \cdot N(x_i | \mu_j, \sigma_j^2)}$$

**M-step**: $r_{ik}$를 이용해 파라미터 업데이트

$$\mu_k^{(t+1)} = \frac{\sum_i r_{ik} x_i}{\sum_i r_{ik}}, \quad \sigma_k^{2(t+1)} = \frac{\sum_i r_{ik}(x_i - \mu_k)^2}{\sum_i r_{ik}}, \quad \pi_k^{(t+1)} = \frac{\sum_i r_{ik}}{N}$$

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# ── GMM 직접 구현 (2-component) ──────────────────────
np.random.seed(42)

# 두 정규분포가 혼합된 데이터 생성
data = np.concatenate([
    np.random.normal(160, 5, 100),   # 그룹 1 (평균 160)
    np.random.normal(175, 6, 150)    # 그룹 2 (평균 175)
])
np.random.shuffle(data)
N = len(data)
K = 2   # 그룹 수

# 파라미터 초기화
np.random.seed(0)
mu    = np.array([data.min(), data.max()])           # 극단값으로 초기화
sigma = np.array([data.std(), data.std()])
pi    = np.array([0.5, 0.5])                         # 동등한 혼합 비율

log_likelihoods = []

for iteration in range(100):
    # ── E-step: 각 데이터의 그룹 소속 확률(책임) 계산 ──
    r = np.zeros((N, K))
    for k in range(K):
        r[:, k] = pi[k] * stats.norm.pdf(data, mu[k], sigma[k])

    # 정규화 (행의 합 = 1)
    r_sum = r.sum(axis=1, keepdims=True)
    r = r / r_sum

    # 로그우도 계산 (수렴 확인용)
    log_lik = np.sum(np.log(r_sum))
    log_likelihoods.append(log_lik)

    # ── M-step: 책임 r로 파라미터 업데이트 ────────────
    N_k = r.sum(axis=0)   # 각 그룹의 유효 샘플 수

    mu    = (r * data[:, None]).sum(axis=0) / N_k
    sigma = np.sqrt((r * (data[:, None] - mu)**2).sum(axis=0) / N_k)
    pi    = N_k / N

    # 수렴 확인
    if iteration > 0 and abs(log_likelihoods[-1] - log_likelihoods[-2]) < 1e-6:
        print(f'수렴 (반복 {iteration}회)')
        break

print(f'그룹 1: 평균={mu[0]:.1f}, 표준편차={sigma[0]:.1f}, 비율={pi[0]:.2f}')
print(f'그룹 2: 평균={mu[1]:.1f}, 표준편차={sigma[1]:.1f}, 비율={pi[1]:.2f}')
print(f'실제값: 그룹1=(160, 5, 0.40), 그룹2=(175, 6, 0.60)')

# ── 결과 시각화 ────────────────────────────────────────
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 데이터 히스토그램 + 추정된 혼합 분포
x_range = np.linspace(data.min() - 5, data.max() + 5, 300)
axes[0].hist(data, bins=30, density=True, alpha=0.5, color='gray', label='관측 데이터')
for k in range(K):
    component = pi[k] * stats.norm.pdf(x_range, mu[k], sigma[k])
    axes[0].plot(x_range, component, linewidth=2, label=f'그룹 {k+1}: μ={mu[k]:.1f}')
total = sum(pi[k] * stats.norm.pdf(x_range, mu[k], sigma[k]) for k in range(K))
axes[0].plot(x_range, total, 'k--', linewidth=2, label='혼합 분포')
axes[0].set_title('GMM 추정 결과')
axes[0].legend(fontsize=8)

# 로그우도 수렴 곡선
axes[1].plot(log_likelihoods, 'b-')
axes[1].set_title('로그우도 수렴 (단조증가 보장)')
axes[1].set_xlabel('반복 횟수')
axes[1].set_ylabel('로그우도')

# 각 데이터의 그룹 소속 확률
soft_assignments = r[:, 1]   # 그룹 2에 속할 확률
scatter = axes[2].scatter(data, np.zeros(N), c=soft_assignments,
                           cmap='RdBu', alpha=0.5, s=10)
plt.colorbar(scatter, ax=axes[2], label='그룹 2 소속 확률')
axes[2].set_title('Soft Assignment (붉을수록 그룹 2)')
axes[2].set_yticks([])

plt.tight_layout()
plt.show()
```

```python
proba  = gmm.predict_proba(data.reshape(-1, 1))     # Soft assignment
log_lik = gmm.score(data.reshape(-1, 1))            # 로그우도
print(f'로그우도: {log_lik:.4f}')

# 최적 성분 수 선택 (BIC 기준)
bic_scores = []
for k in range(1, 8):
    gmm_k = GaussianMixture(n_components=k, n_init=5, random_state=42)
    gmm_k.fit(data.reshape(-1, 1))
    bic_scores.append(gmm_k.bic(data.reshape(-1, 1)))

optimal_k = np.argmin(bic_scores) + 1
print(f'BIC 기준 최적 성분 수: {optimal_k}')
```

### EM 알고리즘의 응용 분야

EM은 GMM에만 쓰이는 것이 아니라 **잠재 변수가 있는 모든 모델**에 적용된다.

|모델|잠재 변수|응용|
|---|---|---|
|**GMM**|데이터의 군집 소속|비지도 군집화, 밀도 추정|
|**HMM** (Hidden Markov Model)|숨겨진 상태(state)|음성 인식, 시계열|
|**LDA** (Latent Dirichlet Allocation)|문서의 토픽|토픽 모델링|
|**결측값 처리**|결측 데이터|불완전 데이터에서 MLE|
|**Factor Analysis**|잠재 요인|차원 축소|
|**k-means**|군집 레이블|k-means를 EM의 특수 경우로 볼 수 있음|

k-means와의 관계가 특히 흥미롭다. k-means는 EM의 **Hard assignment 버전**이다. GMM(EM)은 각 데이터가 여러 그룹에 확률적으로 속하지만(Soft), k-means는 가장 가까운 하나의 중심에만 배정한다(Hard).

```
GMM (EM, Soft):  각 데이터 → 그룹 1에 70%, 그룹 2에 30%
k-means (Hard):  각 데이터 → 그룹 1에 100% (가장 가까운 곳)
```

### EM vs MLE vs MCMC 세 가지 비교

|구분|MLE|EM|MCMC (Bayesian)|
|---|---|---|---|
|**적용 조건**|모든 데이터 관측|잠재 변수 존재|Prior 설정 가능|
|**최적화 방식**|직접 로그우도 최대화|E/M 반복|사후 분포 샘플링|
|**결과**|점 추정|점 추정 (+ 소속 확률)|분포 (불확실성 포함)|
|**수렴 보장**|국소 최적해 가능|단조증가 (로컬 최적)|충분한 반복 시 전역 분포|
|**계산 비용**|낮음|중간|높음|
|**대표 모델**|LogisticRegression|GMM, HMM, LDA|베이즈 신경망|

## 13. 전체 흐름 정리

```
데이터
   ↓
확률 모델 선택 (분포를 아는가?)
   ├─ 안다  → Parametric
   └─ 모른다 → Nonparametric → KDE/EDF
   ↓
파라미터 추정 방법 선택
   ├─ MLE:  점 추정, 빠름 (모든 변수 관측)
   │         → LogisticRegression
   │
   ├─ EM:   잠재 변수 존재 시 E/M 반복
   │         → GMM, HMM, LDA
   │         E-step: 잠재 변수 기댓값 계산
   │         M-step: 파라미터 최대화
   │
   └─ Bayesian (MCMC): 분포 추정, 불확실성 포함
         → Metropolis-Hastings, Gibbs, NUTS (PyMC)
   ↓
로지스틱 회귀 (분류)
   선형 결합 → Odds → Logit → Sigmoid → 확률 (0~1)
   ↓
MLE로 학습 (log-likelihood = Cross-Entropy 최소화)
   ↓
규제 적용 (Penalty)
   L1(Lasso): 변수 선택 / L2(Ridge): 계수 축소 / ElasticNet
   ↓
Solver 선택
   소규모: lbfgs, liblinear / 대규모: sag, saga
   ↓
모델 평가 (Accuracy, AUC, F1, Calibration)
```
