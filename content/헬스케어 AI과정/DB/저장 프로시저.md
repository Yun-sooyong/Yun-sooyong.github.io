# 데이터베이스 서비스 및 SQL 

## 1. SQL Command (명령어 체계)

SQL은 목적에 따라 크게 5가지 범주로 나뉩니다.

|범주|설명|주요 명령어|
|---|---|---|
|**DDL** (Data Definition Language)|데이터 구조(스키마)를 정의, 수정, 삭제|`CREATE`, `DROP`, `ALTER`, `TRUNCATE`|
|**DML** (Data Manipulation Language)|데이터를 조작(삽입, 수정, 삭제)|`INSERT`, `UPDATE`, `DELETE`|
|**DQL** (Data Query Language)|데이터를 조회|`SELECT`|
|**DCL** (Data Control Language)|권한 부여 및 회수|`GRANT`, `REVOKE`|
|**TCL** (Transaction Control Language)|트랜잭션 제어 (논리적 단위 완료/취소)|`COMMIT`, `ROLLBACK`, `SAVE POINT`|

> **💡 보충 설명:**
> 
> - **TRUNCATE vs DELETE**: `DELETE`는 로그를 남기며 행 단위로 삭제하지만, `TRUNCATE`는 로그를 남기지 않고 테이블 공간 자체를 초기화하여 속도가 빠릅니다.
>     
> - **SAVE POINT**: 트랜잭션 내에서 특정 지점을 설정하여, `ROLLBACK` 시 전체가 아닌 해당 지점까지만 되돌릴 수 있게 합니다.
>     

## 2. Select Component (조회문 구성 요소)

데이터를 조회하는 `SELECT` 문은 정해진 순서와 규칙에 따라 작성해야 합니다.

1. **SELECT (필수)**: 가져올 컬럼 지정
    
2. **Expression (필수)**: 수식이나 가공된 데이터 표현
    
3. **FROM**: 대상 테이블 지정
    
4. **WHERE (선택)**: 행(Row)을 필터링하기 위한 조건
    
5. **GROUP BY (선택)**: 특정 컬럼 기준 데이터 그룹화
    
6. **HAVING (선택)**: 그룹화된 결과에 대한 필터링 조건
    
7. **ORDER BY (선택)**: 결과 정렬 (ASC/DESC)
    
8. **LIMIT (선택)**: 반환할 행의 개수 제한
    

> **💡 SQL 실행 순서 (보충):** 실제 DB 엔진은 `FROM` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY` → `LIMIT` 순으로 실행합니다. 이 흐름을 이해하면 복잡한 쿼리 작성 시 오류를 줄일 수 있습니다.

## 3. Stored Procedure (저장 프로시저)

스토어드 프로시저는 일련의 SQL 문을 하나로 묶어 DB 서버에 저장하고 필요할 때마다 호출하여 사용하는 객체입니다.

### 🔹 주요 특징 및 구성

- **기본 구조**: `CREATE`로 생성하고 `CALL`로 실행합니다.
    
- **매개변수**: `IN` (입력값), `OUT` (출력값), `INOUT` (입출력 겸용) 타입을 지원합니다.
    
- **제어문**: `IF`, `LOOP` 등을 사용하여 절차적인 로직을 구현할 수 있습니다.
    
- **변수 및 타입**: 내부에서 `DECLARE`를 사용하여 변수를 선언하고 데이터 타입을 지정합니다.
    
- **예외 처리(Handler)**: `SQLEXCEPTION` 등 오류 발생 시 대응 로직을 설정할 수 있습니다.
    
- **동적 SQL**: 상황에 따라 SQL 문을 동적으로 생성하여 실행 가능합니다.
    

### 🔹 예시

```SQL
CREATE PROCEDURE sp_process_data (
    IN p_id INT, 
    OUT p_status VARCHAR(20)
)
BEGIN
    DECLARE v_count INT;
    -- 예외 발생 시 트랜잭션을 롤백하거나 종료하는 핸들러
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        -- 예외 처리 로직
    END;

    UPDATE user_data SET status = 'active' WHERE id = p_id;
    COMMIT;
END;
```

## 4. Stored Program (저장 프로그램 종류)

데이터베이스 내부에서 로직을 수행하는 프로그램 객체들은 다음과 같습니다.

- **Stored Procedure**: 복잡한 로직을 처리하며 여러 값을 반환할 수 있습니다.
    
- **Stored Function**: 하나의 결과값을 반드시 반환(`RETURN`)하며, SQL 문 안에서 일반 함수처럼 사용됩니다.
    
- **Cursor (커서)**: 쿼리 결과로 반환된 여러 행(Row)을 한 줄씩 처리하기 위한 메모리 공간이자 포인터입니다.
    
- **Trigger (트리거)**: 테이블에 `INSERT`, `UPDATE`, `DELETE` 등 특정 이벤트가 발생할 때 자동으로 실행되는 프로그램입니다.
    

> **💡 프로시저 vs 함수의 차이 (보충):**
> 
> - **프로시저**: `CALL` 문으로 실행, 리턴값이 없을 수 있음, `OUT` 변수로 다수 값 반환 가능.
>     
> - **함수**: `SELECT` 문 내에서 사용, 반드시 하나의 스칼라 값을 `RETURN` 해야 함.
>
