# 자바스크립트
  
## 비동기 처리  
  
자바스크립트는 비동기 처리를 지원한다.    
대표적인 흐름은 다음과 같다.  
  
- `Callback`  
- `Promise`  
- `async / await`  
  
### Promise → async / await  
기존에는 비동기 작업을 `Promise`로 처리했다.  
  
```js  
fetchData()  
  .then((result) => {  
    console.log(result);  
  })  
  .catch((error) => {  
    console.error(error);  
  });
```

이를 더 읽기 쉽게 만든 문법이 `async / await`이다.

```js
async function run() {  
  try {  
    const result = await fetchData();  
    console.log(result);  
  } catch (error) {  
    console.error(error);  
  }  
}
```

## 자바스크립트와 스레드

자바스크립트는 **단일 스레드(Single Thread)** 를 사용한다.

즉, 한 번에 하나의 작업만 직접 실행할 수 있다.  
하지만 비동기 작업은 **큐(Queue)** 를 활용해 처리한다.

### 동작 방식

- 작업을 순서대로 큐에 넣는다.
- 현재 실행 중인 연산이 끝나거나 비는 시점에
- 대기 중인 다른 작업을 조금씩 처리한다.

이 때문에 자바스크립트는 단일 스레드이지만  
비동기 작업을 효율적으로 다룰 수 있다.

---

## 자바스크립트의 특징

### 1. 단일 스레드 프로그래밍

- 한 번에 하나의 작업을 처리한다.
- 동시 실행처럼 보이는 것은 이벤트 루프와 큐 덕분이다.

### 2. UI와 상태의 분리

- 웹 페이지의 구성은 HTML/CSS가 담당한다.
- 자바스크립트는 동작, 상태 변화, 이벤트 처리를 담당한다.

### 3 비동기 실행

- 오래 걸리는 작업을 기다리는 동안 프로그램 전체가 멈추지 않도록 처리한다.

### 4 Blocking vs Non-Blocking

- **Blocking**: 작업이 끝날 때까지 다음 작업이 멈춤
- **Non-Blocking**: 작업 완료를 기다리지 않고 다음 작업 진행 가능

## Callback Function

콜백 함수는 **다른 함수에 전달되는 함수** 이다.

주로 다음 상황에서 사용된다.

- 이벤트 핸들러(Event Handler)
- 리스너(Listener)
- 비동기 처리
```js
button.addEventListener("click", function () {  
  console.log("클릭됨");  
});
```

비동기 처리 방식은 보통 다음 순서로 발전했다.

- 콜백 함수
- Promise
- async / await

## 변수와 타입

자바스크립트는 기본적으로 **느슨한 타입 언어(Dynamically Typed Language)** 이다.

즉, 변수 선언 시 타입을 명시하지 않아도 된다.

```js
let value = 10;  
value = "hello";
```

### 자료형 분류

#### Primitive Type

- `string`
- `number`
- `boolean`
- `null`
- `undefined`
- `symbol`
- `bigint`

#### Reference Type

- `object`
- `array`
- `function`
- `map`

## 연산자

자바스크립트의 연산자는 파이썬과 비슷한 부분이 많다.

예:
- 산술 연산자: `+`, `-`, `*`, `/`, `%`
- 비교 연산자: `==`, `===`, `!=`, `!==`, `>`, `<`
- 논리 연산자: `&&`, `||`, `!`

### 주의

자바스크립트에서는 `==`보다 `===` 사용이 권장된다.

- `==` : 값만 비교
- `===` : 값과 타입까지 비교
- 
```js
1 == "1"   // true  
1 === "1"  // false
```

## 제어문

자바스크립트의 대표적인 제어문은 다음과 같다.

- `for`
- `for...in`
- `forEach`
- `while`
- `do...while`
- `if / else if / else`
- `switch / case`

### 예시
```js
for (let i = 0; i < 3; i++) {  
  console.log(i);  
}

if (score >= 90) {  
  console.log("A");  
} else if (score >= 80) {  
  console.log("B");  
} else {  
  console.log("C");  
}
```

## 함수

자바스크립트에서 함수는 **1급 객체(First-Class Object)** 이다.

즉, 함수는 다음이 가능하다.
- 변수에 저장
- 다른 함수의 인자로 전달
- 함수의 반환값으로 사용

### 익명 함수

이름 없이 정의하는 함수이다.
```js
const hello = function () {  
  console.log("hello");  
};
```

### 화살표 함수
```js
const hello = () => {  
  console.log("hello");  
};
```

### 비동기 함수의 발전

- 콜백 함수
- Promise
- async / await

## 클래스와 객체

자바스크립트에서는 객체를 자주 사용하며  
딕셔너리(Dictionary)처럼 키-값 형태로 다룰 수 있다.
```js
const user = {  
  name: "Tom",  
  age: 20  
};
```

클래스 문법도 지원한다.

```js
class User {  
  constructor(name) {  
    this.name = name;  
  }  
  
  sayHello() {  
    console.log(`Hello, ${this.name}`);  
  }  
}
```
