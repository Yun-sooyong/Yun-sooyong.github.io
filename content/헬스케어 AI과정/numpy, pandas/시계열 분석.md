# Statsmodels와 시계열 분석

`statsmodels`는 Python에서 통계 모델을 구현하는 핵심 라이브러리다.  
`scikit-learn`이 머신러닝 중심이라면, `statsmodels`는 **통계적 추론(계수의 유의성, 신뢰구간, 가설검정)** 까지 함께 제공한다.

---

## 1. 시계열 분석 모델 계보

모델들은 단계적으로 발전했다. 각 모델은 이전 모델의 한계를 극복하며 확장된다.

```
AR  →  MA  →  ARMA  →  ARIMA  →  SARIMA(X)
                                       ↓
                             다변량으로 확장
                                  VAR  →  VECM
```

### 단변량 모델

|모델|핵심|조건|특징|
|---|---|---|---|
|**AR(p)**|과거 자기 자신의 값으로 예측|정상 시계열|PACF 절단점 → p|
|**MA(q)**|과거 예측 오차로 예측|정상 시계열|ACF 절단점 → q|
|**ARMA(p,q)**|AR + MA 결합|정상 시계열|둘 다 활용|
|**ARIMA(p,d,q)**|차분으로 정상화 후 ARMA|비정상 가능|d번 차분 후 적용|
|**SARIMA(X)**|ARIMA + 계절성 + 외부 변수|비정상 가능|계절 패턴 명시적 처리|

#### ARIMA (AutoRegressive Integrated Moving Average)

$$ARIMA(p, d, q): \quad \phi(B)(1-B)^d y_t = \theta(B)\varepsilon_t$$

- 비정상 시계열을 **$d$번 차분해서 정상화**한 뒤 ARMA를 적용한다
- 추세(Trend) 변동이 있는 단변량 시계열에 가장 많이 쓰이는 기본 모델이다
- 계절성은 처리하지 못한다 → 계절성이 있으면 SARIMA로 확장 필요
- 조건: 단변량, 선형 추세 패턴, 계절성 없음

|파라미터|의미|결정 방법|
|---|---|---|
|$p$|AR 차수 — 과거 값 몇 기까지 참조|PACF 절단점|
|$d$|차분 횟수 — 정상화에 필요한 차분 수|ADF 검정 반복|
|$q$|MA 차수 — 과거 오차 몇 기까지 참조|ACF 절단점|

```python
from statsmodels.tsa.arima.model import ARIMA

# ARIMA(1,1,1): 1차 AR + 1회 차분 + 1차 MA
model = ARIMA(df['value'], order=(1, 1, 1))
result = model.fit()
print(result.summary())   # coef, p-value, AIC/BIC 확인

# 예측 + 신뢰구간
forecast_obj = result.get_forecast(steps=12)
pred_mean = forecast_obj.predicted_mean
pred_ci   = forecast_obj.conf_int()
```

#### SARIMA(X) (Seasonal ARIMA with eXogenous variables)

$$SARIMA(p,d,q)(P,D,Q)_s$$

$$\phi(B)\Phi(B^s)(1-B)^d(1-B^s)^D y_t = \theta(B)\Theta(B^s)\varepsilon_t + \beta X_t$$

- ARIMA에 **두 가지를 추가**한 확장 모델이다
    - **계절성(Seasonal)**: 월별, 분기별처럼 일정 주기($s$)로 반복되는 패턴을 명시적으로 모델링
    - **외부 변수(eXogenous, X)**: 예측 대상에 영향을 주는 외부 독립 변수를 추가로 포함 가능
- 상태공간 모델(State Space Model) 형태로 구현되어 수치 안정성이 높다
- 조건: 단변량 + 외부 변수 선택적 추가, 계절성 있는 경우

|파라미터|의미|
|---|---|
|$(p, d, q)$|비계절 AR, 차분, MA 차수 (단기 패턴)|
|$(P, D, Q)_s$|계절 AR, 차분, MA 차수 + 계절 주기 $s$|
|$X$ (외부 변수)|날씨, 공휴일, 프로모션 등 예측에 영향을 주는 외생 변수|

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX
import pandas as pd

# 외부 변수 없는 순수 SARIMA
model = SARIMAX(df['value'],
                order=(1, 1, 1),
                seasonal_order=(1, 1, 1, 12))   # s=12: 월별 연간 계절성
result = model.fit(disp=False)
print(result.summary())

# 외부 변수 포함 SARIMAX
# 예: 기온이 에너지 소비량 예측에 영향
exog_train = df[['temperature', 'holiday']]
exog_test  = future_df[['temperature', 'holiday']]

model_x = SARIMAX(df['value'],
                  exog=exog_train,
                  order=(1, 1, 1),
                  seasonal_order=(1, 1, 1, 12))
result_x = model_x.fit(disp=False)

# 예측 시 외부 변수도 함께 입력
forecast = result_x.forecast(steps=12, exog=exog_test)
```

### 다변량 모델

단변량 모델은 하나의 시계열만 분석하지만, **여러 시계열이 서로 영향을 줄 때**는 다변량 모델이 필요하다.

#### VAR (Vector AutoRegression)

$$\mathbf{y}_t = \mathbf{c} + \mathbf{A}_1 \mathbf{y}_{t-1} + \mathbf{A}_2 \mathbf{y}_{t-2} + \cdots + \mathbf{A}_p \mathbf{y}_{t-p} + \boldsymbol{\varepsilon}_t$$

- **모든 내생 변수가 서로 영향을 주고받는** 관계를 동시에 모델링한다
- AR 모델을 벡터로 확장한 개념이다
- 조건: **정상 시계열** 가정, 공적분 없음
- 예: GDP, 금리, 환율이 서로 영향을 주는 관계 분석

```python
from statsmodels.tsa.vector_ar.var_model import VAR

model = VAR(df[['gdp', 'rate', 'exchange']])
result = model.fit(maxlags=4, ic='aic')   # 최적 lag 자동 선택
print(result.summary())

# 예측
forecast = result.forecast(df.values[-result.k_ar:], steps=10)

# 충격반응함수 (Impulse Response Function)
# 한 변수에 충격이 왔을 때 다른 변수들이 어떻게 반응하는지
irf = result.irf(periods=20)
irf.plot(orth=False)
```

#### VECM (Vector Error Correction Model)

$$\Delta \mathbf{y}_t = \mathbf{\Pi} \mathbf{y}_{t-1} + \sum_{i=1}^{p-1} \mathbf{\Gamma}_i \Delta \mathbf{y}_{t-i} + \boldsymbol{\varepsilon}_t$$

- VAR의 확장으로, 변수들 사이에 **장기균형 관계(공적분)** 가 있을 때 사용한다
- 공적분이란 각 변수는 비정상이지만 선형결합은 정상인 경우다
- 단기 조정 속도와 장기 균형으로의 회귀를 동시에 모델링한다
- 예: 주가와 기업 가치는 장기적으로 균형을 유지 (단기는 이탈 가능)

```python
from statsmodels.tsa.vector_ar.vecm import VECM, coint_johansen

# 공적분 검정 (Johansen)
jo_result = coint_johansen(df[['price', 'value']], det_order=0, k_ar_diff=1)
print(jo_result.lr1)   # 검정 통계량
print(jo_result.cvt)   # 임계값

# VECM 적합
model = VECM(df[['price', 'value']], k_ar_diff=2, coint_rank=1)
result = model.fit()
print(result.summary())
```

### ARIMA vs SARIMA(X) vs VAR vs VECM 비교

|구분|ARIMA|SARIMA(X)|VAR|VECM|
|---|---|---|---|---|
|변수 수|단변량|단변량 (+외부 변수)|다변량|다변량|
|계절성 처리|불가|가능|불가|불가|
|외부 변수|불가|가능 (X)|내생 변수만|내생 변수만|
|정상성 조건|차분으로 처리|차분으로 처리|정상 시계열 가정|공적분 있을 때|
|장기균형|없음|없음|없음|있음|
|주요 용도|추세 변동 예측|계절성+외부충격|변수 간 상호작용|장기균형 분석|

## 2. summary()의 강력함

`model.summary()`는 단순히 결과를 보여주는 것을 넘어 모델의 **통계적 신뢰성을 전면 검증**하는 도구다.

```python
from statsmodels.tsa.arima.model import ARIMA

model = ARIMA(df['value'], order=(1, 1, 1))
result = model.fit()
print(result.summary())
```

출력되는 정보들:

### coef (계수)

각 파라미터($\phi_1$, $\theta_1$ 등)의 추정값이다.  
AR(1) 계수가 0.8이면 "전기 값의 80%가 현기 값에 반영된다"는 의미다.

### std err (표준 오차)

계수 추정의 **불확실성**을 나타낸다. 작을수록 계수 추정이 안정적이다.  
표본 크기가 클수록 표준 오차는 작아진다.

### t-stat (t 통계량)

$$t = \frac{\text{coef}}{\text{std err}}$$

계수가 0과 얼마나 다른지를 표준 오차 단위로 나타낸다.  
절댓값이 클수록 해당 파라미터가 통계적으로 유의미하다.

### p-value (유의확률)

해당 계수가 실제로 0일 때 현재와 같은 t값이 나올 확률이다.

- `p < 0.05`: 해당 파라미터가 유의미함 → 모델에 포함할 이유 있음
- `p ≥ 0.05`: 유의미하지 않음 → 해당 차수 제거 검토

### CI (신뢰구간, Confidence Interval)

계수의 95% 신뢰구간이다.  
`[0.3, 0.9]`처럼 0을 포함하지 않으면 유의미하다는 신호다.  
`[-0.1, 0.7]`처럼 0을 포함하면 해당 계수가 0일 가능성을 배제할 수 없다.

### R² (결정계수)

$$R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

모델이 데이터 변동의 몇 %를 설명하는지를 나타낸다.  
0 ~ 1 사이 값으로, 1에 가까울수록 설명력이 높다.  
시계열에서는 단순 회귀보다 낮게 나오는 경우가 많다.

### AIC / BIC (정보 기준)

$$AIC = 2k - 2\ln(L)$$

$$BIC = k\ln(n) - 2\ln(L)$$

- $k$: 파라미터 수, $n$: 표본 크기, $L$: 우도(likelihood)
- **작을수록 좋다** — 여러 모델을 비교할 때 사용
- AIC는 예측 성능, BIC는 모델 단순성을 더 중시한다
- BIC는 샘플 크기에 따른 패널티가 더 크므로 더 간결한 모델을 선호한다
- 단독으로 의미 있는 값이 아니라 **모델 간 상대 비교**에 사용한다

```python
# 여러 ARIMA 모델 AIC/BIC 비교
import itertools
import pandas as pd

p_range = range(0, 4)
q_range = range(0, 4)
results = []

for p, q in itertools.product(p_range, q_range):
    try:
        m = ARIMA(df['value'], order=(p, 1, q)).fit()
        results.append({'order': (p, 1, q), 'AIC': m.aic, 'BIC': m.bic})
    except:
        pass

compare_df = pd.DataFrame(results).sort_values('AIC')
print(compare_df.head(5))   # AIC 기준 상위 5개 모델
```

## 3. 예측 성능 평가 지표

모델이 학습한 뒤, **테스트 데이터에 대한 예측이 얼마나 정확한지** 측정하는 지표들이다.

### MAE (Mean Absolute Error, 평균 절대 오차)

$$MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$

예측 오차의 절댓값 평균이다.

- 단위가 원본 데이터와 같다 (해석이 직관적)
- 모든 오차를 동등하게 취급한다 (큰 오차에 덜 민감)
- 이상치의 영향이 MSE보다 작다

```python
from sklearn.metrics import mean_absolute_error
mae = mean_absolute_error(y_true, y_pred)
print(f'MAE: {mae:.2f}')
```

### MSE (Mean Squared Error, 평균 제곱 오차)

$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

오차를 제곱해서 평균을 낸다.

- 큰 오차에 **제곱으로 가중치**가 생겨 큰 실수를 더 크게 패널티 부여
- 단위가 원본 데이터의 제곱이라 직관적 해석이 어렵다
- 미분 가능하므로 손실함수로 자주 사용된다

```python
from sklearn.metrics import mean_squared_error
mse = mean_squared_error(y_true, y_pred)
print(f'MSE: {mse:.2f}')
```

### RMSE (Root Mean Squared Error, 평균 제곱근 오차)

$$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2} = \sqrt{MSE}$$

MSE에 제곱근을 씌워 단위를 원본과 맞춘다.

- MSE보다 해석이 쉽고 큰 오차에도 민감하다
- 가장 많이 사용되는 예측 지표 중 하나다
- 이상치가 있으면 값이 크게 올라간다

```python
import numpy as np
rmse = np.sqrt(mean_squared_error(y_true, y_pred))
print(f'RMSE: {rmse:.2f}')
```

### MAPE (Mean Absolute Percentage Error, 평균 절대 퍼센트 오차)

$$MAPE = \frac{100}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|$$

오차를 실제값 대비 **비율(%)**로 표현한다.

- **단위에 무관**하므로 서로 다른 스케일의 모델을 비교할 수 있다
- "예측이 평균 5% 빗나갔다"처럼 직관적으로 해석 가능
- 실제값이 0에 가까우면 분모가 0이 되는 문제가 있다

```python
from sklearn.metrics import mean_absolute_percentage_error
mape = mean_absolute_percentage_error(y_true, y_pred) * 100
print(f'MAPE: {mape:.2f}%')
```

### 지표 비교

|지표|단위|이상치 민감도|특징|사용 시기|
|---|---|---|---|---|
|**MAE**|원본과 동일|낮음|모든 오차 동등 처리|이상치가 많거나 직관적 해석이 필요할 때|
|**MSE**|원본²|높음|큰 오차에 강한 패널티|손실함수, 최적화 목적|
|**RMSE**|원본과 동일|높음|MSE의 직관적 버전|가장 일반적으로 사용|
|**MAPE**|%|중간|단위 무관, 비율 표현|서로 다른 스케일 비교|
|**R²**|없음 (0~1)|낮음|설명력 비율|모델 설명력 평가|

```python
# 전체 지표 한 번에 계산
import numpy as np
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

def evaluate_model(y_true, y_pred):
    mae  = mean_absolute_error(y_true, y_pred)
    mse  = mean_squared_error(y_true, y_pred)
    rmse = np.sqrt(mse)
    mape = np.mean(np.abs((y_true - y_pred) / y_true)) * 100
    r2   = r2_score(y_true, y_pred)

    print(f'MAE:  {mae:.4f}')
    print(f'MSE:  {mse:.4f}')
    print(f'RMSE: {rmse:.4f}')
    print(f'MAPE: {mape:.2f}%')
    print(f'R²:   {r2:.4f}')

evaluate_model(y_test, forecast)
```

## 4. ARIMA 모델 선택 흐름도

슬라이드의 흐름도를 단계별로 상세 설명한다.

```
원본 시계열
   ↓
① 정상성 확인 (ADF 검정)
   ├─ 정상 (p < 0.05)
   │      ↓
   │   d = 0
   └─ 비정상 (p ≥ 0.05)
          ↓
       d 결정: 차분
          ├─ 1차 차분 후 재검정
          ├─ 2차 차분 후 재검정
          └─ d = 정상화에 필요한 차분 횟수
   ↓
② ACF / PACF 분석
   ├─ PACF 절단점 → p 결정 (AR 차수)
   └─ ACF 절단점  → q 결정 (MA 차수)
   ↓
③ ARIMA 후보 생성
   p, d, q 조합으로 여러 모델 생성
   (예: ARIMA(0,1,1), ARIMA(1,1,0), ARIMA(1,1,1) ...)
   ↓
④ AIC / BIC 최소 모델 선택
   AIC 또는 BIC가 가장 낮은 모델 선택
   ↓
⑤ 잔차 검정
   - 잔차 ACF → 자기상관 없어야 함
   - Ljung-Box 검정 → p > 0.05
   - 잔차 정규성 검정
   └─ 통과 못 하면 ③으로 돌아가 재조정
   ↓
⑥ 예측 및 신뢰구간
```

## 5. 전체 분석 코드 예시

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.stattools import adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox
from sklearn.metrics import mean_absolute_error, mean_squared_error

# ── 0. 데이터 준비 ──────────────────────────────
df = pd.read_csv('timeseries.csv', parse_dates=['date'], index_col='date')
train = df[:'2023']
test  = df['2024':]

# ── 1. 정상성 확인 ──────────────────────────────
adf = adfuller(train['value'])
print(f'원본 p-value: {adf[1]:.4f}')

train['diff1'] = train['value'].diff(1)
adf_d = adfuller(train['diff1'].dropna())
print(f'차분 후 p-value: {adf_d[1]:.4f}')
d = 1 if adf_d[1] < 0.05 else 2

# ── 2. ACF/PACF 분석 ──────────────────────────
fig, axes = plt.subplots(2, 1, figsize=(10, 6))
plot_acf(train['diff1'].dropna(),  lags=20, ax=axes[0])
plot_pacf(train['diff1'].dropna(), lags=20, ax=axes[1])
plt.tight_layout(); plt.show()
# → ACF/PACF 보고 p, q 결정

# ── 3. 모델 비교 (AIC 기준) ────────────────────
import itertools
candidates = []
for p, q in itertools.product(range(4), range(4)):
    try:
        m = ARIMA(train['value'], order=(p, d, q)).fit()
        candidates.append({'order': (p, d, q), 'AIC': m.aic, 'BIC': m.bic})
    except:
        pass

best = pd.DataFrame(candidates).sort_values('AIC').iloc[0]
print(f'최적 모델: ARIMA{best["order"]}  AIC={best["AIC"]:.2f}')

# ── 4. 최적 모델 적합 ──────────────────────────
best_order = tuple(best['order'])
final_model = ARIMA(train['value'], order=best_order).fit()
print(final_model.summary())

# ── 5. 잔차 진단 ───────────────────────────────
residuals = final_model.resid
lb = acorr_ljungbox(residuals, lags=10, return_df=True)
print(f'Ljung-Box p-value 최솟값: {lb["lb_pvalue"].min():.4f}')
# p > 0.05 → 잔차에 자기상관 없음 → OK

# ── 6. 예측 및 평가 ────────────────────────────
forecast = final_model.forecast(steps=len(test))
mae  = mean_absolute_error(test['value'], forecast)
rmse = np.sqrt(mean_squared_error(test['value'], forecast))
mape = np.mean(np.abs((test['value'] - forecast) / test['value'])) * 100

print(f'MAE:  {mae:.2f}')
print(f'RMSE: {rmse:.2f}')
print(f'MAPE: {mape:.2f}%')

# ── 7. 시각화 ──────────────────────────────────
forecast_obj = final_model.get_forecast(steps=len(test))
ci = forecast_obj.conf_int()

fig, ax = plt.subplots(figsize=(12, 5))
train['value'].plot(ax=ax, label='학습 데이터')
test['value'].plot(ax=ax, label='실제값', color='green')
forecast.plot(ax=ax, label='예측값', color='red')
ax.fill_between(ci.index, ci.iloc[:, 0], ci.iloc[:, 1],
                alpha=0.2, color='red', label='95% 신뢰구간')
ax.legend()
ax.set_title(f'ARIMA{best_order} 예측 결과  (RMSE={rmse:.2f}, MAPE={mape:.1f}%)')
plt.show()
```

## 6. Statsmodels 주요 시계열 모듈 정리

```
statsmodels
   ├─ tsa (time series analysis)
   │   ├─ stattools          : ADF 검정, ACF/PACF 수치값
   │   ├─ arima.model        : ARIMA
   │   ├─ statespace.sarimax : SARIMA, SARIMAX (외부 변수 포함)
   │   ├─ vector_ar          : VAR, VECM
   │   ├─ seasonal           : 시계열 분해 (seasonal_decompose)
   │   └─ holtwinters        : 지수 평활 모델 (ETS)
   │
   └─ graphics
       └─ tsaplots            : plot_acf, plot_pacf
```

# 지수 평활 모델 (Holt-Winters ETS) — 추세 + 계절성 처리

model = ExponentialSmoothing(

)
result = model.fit()
