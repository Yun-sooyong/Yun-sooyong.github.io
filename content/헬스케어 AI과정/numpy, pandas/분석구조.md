# Data Cleansing & Wrangling (분석구조)

**Garbage In, Garbage Out.**  
아무리 좋은 머신러닝 모델을 써도 입력 데이터가 나쁘면 결과도 나쁘다.  
데이터 전처리는 분석 시간의 70~80%를 차지할 만큼 중요하다.

---

## 1. 나쁜 데이터의 유형

|유형|설명|예시|
|---|---|---|
|**개수 문제**|데이터가 너무 적거나 클래스 불균형|정상 9900건 / 사기 100건|
|**균형 문제**|클래스 간 데이터 수 불균형|Imbalanced data|
|**잡음 (Noise)**|측정 오류, 무작위 오차|센서 오작동 값|
|**이상치 (Outlier)**|정상 범위를 크게 벗어난 값|나이 필드에 999|
|**에러**|입력 오류, 시스템 오류|날짜 필드에 문자열|
|**정규화 문제**|같은 정보가 다른 형식으로 존재|`"서울"`, `"Seoul"`, `"서울시"`|

---

## 2. 전처리의 4단계 흐름

```
1. Cleaning   →   2. Structuring   →   3. Feature Engineering   →   4. Optimization
  (정제)              (구조화)               (특성 공학)                  (최적화)
데이터 오류 제거    분석 가능한 형태로      정보 강화                    성능/속도/안전성
오타, 중복,         merge, join, concat    파생변수 생성                타입 변환
단위불일치          split, melt, pivot     패턴 추출                    파일 저장
                                           도메인 지식 반영
                                           PCA
```

## 3. 1단계: Cleaning (정제)

오타, 중복, 단위 불일치 등 **데이터 자체의 오류를 제거**하는 단계다.

```python
import pandas as pd

# 기본 상태 확인
df.info()
df.describe()
df.isnull().sum()     # 열별 결측값 개수
df.duplicated().sum() # 중복 행 개수

# 중복 제거
df.drop_duplicates()
df.drop_duplicates(subset=['name', 'date'])  # 특정 열 기준

# 단위 불일치 수정
df['price'] = df['price'].str.replace(',', '').astype(float)
df['city'] = df['city'].str.strip().str.replace('서울시', '서울')
```

## 4. 결측치 처리

### 결측치 확인

```python
df.isnull()           # 각 셀의 결측 여부 (True/False)
df.isnull().sum()     # 열별 결측치 개수
df.notnull()          # 결측치가 아닌 셀
df.isnull().mean()    # 열별 결측치 비율
```

### 결측치 제거

```python
df.dropna()                          # 결측치 있는 행 전체 제거
df.dropna(subset=['score'])          # 특정 열에 결측치 있는 행만 제거
df.dropna(how='all')                 # 모든 열이 결측치인 행만 제거
df.dropna(thresh=3)                  # 유효값이 3개 미만인 행 제거
```

### 결측치 보간 (Imputation)

```python
# 고정값으로 채우기
df.fillna(0)
df.fillna({'score': 0, 'name': 'unknown'})

# 통계값으로 채우기
df['score'].fillna(df['score'].mean())
df['score'].fillna(df['score'].median())

# 앞/뒤 값으로 채우기 (시계열에서 유용)
df['value'].ffill()   # 앞 값으로 (forward fill)
df['value'].bfill()   # 뒤 값으로 (backward fill)

# 보간법으로 채우기
df['value'].interpolate(method='linear')
df['value'].interpolate(method='spline', order=3)

# replace: 특정 값을 결측치로 바꾼 뒤 처리
df.replace(999, pd.NA)
df.replace({'gender': {'M': '남', 'F': '여'}})
```

결측치를 무조건 제거하기보다 **왜 결측값이 생겼는지** 파악하는 것이 먼저다.  
완전 무작위(MCAR), 무작위(MAR), 비무작위(MNAR) 세 가지 유형에 따라 처리 방식이 달라진다.

## 5. 이상치 탐지 및 처리

### 이상치 확인 방법

```python
import matplotlib.pyplot as plt

# 박스플롯으로 시각적 확인
df.boxplot(column='score')
plt.show()

# 표준편차 2배 기준 (정규분포 가정 시 95% 범위 밖)
mean = df['score'].mean()
std  = df['score'].std()
outliers = df[(df['score'] < mean - 2*std) | (df['score'] > mean + 2*std)]

# IQR 기준 (분포 무관, 더 일반적)
Q1  = df['score'].quantile(0.25)
Q3  = df['score'].quantile(0.75)
IQR = Q3 - Q1
outliers = df[(df['score'] < Q1 - 1.5*IQR) | (df['score'] > Q3 + 1.5*IQR)]
```

|방법|기준|특징|
|---|---|---|
|표준편차 2배|$\mu \pm 2\sigma$|정규분포 가정. 약 5% 이상치 탐지|
|표준편차 3배|$\mu \pm 3\sigma$|더 엄격. 약 0.3% 이상치 탐지|
|IQR 방식|$Q1 - 1.5 \times IQR$, $Q3 + 1.5 \times IQR$|분포 무관. 가장 범용적|

### 이상치 처리 방법

```python
# 1. 제거
df = df[~((df['score'] < Q1 - 1.5*IQR) | (df['score'] > Q3 + 1.5*IQR))]

# 2. 대체 (Winsorizing) — 이상치를 경계값으로 교체
from scipy.stats import mstats
df['score'] = mstats.winsorize(df['score'], limits=[0.05, 0.05])

# 3. 변환 — 로그 변환으로 이상치 영향 완화
import numpy as np
df['score_log'] = np.log1p(df['score'])   # log(1 + x), 0 처리 포함
```

## 6. 정규화 (Normalization)

변수마다 단위와 범위가 다르면 거리 기반 알고리즘이나 경사하강법에서 특정 변수가 과도한 영향을 미친다. 정규화는 이 문제를 해결한다.

### MinMax 정규화

$$X' = \frac{X - X_{min}}{X_{max} - X_{min}}$$

값을 0~1 범위로 변환한다. 이상치에 민감하다.

```python
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
df_scaled = scaler.fit_transform(df[['score', 'age']])
```

### Robust 정규화

$$X' = \frac{X - X_{median}}{IQR}$$

중앙값과 IQR을 사용해 **이상치의 영향을 최소화**한다. 이상치가 많은 데이터에 적합하다.

```python
from sklearn.preprocessing import RobustScaler
scaler = RobustScaler()
df_scaled = scaler.fit_transform(df[['score']])
```

### 표준화 (Standardization, Z-score)

$$X' = \frac{X - \bar{X}}{s}$$

평균 0, 표준편차 1로 변환한다. 정규분포를 가정하는 모델에 적합하다.

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
df_scaled = scaler.fit_transform(df[['score']])
```

### 벡터 정규화 (Vector Normalize)

$$normalize = \frac{v}{|v|}$$

벡터의 크기(노름)로 나눠 단위 벡터로 만든다. 방향 정보만 남기고 크기를 제거한다. 텍스트 유사도, 코사인 유사도 계산에 사용한다.

```python
from sklearn.preprocessing import normalize
df_normalized = normalize(df[['score', 'age']], norm='l2')
```

### 정규화 방법 비교

|방법|수식|범위|이상치 영향|적합한 경우|
|---|---|---|---|---|
|MinMax|$(x - min) / (max - min)$|0 ~ 1|매우 민감|이상치 없고 범위 고정 필요|
|Robust|$(x - median) / IQR$|제한 없음|거의 없음|이상치 많은 데이터|
|Z-score|$(x - mean) / std$|제한 없음|보통|정규분포 가정 모델|
|L2 Norm|$v / \|v\|$|-1 ~ 1|보통|방향만 중요한 경우|

## 7. 범주화 (Categorical Encoding)

머신러닝 모델 대부분은 숫자 입력만 받는다. 문자열 범주형 데이터를 숫자로 변환해야 한다.

### Factorize (레이블 인코딩)

범주를 정수로 순서대로 매핑한다. 순서 없는 명목형 데이터에 쓰면 모델이 순서가 있다고 잘못 해석할 수 있다.

```python
df['grade_code'], uniques = pd.factorize(df['grade'])
# A→0, B→1, C→2 형태로 변환
```

### One-Hot Encoding (Get Dummies)

범주마다 0/1 이진 열을 만든다. 순서 없는 명목형 데이터에 적합하다.

```python
pd.get_dummies(df['grade'])
pd.get_dummies(df, columns=['grade', 'gender'])

# sklearn
from sklearn.preprocessing import OneHotEncoder
ohe = OneHotEncoder(sparse_output=False)
ohe.fit_transform(df[['grade']])
```

열 수 = 범주 수가 되므로 범주가 너무 많으면 차원이 폭발적으로 증가한다. 이 경우 Target Encoding을 고려한다.

### Target Encoding

각 범주를 해당 범주의 **타깃(y) 평균값**으로 대체한다. 범주 수가 많을 때 유용하지만 데이터 누수(Data Leakage)에 주의해야 한다.

```python
target_mean = df.groupby('city')['price'].mean()
df['city_encoded'] = df['city'].map(target_mean)
```

### Cut과 Qcut — 연속형 → 범주형

연속형 변수를 구간으로 나눠 범주형으로 변환한다.

```python
# cut: 범위를 직접 지정
df['age_group'] = pd.cut(df['age'],
    bins=[0, 20, 30, 40, 100],
    labels=['10대', '20대', '30대', '40대+'])

# qcut: 동일한 개수로 나눔 (분위수 기반)
df['score_group'] = pd.qcut(df['score'], q=4,
    labels=['하', '중하', '중상', '상'])
```

`cut`은 구간 크기가 같고, `qcut`은 각 구간의 데이터 개수가 같다.

## 8. 2단계: Structuring (구조화)

데이터를 **분석 가능한 형태**로 재구성하는 단계다.

```python
# merge — 두 DataFrame 결합 (SQL JOIN)
pd.merge(df1, df2, on='id', how='left')

# concat — 단순 이어붙이기
pd.concat([df1, df2], axis=0, ignore_index=True)

# split — 열 분리
df[['year', 'month']] = df['date'].str.split('-', expand=True)

# melt — 넓은 → 긴 형태
df.melt(id_vars=['name'], value_vars=['kor', 'math'], var_name='subject', value_name='score')

# pivot — 긴 → 넓은 형태
df.pivot(index='name', columns='subject', values='score')
```

## 9. 3단계: Feature Engineering (특성 공학)

원본 변수를 가공하거나 새로운 변수를 만들어 **모델의 성능을 높이는** 단계다.

```python
# 파생 변수 생성
df['bmi'] = df['weight'] / (df['height'] / 100) ** 2
df['age_group'] = pd.cut(df['age'], bins=[0, 30, 50, 100], labels=['청년', '중년', '노년'])

# 날짜에서 특성 추출
df['month']   = df['date'].dt.month
df['weekday'] = df['date'].dt.weekday
df['is_weekend'] = df['weekday'].isin([5, 6]).astype(int)

# PCA로 차원 축소
from sklearn.decomposition import PCA
pca = PCA(n_components=2)
df_pca = pca.fit_transform(df_scaled)
```

도메인 지식을 반영하는 것이 핵심이다. 예를 들어 거래 데이터에서 "최근 7일 평균 거래액"이나 "야간 거래 여부" 같은 변수를 만드는 것이 모델 성능에 큰 영향을 준다.

## 10. 4단계: Optimization (최적화)

분석 파이프라인의 **성능, 속도, 안전성**을 높이는 단계다.

```python
# 타입 변환으로 메모리 절약
df['score'] = df['score'].astype('int8')           # int64 → int8
df['grade'] = df['grade'].astype('category')        # 범주형으로 변환 (메모리 절약)

df.to_parquet('clean_data.parquet')   # 압축, 타입 보존, 빠른 읽기
df.to_csv('clean_data.csv', index=False)
```

## 11. 불균형 데이터 (Imbalanced Data)

클래스 간 데이터 수 차이가 클 때 모델이 다수 클래스만 예측하는 방향으로 학습된다.  
정확도는 높아도 소수 클래스를 전혀 탐지 못하는 문제가 발생한다.

### Undersampling

다수 클래스 데이터를 **줄여서** 균형을 맞춘다. 데이터 손실이 발생한다.

```python
from imblearn.under_sampling import RandomUnderSampler
rus = RandomUnderSampler(random_state=42)
X_res, y_res = rus.fit_resample(X, y)
```

### Oversampling

소수 클래스 데이터를 **늘려서** 균형을 맞춘다. SMOTE는 기존 소수 클래스 데이터를 보간해 새 데이터를 합성한다.

```python
from imblearn.over_sampling import SMOTE
sm = SMOTE(random_state=42)
X_res, y_res = sm.fit_resample(X, y)
```

### 데이터 증강 (Data Augmentation)

이미지, 텍스트처럼 원본 데이터를 변형해 새 데이터를 만드는 방법이다.  
이미지라면 회전, 반전, 크롭, 밝기 조절 등으로 데이터 수를 늘린다.

### Boosting

앙상블 방법 중 하나로, 이전 모델이 틀린 샘플에 더 높은 가중치를 부여해 다음 모델이 집중 학습하도록 한다. 불균형 데이터에서 소수 클래스를 더 잘 학습하게 만들 수 있다.

|방법|방식|데이터 손실|
|---|---|---|
|Undersampling|다수 클래스 줄임|있음|
|Oversampling (SMOTE)|소수 클래스 합성|없음|
|Data Augmentation|원본 변형으로 생성|없음|
|Class Weight 조정|모델 손실함수에 가중치|없음|

```python
# 모델에 클래스 가중치 부여 (데이터 변환 없이)
from sklearn.linear_model import LogisticRegression
model = LogisticRegression(class_weight='balanced')
```

## 12. 편향-분산 트레이드오프

$$MSE = Bias^2 + Variance$$

|상태|Bias|Variance|설명|
|---|---|---|---|
|**Underfitting**|높음|낮음|모델이 너무 단순. 패턴을 못 잡음|
|**Good Model**|낮음|낮음|최적 균형|
|**Overfitting**|낮음|높음|학습 데이터에만 과적합. 일반화 실패|

전처리 품질이 좋을수록 모델이 불필요한 노이즈에 학습되지 않아 **Variance를 낮추는 데** 기여한다.

## 13. 전체 전처리 흐름

```
원본 데이터 수집
   ↓
1. Cleaning (정제)
   오타 수정 / 중복 제거 / 단위 통일
   ↓
2. 결측치 처리
   dropna / fillna / interpolate
   ↓
3. 이상치 처리
   IQR / 표준편차 기준 탐지 → 제거 or 대체
   ↓
4. Structuring (구조화)
   merge / split / melt / pivot
   ↓
5. Feature Engineering (특성 공학)
   파생변수 / 범주화 / 정규화 / 차원 축소
   ↓
6. Optimization (최적화)
   타입 변환 / 메모리 절약 / 파일 저장
   ↓
모델 학습 입력
```
