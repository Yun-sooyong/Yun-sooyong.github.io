# 비지도 학습: 시계열 분석 (Time Series Analysis)

시계열 분석은 **과거로부터 현재를 이해하고 미래를 예측**하는 분석이다.  
시계열 데이터는 시간에서 **순차적으로(sequentially)** 관측한 값들의 집합으로, 관측값 사이의 **순서와 시간 간격**이 중요하다.

일반 데이터와 시계열 데이터의 핵심 차이는 **관측 순서가 의미를 가진다**는 점이다.  
일반 회귀분석에서는 행의 순서를 바꿔도 결과가 같지만, 시계열에서는 순서를 바꾸면 분석 자체가 무의미해진다.

---

## 1. 시계열 데이터의 특성과 개념

### 시계열 데이터란

동일한 대상을 일정 시간 간격으로 반복 측정한 데이터다.

```
시간 →   t1    t2    t3    t4    t5    t6   ...
값   →  [100] [105] [98] [112] [108] [115]  ...
```

관측값 하나하나가 독립적이지 않고 **이전 값에 영향을 받는다**는 것이 핵심이다.  
오늘 기온은 어제 기온과 무관하지 않고, 오늘 주가는 어제 주가의 영향을 받는다.

### 시계열 데이터의 다섯 가지 특성

#### 1. 시간 의존성 (Temporal Dependence)

과거 값이 현재 값에 영향을 준다. 이 관계를 **자기상관(Autocorrelation)** 이라고 한다.

```
강한 자기상관: 오늘 값 ≈ 어제 값 (예: 기온)
약한 자기상관: 오늘 값이 어제 값과 거의 무관 (예: 주사위 눈)
```

#### 2. 추세 (Trend)

장기적으로 값이 증가하거나 감소하는 방향성이다.

```
상승 추세: ↗  (예: 물가 지수, 인구수)
하락 추세: ↘  (예: 하드디스크 가격)
무추세:    ↔  (예: 정상 시계열)
```

선형 추세: $y_t = \alpha + \beta t + \varepsilon_t$  
비선형 추세: 지수적 증가, S자 곡선 등

#### 3. 계절성 (Seasonality)

**고정된 주기**로 반복되는 패턴이다. 계절성은 주기가 알려져 있고 일정하다.

```
일별 계절성: 출퇴근 시간대 교통량 급증
주별 계절성: 주말 매출 감소
월별 계절성: 여름 에너지 소비 증가
연별 계절성: 연말 소비 급증
```

계절성이 추세와 독립적이면 **가법 모형**, 계절 변동폭이 추세 크기에 비례하면 **승법 모형**을 사용한다.

$$\text{가법}: y_t = T_t + S_t + R_t$$ $$\text{승법}: y_t = T_t \times S_t \times R_t$$

#### 4. 주기 (Cycle)

계절성과 달리 **주기가 고정되지 않은** 장기 파동이다. 길이가 1~수십 년에 걸친다.

```
경기 순환: 호황 → 침체 → 회복 반복 (주기 4~12년)
태양 활동 주기: 약 11년
```

계절성은 달력에 따라 정확히 예측 가능하지만, 주기는 그렇지 않다.

#### 5. 불규칙성 (Irregularity / Noise)

추세, 계절성, 주기로 설명되지 않는 **무작위 잔차**다.  
완전히 예측 불가능하며, 모델이 완벽해도 이 부분은 남는다.

```
원본 시계열 = 추세(T) + 계절성(S) + 주기(C) + 불규칙성(R)
```

### 시계열 vs 횡단면 데이터 비교

|구분|시계열 (Time Series)|횡단면 (Cross-sectional)|
|---|---|---|
|관측 방식|같은 대상을 시간 순서로 반복 관측|특정 시점에 여러 대상을 한 번 관측|
|관측 순서|의미 있음 (순서 바꾸면 분석 불가)|의미 없음 (행 순서 바꿔도 무관)|
|독립성|관측값이 서로 의존|관측값이 독립|
|예시|월별 매출, 일별 기온, 시간별 주가|지역별 인구, 사람별 키/몸무게|

### 시계열 분해 개념도

```
원본 시계열
     │
     ├──────────────────────────────────────────┐
     │                                          │
  가법 분해 (변동폭 일정)              승법 분해 (변동폭 추세에 비례)
  y = T + S + R                        y = T × S × R
     │
     ↓
  ┌──────────┐   ┌──────────┐   ┌──────────┐
  │  추세(T)  │ + │ 계절성(S) │ + │ 잔차(R)   │
  │ 장기 방향 │   │ 반복 패턴 │   │ 설명 불가 │
  └──────────┘   └──────────┘   └──────────┘
```

```python
from statsmodels.tsa.seasonal import seasonal_decompose
import matplotlib.pyplot as plt

# 가법 분해
result = seasonal_decompose(df['value'], model='additive', period=12)
result.plot()
plt.tight_layout()
plt.show()

# 각 성분 추출
trend    = result.trend      # 추세
seasonal = result.seasonal   # 계절성
residual = result.resid      # 잔차
```

## 2. Pandas 시계열 자료구조

Pandas는 시계열을 다루기 위한 전용 자료구조를 제공한다.

|데이터 유형|단일 값|인덱스|데이터 타입|예시|
|---|---|---|---|---|
|**Time stamp**|`Timestamp`|`DatetimeIndex`|`datetime64[ns]`, `datetime64[ns, tz]`|`"2020-01-10"`, `"14:59:00"`|
|**Time duration**|`Timedelta`|`TimedeltaIndex`|`timedelta64[ns]`|`"10 hours"`, `"30 seconds"`|
|**Fixed frequency interval**|`Period`|`PeriodIndex`|`period[freq]`|`"2 business days"`, `"5 months"`|

### 세 자료구조의 차이

- **Timestamp**: 특정 시각 하나를 나타낸다. "2020-01-10 14:59:00"처럼 한 시점. 시계열 인덱스의 가장 기본 단위
- **Timedelta**: 두 시각 사이의 **경과 시간**을 나타낸다. "10시간 후", "30초 전"처럼 시간의 차이를 나타낼 때 사용. `Timestamp - Timestamp = Timedelta`
- **Period**: 고정된 주기의 **시간 구간**을 나타낸다. "2020년 1월", "2020년 1분기"처럼 하나의 기간 전체를 가리킬 때 사용

```python
import pandas as pd

# Timestamp — 특정 시각
ts = pd.Timestamp('2020-01-10 14:59:00')
ts = pd.Timestamp('2020-01-10', tz='Asia/Seoul')   # 타임존 포함
print(ts.year, ts.month, ts.day, ts.hour)          # 속성 추출

# Timedelta — 시간 간격
td = pd.Timedelta('10 hours')
td = pd.Timedelta(days=3, hours=2)
print(ts + td)   # Timestamp에 Timedelta를 더해 새 시각 계산

# Period — 기간
p = pd.Period('2020-01', freq='M')   # 2020년 1월 (월 단위)
p = pd.Period('2020Q1', freq='Q')    # 2020년 1분기
print(p.start_time, p.end_time)      # 기간의 시작/끝 시각

# DatetimeIndex 생성
idx_monthly = pd.date_range('2024-01-01', periods=12, freq='ME')  # 월별 12개
idx_daily   = pd.date_range('2024-01-01', '2024-12-31', freq='D') # 일별 전체
idx_hourly  = pd.date_range('2024-01-01', periods=24, freq='h')   # 시간별 24개

# 날짜 파싱
df['date'] = pd.to_datetime(df['date'])      # 문자열 → Timestamp
df = df.set_index('date')                    # 인덱스로 설정
```

### DatetimeIndex 슬라이싱

DatetimeIndex가 설정되면 문자열로 직접 날짜 범위를 지정할 수 있다.

```python
df['2024']              # 2024년 전체
df['2024-06']           # 2024년 6월
df['2024-01':'2024-06'] # 2024년 1~6월 (끝 포함)
df.loc['2024-03-15']    # 특정 날짜
df.between_time('09:00', '18:00')  # 시간 범위
```

## 3. 시계열의 예측 목표

|특성|설명|예시|시각화 방법|
|---|---|---|---|
|**추세 (Trend)**|장기적 증가 또는 감소 방향|매년 꾸준히 증가하는 매출|이동 평균선|
|**주기 (Periodicity)**|일정하지 않은 긴 파동|경기 사이클|장기 선 그래프|
|**계절성 (Seasonality)**|일정 주기로 반복되는 패턴|여름마다 에어컨 판매 급증|분해 플롯|
|**불규칙성 (Irregularity)**|예측 불가능한 무작위 변동|갑작스러운 이벤트, 노이즈|잔차 플롯|

## 4. 정상성 (Stationarity)

### 왜 정상성이 필요한가

ARIMA 같은 시계열 모델은 수학적으로 **통계적 성질이 시간에 따라 변하지 않는다**고 가정한다.  
추세가 있으면 평균이 계속 변하므로 모델이 "평균이 얼마인가"를 안정적으로 학습할 수 없다.  
즉, 정상성은 모델이 과거 패턴을 미래에도 적용할 수 있다는 가정의 기반이다.

### 정상 시계열의 조건

시간이 지나도 다음 세 가지가 일정해야 한다.

- **평균이 일정**: 추세가 없음. $E[y_t] = \mu$ (상수)
- **분산이 일정**: 시간에 따라 변동폭이 커지거나 작아지지 않음. $Var(y_t) = \sigma^2$ (상수)
- **자기공분산이 시차에만 의존**: 특정 시점에 무관하게 같은 시차면 공분산이 같음. $Cov(y_t, y_{t+k})$가 $t$에 무관하고 $k$에만 의존

```
비정상 시계열:
  값 ↗↗↗       ← 추세 있음 (평균이 증가)
  변동폭 ↕↕↕↕↕  ← 계절성 있음 (분산이 계절에 따라 변함)

정상 시계열:
  값 ~~~~~      ← 일정 범위 안에서 진동
  변동폭 ≈ 일정
```

### 비정상 → 정상 변환

|변환|목적|사용 시기|
|---|---|---|
|차분 (diff)|추세 제거|평균이 시간에 따라 변할 때|
|로그 변환 (log)|분산 안정화|값이 클수록 변동폭도 커질 때|
|지수 변환 (exp)|로그 변환의 역변환|로그 스케일로 변환된 데이터 복원|
|Box-Cox 변환|분산 안정화 (일반화)|최적 변환 방법을 자동으로 찾고 싶을 때|

```python
import numpy as np
from scipy.stats import boxcox
from statsmodels.tsa.stattools import adfuller

# 1. 차분 — 추세 제거 (가장 기본적인 방법)
# 1차 차분: y_t - y_{t-1} (오늘 값 - 어제 값)
df['diff1'] = df['value'].diff(1)
# 2차 차분: 1차 차분에 다시 차분 적용 (1차로 부족할 때)
df['diff2'] = df['value'].diff(1).diff(1)

# 2. 로그 변환 — 분산 안정화
# 값이 10배가 되면 변동폭도 10배가 되는 경우 (주가, 인구 등)
df['log'] = np.log(df['value'])            # 자연로그
df['log_diff'] = np.log(df['value']).diff(1)  # 로그 + 차분 (수익률 개념)

# 3. 지수 변환 — 로그 변환의 역
df['exp'] = np.exp(df['log'])

# 4. Box-Cox 변환 — 최적 λ를 자동으로 찾아 변환
# λ=0이면 로그 변환, λ=1이면 선형 변환과 같음
df['boxcox'], lambda_ = boxcox(df['value'])
print(f'최적 λ: {lambda_:.3f}')

# 정상성 검정 (ADF Test: Augmented Dickey-Fuller)
# 귀무가설: 단위근이 있다 (= 비정상 시계열)
result = adfuller(df['value'])
print(f'ADF 통계량: {result[0]:.4f}')
print(f'p-value:   {result[1]:.4f}')
print(f'임계값 (5%): {result[4]["5%"]:.4f}')
# p < 0.05 → 귀무가설 기각 → 정상 시계열
# p ≥ 0.05 → 귀무가설 기각 실패 → 비정상 → 차분 필요
```

## 5. 전처리 핵심 도구

### Resample — 시간 단위 변환

시간 해상도를 바꾸는 작업이다.  
**다운샘플링**은 세밀한 데이터를 거칠게(일별 → 월별), **업샘플링**은 거친 데이터를 세밀하게(월별 → 일별) 변환한다.

```python
# 다운샘플링 — 집계해서 줄임
df.resample('ME').mean()         # 일별 → 월별 평균
df.resample('ME').sum()          # 일별 → 월별 합계
df.resample('QE').agg({
    'price':  'mean',
    'volume': 'sum'
})                               # 열마다 다른 집계

# 업샘플링 — 빈 값 채움 (보간 필요)
df.resample('D').ffill()                       # 앞 값으로 채우기
df.resample('D').bfill()                       # 뒤 값으로 채우기
df.resample('D').interpolate('linear')         # 선형 보간
df.resample('D').interpolate('spline', order=3) # 스플라인 보간
```

### Shift & Lag — 시차 이동

**Lag(시차)** 는 시계열 분석에서 핵심 개념이다.  
"오늘 값이 어제 값에 얼마나 의존하는가"를 모델에 반영하기 위해 과거 값을 새 열로 만든다.

```python
df['lag1'] = df['value'].shift(1)    # 1기간 전 값 (1 lag)
df['lag7'] = df['value'].shift(7)    # 7기간 전 값 (1주 전)
df['lead1'] = df['value'].shift(-1)  # 1기간 후 값 (미래 참조 — 예측 평가용)

# 예: lag 변수를 특성으로 사용하는 머신러닝 시계열 모델
features = df[['lag1', 'lag2', 'lag7', 'lag30']].dropna()
target   = df['value'].loc[features.index]
```

```
원본:   [100, 105, 98, 112, 108]
lag1:   [NaN, 100, 105,  98, 112]  ← 1칸 오른쪽으로 이동
lag2:   [NaN, NaN, 100, 105,  98]  ← 2칸 오른쪽으로 이동
```

### Diff — 변화량

차분은 **연속된 두 관측값의 차이**다. 추세 제거와 변화율 분석에 모두 쓰인다.

```python
df['diff1'] = df['value'].diff(1)          # 전기 대비 차이 (1차 차분)
df['diff7'] = df['value'].diff(7)          # 7기간 전 대비 차이 (주간 변화)
df['pct_change'] = df['value'].pct_change() * 100  # 전기 대비 증감률 (%)

# 로그 차분 ≈ 증감률 (값이 클 때 더 안정적)
df['log_diff'] = np.log(df['value']).diff(1)
```

```
원본:  [100, 110, 105, 115]
diff1: [NaN,  10,  -5,  10]  ← 전기 대비 변화량
pct:   [NaN, 10%, -4.5%, 9.5%]  ← 전기 대비 증감률
```

## 6. 자기상관 (Autocorrelation)

### 개념

자기상관은 시계열의 **현재 값과 과거 자기 자신의 값 사이의 상관관계**다.  
일반 상관이 서로 다른 두 변수의 관계를 보는 것과 달리, 자기상관은 **하나의 변수를 시간을 달리해서 비교**한다.

```
일반 상관: 키(x)와 몸무게(y)의 관계
자기상관: 오늘 기온(y_t)과 어제 기온(y_{t-1})의 관계
                         또는 1주일 전 기온(y_{t-7})의 관계
```

자기상관이 높다 = 과거 값이 미래를 예측하는 데 유용하다 = 시계열에 패턴이 있다.  
자기상관이 없다 = 과거 값이 미래를 예측하는 데 쓸모없다 = 백색잡음에 가깝다.

### 자기상관 계수 수식

$$\rho_s = \frac{cov(y_t, y_{t+s})}{var(y_t)}$$

$$\hat{\rho}_k = \frac{\sum_{t=k+1}^{T}(r_t - \bar{r})(r_{t-k} - \bar{r})}{\sum_{t=1}^{T}(r_t - \bar{r})^2}$$

- $k$ (시차, lag): 몇 기간 전 값과 비교하는지
- $\hat{\rho}_k$: 시차 $k$에서의 자기상관 계수 (-1 ~ 1)
- 양수: 과거 값이 높으면 현재도 높은 경향
- 음수: 과거 값이 높으면 현재는 낮은 경향 (진동)

### ACF (자기상관함수, Autocorrelation Function)

ACF는 시차 $k$에서 **현재 값과 $k$기 전 값의 상관계수**를 모든 시차에 걸쳐 나타낸 함수다.

$$ACF(k) = \rho_k = \frac{Cov(y_t, y_{t-k})}{Var(y_t)}$$

중요한 점은 ACF가 **직접 효과와 간접 효과를 모두 포함**한다는 것이다.

```
예: 기온 데이터에서 lag=3 ACF가 높게 나왔을 때
    이 상관은 두 가지 이유일 수 있다:
    
    (A) 직접 효과: 3일 전 기온 → 오늘 기온에 직접 영향
    (B) 간접 효과: 3일 전 → 2일 전 → 어제 → 오늘 (연쇄 전달)
    
    ACF는 (A)와 (B)를 구분하지 않고 합산해서 보여준다.
```

**ACF 플롯 읽는 법**

```
ACF 값
 1.0 │●
     │ \
 0.5 │  ●─●
     │      ●─●─●
 0.0 │──────────────── LAG
     │              ●●●
-0.5 │
     0  1  2  3  4  5  6  7

- 파란 음영: 95% 신뢰구간 (±1.96/√n)
- 막대가 신뢰구간 밖: 해당 시차에서 유의미한 자기상관 있음
- lag=0은 항상 1 (자기 자신과의 상관)
```

ACF 모양과 의미:

- **천천히 감소**: 추세 있음 → 차분 필요 (비정상 시계열)
- **급격히 절단 (lag q 이후 0에 수렴)**: MA(q) 특성
- **사인파 모양 (양음 반복)**: AR 특성 또는 계절성
- **lag s마다 뾰족하게 솟음**: 주기 $s$의 계절성 존재

---

### PACF (편자기상관함수, Partial Autocorrelation Function)

PACF는 **중간 시차의 간접 효과를 통계적으로 제거**하고, 시차 $k$에서의 **순수한 직접 자기상관**만 측정한다.

직관적으로 설명하면:

- PACF(1) = lag=1 ACF (중간이 없으므로 동일)
- PACF(2) = lag=1의 영향을 제거하고 나서 lag=2의 순수 영향
- PACF(3) = lag=1, lag=2의 영향을 제거하고 나서 lag=3의 순수 영향

```
ACF와 PACF 차이 예시 (AR(2) 모델인 경우):

y_t = 0.6*y_{t-1} + 0.3*y_{t-2} + ε_t

ACF:  lag=1 ↑, lag=2 ↑, lag=3 ↑, lag=4 ↑ ...  (천천히 감소)
      → y_t와 y_{t-3}은 직접 연결이 없지만
        y_t→y_{t-1}→y_{t-2}→y_{t-3} 체인으로 상관이 전달됨

PACF: lag=1 ↑, lag=2 ↑, lag=3 ≈ 0, lag=4 ≈ 0 (p=2 이후 절단)
      → 체인 효과를 제거하면 lag=3 이후는 직접 영향이 없음
```

수식으로는 현재 값 $y_t$에서 $y_{t-1}, \ldots, y_{t-k+1}$의 영향을 선형회귀로 제거한 후의 편상관계수다.

---

### ACF vs PACF 비교

|구분|ACF|PACF|
|---|---|---|
|측정 대상|현재와 k기 전의 **총** 상관|중간 시차 제거 후 **순수** 직접 상관|
|간접 효과|포함|제거|
|절단 패턴|MA(q) → lag q 이후 절단|AR(p) → lag p 이후 절단|
|주 용도|MA 차수(q) 결정, 계절성 탐지|AR 차수(p) 결정|

### ACF/PACF 해석 패턴 → 모델 결정

|ACF 패턴|PACF 패턴|의미|적합한 모델|
|---|---|---|---|
|lag q 이후 **급격히 절단**|지수적으로 서서히 감소|이동 평균 특성|**MA(q)**|
|지수적으로 서서히 감소|lag p 이후 **급격히 절단**|자기회귀 특성|**AR(p)**|

|lag s, 2s, 3s에서 뾰족한 봉우리|마찬가지|주기 s의 계절성|**SARIMA의 s 결정**|

```
ACF    PACF          ACF    PACF

```

### 실전 분석 예시: ARIMA 차수 결정 과정

```python
from statsmodels.tsa.stattools import adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt

# 1단계: 원본 데이터 ACF/PACF 확인
fig, axes = plt.subplots(3, 2, figsize=(14, 12))

df['value'].plot(ax=axes[0, 0], title='원본 시계열')
axes[0, 1].set_visible(False)

plot_acf(df['value'],  lags=20, ax=axes[1, 0], title='원본 ACF')
plot_pacf(df['value'], lags=20, ax=axes[1, 1], title='원본 PACF')

# 2단계: 차분 후 재확인 (비정상이면)
df['diff1'] = df['value'].diff(1).dropna()
df['diff1'].plot(ax=axes[0, 0].twinx(), color='red', alpha=0.5)

plot_acf(df['diff1'],  lags=20, ax=axes[2, 0], title='차분 후 ACF')
plot_pacf(df['diff1'], lags=20, ax=axes[2, 1], title='차분 후 PACF')

plt.tight_layout()
plt.show()

# 3단계: ADF 검정으로 정상성 확인
print("=== 원본 ADF 검정 ===")
adf_orig = adfuller(df['value'])
print(f'p-value: {adf_orig[1]:.4f}  {"정상" if adf_orig[1] < 0.05 else "비정상"}')

print("=== 차분 후 ADF 검정 ===")
adf_diff = adfuller(df['diff1'].dropna())
print(f'p-value: {adf_diff[1]:.4f}  {"정상" if adf_diff[1] < 0.05 else "비정상"}')

# 4단계: 차분 후 ACF/PACF 패턴으로 p, q 결정
# - PACF가 lag=1 이후 절단 → p=1
# - ACF가 lag=1 이후 절단 → q=1
# - 차분 1회 → d=1
# → ARIMA(1, 1, 1) 시도
```

## 7. 이동 평균 (Moving Average Smoothing)

노이즈가 많은 시계열에서 **전체 추세를 드러내기 위한 평활화(Smoothing)** 방법이다.  
고주파 변동(노이즈)을 걸러내고 저주파 패턴(추세)만 남긴다.

> 주의: 여기서 말하는 이동 평균은 MA 모델의 이동 평균과 다른 개념이다.  
> MA 모델은 과거 **오차**를 사용하지만, 이동 평균 평활화는 과거 **값** 자체를 사용한다.

### 단순 이동 평균 (Simple Moving Average, SMA)

$$SMA_t = \frac{A_{t} + A_{t-1} + \cdots + A_{t-n+1}}{n} = \frac{1}{n}\sum_{i=0}^{n-1} A_{t-i}$$

최근 $n$개 값의 단순 평균이다. 모든 값에 동일한 가중치($\frac{1}{n}$)를 부여한다.

```python
df['SMA_7']  = df['value'].rolling(window=7).mean()   # 7일 이동 평균
df['SMA_30'] = df['value'].rolling(window=30).mean()  # 30일 이동 평균
```

- $n$이 작을수록 최근 변화에 민감하고 노이즈가 많다
- $n$이 클수록 부드럽지만 최근 변화에 반응이 느리다
- 처음 $n-1$개 값은 NaN이 된다 (창이 채워지지 않음)

### 가중 이동 평균 (Weighted Moving Average, WMA)

$$WMA_t = A_t \times W_1 + A_{t-1} \times W_2 + \cdots + A_{t-n+1} \times W_n, \quad \sum W_i = 1$$

최근 값에 더 높은 가중치를 부여한다. SMA보다 최근 변화에 더 빠르게 반응한다.

```python
weights = [0.4, 0.3, 0.2, 0.1]   # 최근일수록 높은 가중치, 합 = 1.0
df['WMA_4'] = df['value'].rolling(4).apply(
    lambda x: (x * weights[::-1]).sum()   # 오래된 값부터 곱
)
```

### 지수 이동 평균 (Exponential Moving Average, EMA)

$$EMA_t = \alpha \cdot y_t + (1-\alpha) \cdot EMA_{t-1}, \quad \alpha = \frac{Smoothing}{1+Days}$$

슬라이드의 수식 형태로 쓰면: $$EMA_{today} = Value_{today} \times \frac{Smoothing}{1+Days} + EMA_{yesterday} \times \left(1 - \frac{Smoothing}{1+Days}\right)$$

- 과거 모든 값을 지수적으로 감소하는 가중치로 반영한다
- 가장 최근 값에 가장 큰 가중치가 부여된다
- 과거로 갈수록 가중치가 지수적으로 줄어든다 ($\alpha^1, \alpha^2, \alpha^3, \ldots$)
- SMA/WMA와 달리 창 밖의 데이터도 간접 반영된다

```python
df['EMA_12'] = df['value'].ewm(span=12, adjust=False).mean()
df['EMA_26'] = df['value'].ewm(span=26, adjust=False).mean()

# MACD — 단기 EMA와 장기 EMA의 차이로 추세 전환 신호 포착
df['MACD']        = df['EMA_12'] - df['EMA_26']
df['Signal_Line'] = df['MACD'].ewm(span=9, adjust=False).mean()
df['Histogram']   = df['MACD'] - df['Signal_Line']
```

### 세 이동 평균 비교

|방법|반응 속도|과거 데이터|특징|주요 용도|
|---|---|---|---|---|
|SMA|느림|창 안의 값만 동등 반영|단순하고 해석 쉬움|장기 추세 파악|
|WMA|중간|창 안에서 최근에 더 높은 가중치|가중치 직접 제어|중기 추세|
|EMA|빠름|전체 과거 지수적 반영|최근 데이터에 민감|주식 기술 분석|

## 8. 시계열 분석 모델

모델들은 복잡도 순서로 발전했다: AR → MA → ARMA → ARIMA → SARIMA

### AR — 자기회귀 모델 (Autoregression)

$$y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t$$

**과거 자기 자신의 값**으로 현재를 예측하는 회귀 모델이다.  
$p$는 참조하는 과거 시점의 수(AR 차수)다.

직관: "오늘 기온은 어제, 그제 기온의 가중합이다"

- PACF가 시차 $p$ 이후 급격히 절단 → AR(p) 적합
- 정상 시계열에 적용

### MA — 이동 평균 모델 (Moving Average)

$$y_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q}$$

과거 **예측 오차(잔차)** 로 현재를 예측한다. $q$는 참조하는 과거 오차의 수다.

직관: "오늘 예측값 = 평균 + 과거 예측이 얼마나 틀렸는지의 보정"  
이동 평균 **평활화**와 이름이 같지만 완전히 다른 개념이다.

- ACF가 시차 $q$ 이후 급격히 절단 → MA(q) 적합
- 정상 시계열에 적용

### ARMA — 자기회귀 이동 평균 모델

$$y_t = c + \underbrace{\sum_{i=1}^{p}\phi_i y_{t-i}}_{\text{AR 부분}} + \varepsilon_t + \underbrace{\sum_{j=1}^{q}\theta_j \varepsilon_{t-j}}_{\text{MA 부분}}$$

AR과 MA를 결합한 모델이다.  
**정상 시계열**에만 적용 가능하며, 추세나 계절성이 있으면 먼저 제거해야 한다.

### ARIMA — 누적 자기회귀 이동 평균 모델

$$ARIMA(p, d, q)$$

비정상 시계열도 다룰 수 있도록 ARMA에 **차분($d$)** 을 추가한 모델이다.  
"I(Integrated)"는 차분(differencing)을 의미한다.

|파라미터|의미|결정 방법|
|---|---|---|
|$p$|AR 차수 (과거 값 참조 수)|PACF 그래프에서 절단점|
|$d$|차분 횟수|ADF 검정 반복 → 정상화에 필요한 차분 횟수|
|$q$|MA 차수 (과거 오차 참조 수)|ACF 그래프에서 절단점|

```python
from statsmodels.tsa.arima.model import ARIMA

# ARIMA(1,1,1): AR 1차 + 차분 1회 + MA 1차
model = ARIMA(df['value'], order=(1, 1, 1))
result = model.fit()
print(result.summary())

# 예측 (30기간)
forecast = result.get_forecast(steps=30)
pred_mean = forecast.predicted_mean
pred_ci   = forecast.conf_int()   # 95% 신뢰구간

# 시각화
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(12, 4))
df['value'].plot(ax=ax, label='실제값')
pred_mean.plot(ax=ax, label='예측값', color='red')
ax.fill_between(pred_ci.index,
                pred_ci.iloc[:, 0], pred_ci.iloc[:, 1],
                alpha=0.2, color='red', label='95% 신뢰구간')
ax.legend()
plt.show()
```

### SARIMA — 계절성 ARIMA

$$SARIMA(p, d, q)(P, D, Q)_s$$

ARIMA에 **계절성 파라미터**를 추가한 모델이다.  
월별 데이터의 연간 계절성, 일별 데이터의 주간 계절성 등을 명시적으로 모델링한다.

|파라미터|의미|
|---|---|
|$(p, d, q)$|비계절 ARIMA 파라미터 (단기 패턴)|
|$(P, D, Q)$|계절 AR, 차분, MA 차수 (장기 패턴)|
|$s$|계절 주기 (월별: 12, 분기별: 4, 주별: 52)|

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX

# 월별 데이터, 연간 계절성
model = SARIMAX(df['value'],
                order=(1, 1, 1),
                seasonal_order=(1, 1, 1, 12))
result = model.fit(disp=False)
print(result.summary())
```

### 모델 진화 관계

```
AR(p)       ← 과거 값만 사용
   +
MA(q)       ← 과거 오차만 사용
   ↓
ARMA(p,q)   ← 과거 값 + 과거 오차 (정상 시계열)
   ↓
ARIMA(p,d,q) ← 차분 추가 (비정상 시계열 가능)
   ↓
SARIMA      ← 계절성 추가
```

## 9. 모델 선택 흐름

```
시계열 데이터
   ↓
1. 탐색적 분석
   - 선 그래프 → 추세/계절성 육안 확인
   - 분해 플롯 (seasonal_decompose)
   - 이동 평균으로 노이즈 제거 후 추세 확인
   ↓
2. 정상성 검정 (ADF Test)
   ├─ p < 0.05 → 정상 → 3단계로
   └─ p ≥ 0.05 → 비정상
              ├─ 추세만 있음 → 차분
              ├─ 분산 불안정 → 로그 변환 후 차분
              └─ 계절성 있음 → 계절 차분 고려
   ↓
3. ACF / PACF 플롯 → p, q 결정
   ↓
4. 모델 학습
   정상 + 비계절 → ARIMA
   정상 + 계절성 → SARIMA
   ↓
5. 모델 비교 (AIC 기준)
   AIC = 2k - 2ln(L) → 낮을수록 좋음
   ↓
6. 잔차 진단
   - ACF 플롯 → 자기상관 없어야 함
   - Ljung-Box 검정 → p > 0.05
   ↓
7. 예측 및 신뢰구간
```

## 10. 잔차 진단

모델이 제대로 학습됐다면 잔차는 **백색잡음(White Noise)** 이어야 한다.

백색잡음이란 다음 조건을 만족하는 무작위 오차다.

- 평균 = 0
- 분산 일정 (등분산)
- 자기상관 없음 → 어떤 시차에서도 ACF가 신뢰구간 안에 있음

잔차에 패턴이 남아 있다면 모델이 설명하지 못한 구조가 아직 있다는 신호다.

```python
from statsmodels.graphics.tsaplots import plot_acf
from statsmodels.stats.diagnostic import acorr_ljungbox
import matplotlib.pyplot as plt

residuals = result.resid

fig, axes = plt.subplots(3, 1, figsize=(10, 10))

# 1. 잔차 시각화 — 무작위 패턴이어야 함
residuals.plot(ax=axes[0], title='잔차 시계열')
axes[0].axhline(0, color='red', linestyle='--')

# 2. 잔차 분포 — 정규분포에 가까워야 함
residuals.hist(bins=20, ax=axes[1])
axes[1].set_title('잔차 분포')

# 3. ACF — 모든 시차에서 신뢰구간(파란 점선) 안에 있어야 함
plot_acf(residuals, lags=20, ax=axes[2])

plt.tight_layout()
plt.show()

# Ljung-Box 검정 — 잔차에 자기상관이 없는지 통계적 검정
lb = acorr_ljungbox(residuals, lags=10, return_df=True)
print(lb)
# lb_pvalue > 0.05 → 자기상관 없음 → 백색잡음 OK
```

## 11. 전체 흐름 정리

```
시계열 데이터 로드 및 DatetimeIndex 설정
   ↓
탐색적 분석
   ├─ 선 그래프 → 추세, 계절성 육안 확인
   ├─ seasonal_decompose → 추세/계절성/잔차 분리
   └─ 이동 평균 (SMA/EMA) → 노이즈 제거, 추세 파악
   ↓
데이터 전처리
   ├─ resample → 시간 단위 통일
   ├─ shift/lag → 과거 값 특성 생성
   └─ diff → 변화량, 추세 제거
   ↓
정상성 확보
   └─ ADF 검정 → diff/log/boxcox 변환 → 재검정
   ↓
자기상관 분석
   └─ ACF/PACF → 모델 유형 및 p, q 결정
   ↓
모델 학습 및 비교 (AIC 기준)
   AR → MA → ARMA → ARIMA → SARIMA
   ↓
잔차 진단
   └─ ACF 플롯 + Ljung-Box → 백색잡음 확인
   ↓
예측 및 신뢰구간 시각화
```
