# Data Summarization & EDA

데이터 분석의 목표는 데이터에서 **인사이트(insight)** 를 뽑아내는 것이다.  
그 과정은 단순히 숫자를 보는 것이 아니라 다음 흐름으로 이어진다.

```
데이터 → 정보 → 패턴 → 해석 → 의사결정
```

---

## 1. 데이터 분석의 종류

|분석 종류|설명|질문 형태|
|---|---|---|
|**기술 분석 (Descriptive)**|데이터를 요약하고 집계해서 현재 상태 파악|"지난달 매출은 얼마였나?"|
|**탐색적 분석 (Exploratory, EDA)**|가설 없이 데이터를 탐색해서 패턴과 구조 발견|"어떤 변수가 중요한가?"|
|**추론 분석 (Inferential)**|표본으로 모집단을 추론, 가설검정|"이 차이가 통계적으로 유의한가?"|
|**예측 분석 (Predictive)**|과거 데이터로 미래를 예측|"다음 달 매출은 얼마일까?"|
|**인과관계 분석 (Casual)**|원인과 결과의 관계를 밝힘|"할인 행사가 매출을 늘렸는가?"|

분석 순서는 보통 기술 → 탐색 → 추론 → 예측 → 인과관계 순으로 깊어진다.

---

## 2. 데이터를 요약하는 5가지 기술

### 1. 기술적 통계 (Descriptive Statistics)

수치로 데이터의 중심, 퍼짐, 형태를 요약한다.

```python
df.describe()          # 수치형 변수 기술통계 한 번에
df.describe(include='all')  # 범주형 포함
```

### 2. 시각화 — 분포, 추세, 비교, 변화

눈으로 패턴을 파악한다. 수치만으로 놓치는 이상치, 분포 모양, 집단 간 차이를 시각화로 확인한다.

### 3. 관계 분석

변수 간의 상관관계나 연관성을 파악한다. 상관 행렬, 산점도, 크로스탭이 여기에 해당한다.

### 4. 데이터 집계

그룹별로 묶어서 요약한다. `groupby`, `pivot_table`, `crosstab` 등이 핵심 도구다.

### 5. 차원 축소 기술

변수가 너무 많을 때 PCA, t-SNE 등으로 중요한 정보만 남기고 차원을 줄인다.

---

## 3. 집계 함수의 종류

|종류|함수|설명|
|---|---|---|
|**통계적 집계**|`mean`, `median`, `describe`|중심 경향성, 전체 분포 요약|
|**위치 지표**|`quantile`, `iqr`|데이터의 위치 (사분위수)|
|**산포 지표**|`std`, `var`, `range`, `skew`, `kurt`|퍼짐 정도, 분포 형태|
|**변동성 지표**|`diff`, `momentum`|전기 대비 변화량, 변화의 가속도|

```python
df['score'].mean()
df['score'].median()
df['score'].quantile([0.25, 0.5, 0.75])
df['score'].std()
df['score'].var()
df['score'].skew()     # 왜도 (분포 비대칭 정도)
df['score'].kurt()     # 첨도 (뾰족한 정도)
df['score'].diff()     # 전행과의 차이
```

**momentum**: 이동 평균의 변화율로, 추세가 가속/감속 중인지를 나타낸다.

```python
# 5일 이동평균의 변화량 (모멘텀)
df['momentum'] = df['price'].rolling(5).mean().diff()
```

## 4. Pandas 요약 도구

### value_counts — 도수분포표

범주형 변수에서 각 값의 빈도를 세어 내림차순으로 반환한다.

```python
df['grade'].value_counts()
df['grade'].value_counts(normalize=True)   # 비율로 표시
df['grade'].value_counts(dropna=False)     # 결측값 포함

# 연속형도 bins로 구간화해서 사용 가능
df['score'].value_counts(bins=5)
```

### groupby — 범주별 집계 (멀티인덱스 지원)

특정 열을 기준으로 그룹을 나눠 집계한다. 결과가 MultiIndex로 반환된다.

```python
# 단일 그룹
df.groupby('grade')['score'].mean()

# 복수 그룹 — 결과가 MultiIndex
df.groupby(['grade', 'gender'])['score'].mean()

# 여러 집계 동시에
df.groupby('grade').agg({
    'score': ['mean', 'std', 'count'],
    'age':   'mean'
})

# transform — 그룹별 값을 원래 DataFrame 크기로 반환
df['group_mean'] = df.groupby('grade')['score'].transform('mean')

# filter — 조건 만족하는 그룹만 남김
df.groupby('grade').filter(lambda x: x['score'].mean() >= 80)
```

### agg — 복수 집계 함수 적용

`agg()`는 groupby 결과에 **여러 집계 함수를 동시에** 적용하는 함수다.  
단순히 `.mean()`이나 `.sum()` 하나만 쓰는 것과 달리, 열마다 다른 함수를 지정하거나 사용자 정의 함수를 넣을 수 있다.

```python
# ── 기본 사용법 ──────────────────────────────────
# 단일 함수: 모든 수치형 열에 동일 적용
df.groupby('grade').agg('mean')

# 리스트: 하나의 열에 여러 함수
df.groupby('grade')['score'].agg(['mean', 'std', 'min', 'max'])

# 딕셔너리: 열마다 다른 함수 지정
df.groupby('grade').agg({
    'score': ['mean', 'std', 'count'],
    'age':   'median',
    'name':  'count'
})
```

```python
# ── Named Aggregation (권장 방식) ────────────────
# 결과 열 이름을 직접 지정할 수 있어 가독성이 높음
df.groupby('grade').agg(
    평균점수   = ('score', 'mean'),
    표준편차   = ('score', 'std'),
    인원수     = ('score', 'count'),
    평균나이   = ('age',   'median'),
    합격률     = ('result', lambda x: (x == 'Pass').mean())
).reset_index()

#   grade  평균점수  표준편차  인원수  평균나이  합격률
# 0     A      92.0       2.1      15      23.0    0.93
# 1     B      83.0       3.4      22      22.5    0.72
# 2     C      74.0       4.2      13      21.8    0.31
```

```python
# ── 사용자 정의 함수 적용 ─────────────────────────
def iqr(x):
    return x.quantile(0.75) - x.quantile(0.25)

def cv(x):
    return x.std() / x.mean() * 100   # 변동계수 (%)

df.groupby('grade')['score'].agg(['mean', 'std', iqr, cv])
```

```python
# ── across 방식 (여러 열에 동일 함수) ────────────
# 수치형 열 전체에 동시 적용
df.groupby('grade').agg(
    {col: ['mean', 'std'] for col in df.select_dtypes('number').columns}
)
```

**agg에서 쓸 수 있는 주요 집계 함수**

|함수 문자열|설명|
|---|---|
|`'mean'`|평균|
|`'median'`|중위수|
|`'std'`|표준편차|
|`'var'`|분산|
|`'sum'`|합계|
|`'count'`|결측값 제외 개수|
|`'size'`|결측값 포함 전체 개수|
|`'min'` / `'max'`|최솟값 / 최댓값|
|`'first'` / `'last'`|첫 번째 / 마지막 값|
|`'nunique'`|고유값 개수|
|`lambda`|사용자 정의 함수|

**`count` vs `size` 차이**

```python
# count: 결측값 제외
# size: 결측값 포함 전체 개수
df.groupby('grade').agg(
    non_null_count = ('score', 'count'),
    total_size     = ('score', 'size')
)
```

**agg vs apply 차이**

|구분|`agg`|`apply`|
|---|---|---|
|목적|집계 (요약값 하나)|변환 (임의 형태 반환 가능)|
|반환|집계된 스칼라값|DataFrame, Series, 스칼라 모두 가능|
|속도|빠름 (최적화됨)|상대적으로 느림|
|사용 시점|그룹별 통계량 계산|복잡한 그룹 연산|

```python
# agg: 그룹별 평균 (스칼라 반환)
df.groupby('grade')['score'].agg('mean')

# apply: 그룹 내 z-score 계산 (Series 반환 → 원래 크기 유지)
df.groupby('grade')['score'].apply(lambda x: (x - x.mean()) / x.std())
```

### crosstab — 범주 행과 범주 열의 교차표

두 범주형 변수의 조합별 빈도를 표로 만든다. 분할표(contingency table)라고도 하며, 카이제곱 검정의 입력으로 사용된다.

```python
pd.crosstab(df['subject'], df['result'])
# result  Fail  Pass
# subject
# 과학       2     4
# 수학       3     3

# 비율로 표시
pd.crosstab(df['subject'], df['result'], normalize='index')  # 행 기준 비율

# 집계 함수 추가
pd.crosstab(df['subject'], df['result'],
            values=df['jumsu'], aggfunc='mean')  # 평균 점수
```

### pivot — 3축 구조

행 인덱스 / 열 인덱스 / 값 세 가지 축으로 데이터를 재구성한다.

```python
# pivot: 집계 없이 형태만 변환 (중복 없어야 함)
df.pivot(index='name', columns='subject', values='score')

# pivot_table: 집계 포함 (엑셀의 피벗과 동일)
pd.pivot_table(df,
    values='jumsu',
    index='subject',
    columns='result',
    aggfunc='mean',
    margins=True,        # 전체 합계 행/열 추가 (All)
    fill_value=0
)
# result   Fail  Pass   All
# Subject
# 과학      65.0  80.0  74.2
# 수학      72.5  85.0  78.8
# All       69.0  82.5  76.5
```

`margins=True`를 붙이면 슬라이드의 표처럼 `All` 행과 열이 자동으로 추가된다.

## 5. Long vs Wide 형태

데이터는 분석 목적에 따라 긴(Long) 형태와 넓은(Wide) 형태를 오가며 변환한다.

### Wide (넓은 형태)

사람이 읽기 편한 형태다. 각 변수가 별도의 열로 펼쳐져 있다.

```
Name   Exam   Subject  Result  Jumsu
영구   중간고사  수학    Pass    100.0
달구   중간고사  수학    Pass     80.0
이구   중간고사  수학    Fail     70.0
```

### Long (긴 형태)

분석 도구가 처리하기 편한 형태다. 변수명이 하나의 열로 모이고 값이 다른 열에 쌓인다.  
ggplot2, seaborn 등 대부분의 시각화 도구는 Long 형태를 요구한다.

```
Subject  Result  Count
과학      Fail      2
과학      Pass      4
수학      Fail      3
수학      Pass      3
```

### 변환 코드

```python
# Wide → Long
df_long = df.melt(
    id_vars=['name', 'exam'],
    value_vars=['kor', 'math', 'eng'],
    var_name='subject',
    value_name='score'
)

# Long → Wide
df_wide = df_long.pivot(
    index='name',
    columns='subject',
    values='score'
).reset_index()
```

## 7. 회귀 분석 vs SHAP 분석 — 핵심 차이

EDA에서 변수 간 관계를 파악한 뒤, 모델을 만들고 해석하는 단계에서 두 방법이 등장한다.

### 한 줄 요약

|구분|회귀 분석|SHAP 분석|
|---|---|---|
|**목적**|변수와 결과의 관계를 수식으로 모델링|모델의 예측 결과를 변수별 기여도로 설명|
|**해석 단위**|전체 데이터 기준 평균적 영향 ($\beta$)|개별 샘플 하나하나의 기여도|
|**적용 모델**|선형 모델|선형 + 트리 + 신경망 등 모든 모델|
|**출력**|계수($\beta$), p-value, $R^2$|변수별 SHAP 값, 시각화|
|**언제 쓰나**|관계를 설명하고 추론할 때|복잡한 모델의 예측을 해석할 때|

### 관계

```
EDA (변수 탐색)
   ↓
회귀 분석 (관계를 수식으로 모델링 + 통계적 유의성 검정)
   ↓
복잡한 모델로 확장 (랜덤 포레스트, XGBoost 등)
   ↓
SHAP (복잡한 모델의 예측을 변수별로 분해해서 해석)
```

회귀 분석은 **"왜 이런 관계가 있는가"를 통계적으로 설명**하고,  
SHAP은 **"이 예측값이 왜 나왔는가"를 사후에 해석**한다.

## 8. 요약 도구와 분석 방법 통합 정리

EDA의 각 단계에서 어떤 도구를 쓰고, 이후 어떤 분석으로 연결되는지 한눈에 정리한다.

```
데이터 입력
   ↓
──────────────────────────────────────────────────
단계 1: 단변수 탐색 (변수 하나씩 파악)
──────────────────────────────────────────────────
   수치형: describe() / hist() / boxplot()
           → 평균, std, 분위수, 이상치 확인
   범주형: value_counts()
           → 빈도, 비율, 도수분포
   ↓
──────────────────────────────────────────────────
단계 2: 이변수 탐색 (두 변수 관계 파악)
──────────────────────────────────────────────────
   수치 × 수치: corr() + heatmap / scatter
               → 상관관계 → 회귀 분석으로 연결
   범주 × 수치: groupby() + boxplot
               → 그룹 차이 → t-test / ANOVA로 연결
   범주 × 범주: crosstab() + heatmap
               → 빈도 교차 → 카이제곱 검정으로 연결
   ↓
──────────────────────────────────────────────────
단계 3: 다변수 탐색 (여러 변수 동시 파악)
──────────────────────────────────────────────────
   pivot_table()  → 두 범주 기준 집계 요약
   scatter_matrix → 변수 쌍 전체 산점도
   pairplot(hue)  → 그룹별 색상 구분
   ↓
──────────────────────────────────────────────────
단계 4: 모델링 및 해석
──────────────────────────────────────────────────
   선형 관계     → 회귀 분석 (β, R², p-value)
   변수 중요도   → SHAP (전체 기여도 순위)
   개별 예측 해석 → SHAP Waterfall / Force Plot
```

### 요약 도구별 다음 단계 연결

|요약 도구|파악하는 것|연결되는 분석|
|---|---|---|
|`describe()`|평균, 분산, 분위수|정규성 검정, 이상치 탐지|
|`value_counts()`|범주 빈도|불균형 확인, 범주화|
|`corr()`|변수 간 선형 관계|회귀 분석, 다중공선성 확인|
|`groupby()`|그룹별 차이|t-test, ANOVA, SHAP 그룹 비교|
|`crosstab()`|두 범주 교차 빈도|카이제곱 검정|
|`pivot_table()`|다차원 집계|보고서, 시각화|
|회귀 분석|변수 → 결과 관계 수식화|예측, 인과 추론|
|SHAP|예측 기여도 분해|모델 해석, 변수 중요도|

### 범주화 → 요약 → 시각화 → 해석 전체 예시

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import shap
from sklearn.ensemble import GradientBoostingRegressor

# ── 1. 범주화 ──────────────────────────────────────
df['score_group'] = pd.qcut(df['score'], q=4,
                             labels=['하', '중하', '중상', '상'])

# ── 2. 요약 (groupby + pivot_table) ───────────────
summary = df.groupby('score_group').agg(
    count      = ('score', 'count'),
    mean_score = ('score', 'mean'),
    pass_rate  = ('result', lambda x: (x == 'Pass').mean())
).reset_index()

cross = pd.crosstab(df['score_group'], df['result'],
                    margins=True, normalize='index')

# ── 3. 시각화 ─────────────────────────────────────
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

summary.plot(x='score_group', y='count',
             kind='bar', ax=axes[0], title='그룹별 인원', rot=0)

summary.plot(x='score_group', y='pass_rate',
             kind='bar', ax=axes[1], title='그룹별 합격률', rot=0)

sns.heatmap(df[['score', 'age', 'jumsu']].corr(),
            annot=True, fmt='.2f', cmap='coolwarm', ax=axes[2])
axes[2].set_title('상관 행렬')

plt.tight_layout()
plt.show()

# ── 4. 회귀 분석 (관계 수식화) ────────────────────
import statsmodels.api as sm

X = sm.add_constant(df[['score', 'age']])
model = sm.OLS(df['jumsu'], X).fit()
print(model.summary())   # β, p-value, R² 확인

# ── 5. SHAP (예측 기여도 해석) ────────────────────
gb = GradientBoostingRegressor().fit(df[['score', 'age']], df['jumsu'])

explainer  = shap.Explainer(gb, df[['score', 'age']])
shap_values = explainer(df[['score', 'age']])

shap.plots.bar(shap_values)        # 전체 변수 중요도
shap.plots.beeswarm(shap_values)   # 변수별 기여 방향
```

## 9. EDA 실전 흐름

Pandas를 활용한 EDA의 표준 흐름이다.

```

   df.isnull().sum() / df.boxplot()
   ↓

   value_counts() → 빈도 분포 파악
   ↓

   describe() / hist() / boxplot()
   ↓
5. 변수 간 관계 탐색
   corr() → heatmap / scatter_matrix
   ↓
6. 그룹별 비교
   groupby() / crosstab() / pivot_table()
   ↓
7. 시각화로 패턴 확인
   분포 / 추세 / 비교 / 변화
   ↓
8. 모델링 및 해석
   회귀 분석 (관계 수식화) → SHAP (예측 기여도 분해)
   ↓
9. 인사이트 도출 및 의사결정
```
