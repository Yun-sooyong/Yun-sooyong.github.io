# Data Summarization & EDA

데이터 분석의 목표는 데이터에서 **인사이트(insight)** 를 뽑아내는 것이다.  
그 과정은 단순히 숫자를 보는 것이 아니라 다음 흐름으로 이어진다.

```
데이터 → 정보 → 패턴 → 해석 → 의사결정
```

---

## 1. 데이터 분석의 종류

|분석 종류|설명|질문 형태|
|---|---|---|
|**기술 분석 (Descriptive)**|데이터를 요약하고 집계해서 현재 상태 파악|"지난달 매출은 얼마였나?"|
|**탐색적 분석 (Exploratory, EDA)**|가설 없이 데이터를 탐색해서 패턴과 구조 발견|"어떤 변수가 중요한가?"|
|**추론 분석 (Inferential)**|표본으로 모집단을 추론, 가설검정|"이 차이가 통계적으로 유의한가?"|
|**예측 분석 (Predictive)**|과거 데이터로 미래를 예측|"다음 달 매출은 얼마일까?"|
|**인과관계 분석 (Casual)**|원인과 결과의 관계를 밝힘|"할인 행사가 매출을 늘렸는가?"|

분석 순서는 보통 기술 → 탐색 → 추론 → 예측 → 인과관계 순으로 깊어진다.

---

## 2. 데이터를 요약하는 5가지 기술

### 1. 기술적 통계 (Descriptive Statistics)

수치로 데이터의 중심, 퍼짐, 형태를 요약한다.

```python
df.describe()          # 수치형 변수 기술통계 한 번에
df.describe(include='all')  # 범주형 포함
```

### 2. 시각화 — 분포, 추세, 비교, 변화

눈으로 패턴을 파악한다. 수치만으로 놓치는 이상치, 분포 모양, 집단 간 차이를 시각화로 확인한다.

### 3. 관계 분석

변수 간의 상관관계나 연관성을 파악한다. 상관 행렬, 산점도, 크로스탭이 여기에 해당한다.

### 4. 데이터 집계

그룹별로 묶어서 요약한다. `groupby`, `pivot_table`, `crosstab` 등이 핵심 도구다.

### 5. 차원 축소 기술

변수가 너무 많을 때 PCA, t-SNE 등으로 중요한 정보만 남기고 차원을 줄인다.

---

## 3. 집계 함수의 종류

|종류|함수|설명|
|---|---|---|
|**통계적 집계**|`mean`, `median`, `describe`|중심 경향성, 전체 분포 요약|
|**위치 지표**|`quantile`, `iqr`|데이터의 위치 (사분위수)|
|**산포 지표**|`std`, `var`, `range`, `skew`, `kurt`|퍼짐 정도, 분포 형태|
|**변동성 지표**|`diff`, `momentum`|전기 대비 변화량, 변화의 가속도|

```python
df['score'].mean()
df['score'].median()
df['score'].quantile([0.25, 0.5, 0.75])
df['score'].std()
df['score'].var()
df['score'].skew()     # 왜도 (분포 비대칭 정도)
df['score'].kurt()     # 첨도 (뾰족한 정도)
df['score'].diff()     # 전행과의 차이
```

**momentum**: 이동 평균의 변화율로, 추세가 가속/감속 중인지를 나타낸다.

```python
# 5일 이동평균의 변화량 (모멘텀)
df['momentum'] = df['price'].rolling(5).mean().diff()
```

## 4. Pandas 요약 도구

### value_counts — 도수분포표

범주형 변수에서 각 값의 빈도를 세어 내림차순으로 반환한다.

```python
df['grade'].value_counts()
df['grade'].value_counts(normalize=True)   # 비율로 표시
df['grade'].value_counts(dropna=False)     # 결측값 포함

# 연속형도 bins로 구간화해서 사용 가능
df['score'].value_counts(bins=5)
```

### groupby — 범주별 집계 (멀티인덱스 지원)

특정 열을 기준으로 그룹을 나눠 집계한다. 결과가 MultiIndex로 반환된다.

```python
# 단일 그룹
df.groupby('grade')['score'].mean()

# 복수 그룹 — 결과가 MultiIndex
df.groupby(['grade', 'gender'])['score'].mean()

# 여러 집계 동시에
df.groupby('grade').agg({
    'score': ['mean', 'std', 'count'],
    'age':   'mean'
})

# transform — 그룹별 값을 원래 DataFrame 크기로 반환
df['group_mean'] = df.groupby('grade')['score'].transform('mean')

# filter — 조건 만족하는 그룹만 남김
df.groupby('grade').filter(lambda x: x['score'].mean() >= 80)
```

### crosstab — 범주 행과 범주 열의 교차표

두 범주형 변수의 조합별 빈도를 표로 만든다. 분할표(contingency table)라고도 하며, 카이제곱 검정의 입력으로 사용된다.

```python
pd.crosstab(df['subject'], df['result'])
# result  Fail  Pass
# subject
# 과학       2     4
# 수학       3     3

# 비율로 표시
pd.crosstab(df['subject'], df['result'], normalize='index')  # 행 기준 비율

# 집계 함수 추가
pd.crosstab(df['subject'], df['result'],
            values=df['jumsu'], aggfunc='mean')  # 평균 점수
```

### pivot — 3축 구조

행 인덱스 / 열 인덱스 / 값 세 가지 축으로 데이터를 재구성한다.

```python
# pivot: 집계 없이 형태만 변환 (중복 없어야 함)
df.pivot(index='name', columns='subject', values='score')

# pivot_table: 집계 포함 (엑셀의 피벗과 동일)
pd.pivot_table(df,
    values='jumsu',
    index='subject',
    columns='result',
    aggfunc='mean',
    margins=True,        # 전체 합계 행/열 추가 (All)
    fill_value=0
)
# result   Fail  Pass   All
# Subject
# 과학      65.0  80.0  74.2
# 수학      72.5  85.0  78.8
# All       69.0  82.5  76.5
```

`margins=True`를 붙이면 슬라이드의 표처럼 `All` 행과 열이 자동으로 추가된다.

## 5. Long vs Wide 형태

데이터는 분석 목적에 따라 긴(Long) 형태와 넓은(Wide) 형태를 오가며 변환한다.

### Wide (넓은 형태)

사람이 읽기 편한 형태다. 각 변수가 별도의 열로 펼쳐져 있다.

```
Name   Exam   Subject  Result  Jumsu
영구   중간고사  수학    Pass    100.0
달구   중간고사  수학    Pass     80.0
이구   중간고사  수학    Fail     70.0
```

### Long (긴 형태)

분석 도구가 처리하기 편한 형태다. 변수명이 하나의 열로 모이고 값이 다른 열에 쌓인다.  
ggplot2, seaborn 등 대부분의 시각화 도구는 Long 형태를 요구한다.

```
Subject  Result  Count
과학      Fail      2
과학      Pass      4
수학      Fail      3
수학      Pass      3
```

### 변환 코드

```python
# Wide → Long
df_long = df.melt(
    id_vars=['name', 'exam'],
    value_vars=['kor', 'math', 'eng'],
    var_name='subject',
    value_name='score'
)

# Long → Wide
df_wide = df_long.pivot(
    index='name',
    columns='subject',
    values='score'
).reset_index()
```

## 6. EDA 실전 흐름

Pandas를 활용한 EDA의 표준 흐름이다.

```
1. 데이터 로드 및 기본 확인
   df.shape / df.info() / df.head() / df.describe()
   ↓
2. 결측값 및 이상치 확인
   df.isnull().sum() / df.boxplot()
   ↓
3. 범주형 변수 탐색
   value_counts() → 빈도 분포 파악
   ↓
4. 수치형 변수 탐색
   describe() / hist() / boxplot()
   ↓
5. 변수 간 관계 탐색
   corr() → heatmap / scatter_matrix
   ↓
6. 그룹별 비교
   groupby() / crosstab() / pivot_table()
   ↓
7. 시각화로 패턴 확인
   분포 / 추세 / 비교 / 변화
   ↓
8. 인사이트 도출 및 가설 수립
```

### 범주화 → 요약 → 시각화 흐름 (Pandas EDA 패턴)

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 1. 범주화
df['score_group'] = pd.qcut(df['score'], q=4, labels=['하', '중하', '중상', '상'])

# 2. 데이터 요약
summary = df.groupby('score_group').agg(
    count=('score', 'count'),
    mean_score=('score', 'mean'),
    pass_rate=('result', lambda x: (x == 'Pass').mean())
).reset_index()

# 3. 시각화
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

summary.plot(x='score_group', y='count', kind='bar', ax=axes[0], title='그룹별 인원')
summary.plot(x='score_group', y='pass_rate', kind='bar', ax=axes[1], title='그룹별 합격률')

plt.tight_layout()
plt.show()
```
