# 시각화와 탐색적 데이터 분석 (EDA)

데이터를 수치로만 보면 놓치는 패턴이 많다. 시각화는 그 패턴을 직관적으로 드러내는 도구다.  
이 문서는 시각화의 목적, ggplot2의 핵심 구조, 고차원 데이터 표현 방법, 그리고 흔히 발생하는 오류와 해결 방법을 정리한다.

---

## 1. 데이터 시각화의 목적

### 데이터 요약 (Summarization)

복잡하고 방대한 원시 데이터(Raw Data)를 인간이 직관적으로 이해할 수 있도록 **단순화**하는 과정이다.

- 분산, 평균, 사분위수 등 통계 수치로 데이터를 정제한다
- 요약된 수치를 시각적 요소로 변환해 전체 패턴을 파악한다

### 시각화로 알 수 있는 것

- **변수 간 관계**: 두 개 이상의 변수가 서로 어떻게 연관되는지(상관관계, 경향성)를 한눈에 볼 수 있다
- **이상치 탐지**: 수치만 볼 때는 발견하기 어려운 예외값이나 특이한 패턴을 식별할 수 있다
- **분포 파악**: 데이터가 어느 값 근처에 몰려 있는지, 얼마나 퍼져 있는지를 직관적으로 파악할 수 있다

---

## 2. ggplot2의 핵심 구조

ggplot2는 **레이어를 쌓는 방식**으로 그래프를 만든다.  
데이터 → 미적 요소 매핑 → 기하학적 객체 → 통계 변환 → 좌표계 순서로 구성된다.

```r
ggplot(data = df, aes(x = score, y = grade)) +
  geom_point() +
  geom_smooth(method = "lm")
```

### stats — 통계적 변환

`geom_` 함수 내부에 기본적으로 통계 변환이 포함되어 있다. 예를 들어 `geom_histogram()`은 자동으로 구간별 빈도를 계산한다.

필요할 때는 `stat_summary()`로 명시적으로 지정해서 평균, 신뢰구간 등을 직접 계산해 표현할 수 있다.

```r
# 그룹별 평균을 점으로 표시
stat_summary(fun = mean, geom = "point", size = 3)

# 평균 ± 표준편차 범위를 에러바로 표시
stat_summary(fun.data = mean_sd, geom = "errorbar")
```

### ggsave — 고품질 저장

```r
ggsave("plot.png", width = 8, height = 5, dpi = 300)
```

해상도(`dpi`)와 크기를 지정해서 저장할 수 있다. 보고서나 논문용으로는 300dpi 이상을 권장한다.

## 3. 그래프 종류 선택

데이터의 성격에 따라 어떤 그래프를 쓸지가 달라진다.

### 히스토그램 vs 막대 그래프

|구분|히스토그램|막대 그래프|
|---|---|---|
|데이터 종류|연속형 수치 데이터|범주형 데이터|
|막대 간격|붙어 있음 (연속성 표현)|간격 있음|
|목적|분포 파악|크기 비교|
|R 함수|`geom_histogram()`|`geom_bar()`, `geom_col()`|

**히스토그램**: 데이터를 자동으로 구간(bin)으로 나눠 각 구간의 빈도를 시각화한다. 막대가 붙어 있는 것은 데이터가 연속된다는 의미다.

```r
ggplot(df, aes(x = score)) +
  geom_histogram(binwidth = 5, fill = "steelblue", color = "white")
```

**막대 그래프**: 범주별 크기를 비교한다. `geom_bar()`는 빈도를 자동 계산하고, `geom_col()`은 직접 높이를 지정한다.

```r
ggplot(df, aes(x = grade, fill = grade)) +
  geom_bar()
```

### 자주 쓰는 그래프 종류

|그래프|함수|목적|
|---|---|---|
|산점도|`geom_point()`|두 변수의 관계|
|선 그래프|`geom_line()`|시계열, 추세|
|박스플롯|`geom_boxplot()`|분포, 이상치 확인|
|바이올린 플롯|`geom_violin()`|분포 모양 시각화|
|히스토그램|`geom_histogram()`|단일 변수 분포|
|밀도 그래프|`geom_density()`|부드러운 분포 곡선|

## 4. 고차원 데이터 표현

2차원 화면에 여러 변수를 동시에 표현하는 두 가지 전략이다.

### 미적 요소 매핑 (Aesthetics)

색상, 모양, 크기, 투명도 같은 시각적 속성에 추가 변수를 매핑해서 차원을 늘린다.  
`group_by()`와 비슷한 논리로 데이터를 분류해 시각적으로 구분한다.

```r
ggplot(df, aes(x = score, y = gpa, color = grade, shape = gender, size = age)) +
  geom_point()
```

|속성|설명|
|---|---|
|`color`|색상으로 집단 구분|
|`shape`|모양으로 집단 구분|
|`size`|크기로 수치 표현|
|`alpha`|투명도로 밀도 표현|
|`fill`|채우기 색상|

주의: 매핑을 너무 많이 쓰면 오히려 가독성이 떨어진다. 한 그래프에서 3개 이상의 속성을 동시에 쓰는 것은 피하는 것이 좋다.

### 화면 분할 (Facets)

범주형 변수에 따라 화면을 여러 개의 작은 그래프로 분할한다.  
서로 다른 집단을 **동일한 기준**으로 나란히 비교할 때 유용하다.

```r
# 한 변수로 분할
ggplot(df, aes(x = score)) +
  geom_histogram() +
  facet_wrap(~grade)

# 두 변수로 분할 (격자 형태)
ggplot(df, aes(x = score)) +
  geom_histogram() +
  facet_grid(gender ~ grade)
```

`facet_wrap()`은 1차원으로 나열하고, `facet_grid()`는 두 변수를 행과 열로 배치한다.

## 5. 시각화 오류와 해결 방법

데이터를 그대로 그리면 정보가 왜곡되거나 누락되는 경우가 있다.

### 데이터 중복 (Overplotting)

데이터 포인트가 너무 많거나 같은 위치에 겹쳐서 실제 밀도를 가늠하기 어려운 상황이다.

```r
# Jitter: 점을 미세하게 흩뿌림
geom_jitter(width = 0.2, height = 0.2)

# Alpha: 투명도를 낮춰 겹침 표현
geom_point(alpha = 0.3)

# Rug: 축에 데이터 위치를 눈금으로 표시
geom_rug(sides = "b")
```

Jitter와 alpha는 함께 쓰면 더 효과적이다.

### 빈 데이터 (Gap)

중간에 데이터가 없어 흐름이 끊기는 상황이다.  
보간법(Interpolation)으로 빈 구간을 통계적 추정치로 채워 자연스럽게 연결한다.

```r
# 회귀선으로 경향 파악
geom_smooth(method = "lm")

# 로컬 평균으로 부드럽게 연결
geom_smooth(method = "loess")
```

### 고주파 데이터 (High-frequency)

노이즈가 많아 세밀한 등락이 반복되어 전체 경향을 파악하기 어려운 상황이다.  
평균이나 대표값으로 단순화해서 전체 흐름(Trend)을 보기 쉽게 만든다.

```r
# 이동평균으로 노이즈 제거
geom_smooth(span = 0.3)

# 구간별 평균으로 단순화
stat_summary(fun = mean, geom = "line")
```

### 문제별 해결 방법 정리

|문제|원인|해결 방법|
|---|---|---|
|Overplotting|데이터 포인트 겹침|Jitter, Alpha, Rug|
|Gap|중간 데이터 누락|보간법 (geom_smooth)|
|High-frequency|노이즈가 많음|이동평균, 단순화|

## 6. 좌표계의 종류

분석하려는 데이터의 성격에 따라 좌표계를 선택한다.

|좌표계|특징|활용 사례|
|---|---|---|
|데카르트 (Cartesian)|X-Y 평면, 가장 보편적|대부분의 일반 그래프|
|극 좌표 (Polar)|각도와 거리 사용|파이 차트, 바람 장미|
|구형 좌표 (Spherical)|3차원 공간 표현|위도/경도, 지구 모델링|

```r
# 막대 그래프를 파이 차트로 변환
ggplot(df, aes(x = "", fill = grade)) +
  geom_bar() +
  coord_polar(theta = "y")

# 좌우 반전
coord_flip()

# 축 범위 지정
coord_cartesian(xlim = c(0, 100), ylim = c(0, 50))
```

## 7. 시각화 최종 체크리스트

그래프를 완성하기 전에 확인할 사항들이다.

- **통계적 정합성**: 평균과 분산이 실제 분포를 왜곡 없이 대변하고 있는가
- **미적 효율성**: 너무 많은 속성 매핑(color, shape, size 등)으로 가독성을 해치고 있지 않은가
- **정밀도 유지**: 중복 데이터가 누락되지 않도록 jitter나 alpha를 적절히 사용했는가
- **축 레이블**: 단위와 변수명이 명확하게 표시되어 있는가
- **범례**: 색상이나 모양의 의미가 범례에 명확히 설명되어 있는가
