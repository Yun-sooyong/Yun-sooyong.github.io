# 회귀 분석 (Regression Analysis)

$y$와 $x$의 관계 $y \sim x$ 에서, $x$가 $y$를 얼마나 설명하는지 파악하고 예측하는 분석이다.  
회귀 분석의 목표는 데이터를 가장 잘 대표하는 **회귀선(Regression Line)** 을 찾는 것이다.

---

## 1. 회귀선과 최소제곱법

### 회귀선이란

데이터 전체를 하나의 직선으로 요약한 것이다.  
단순히 평균을 쓰면 개별 데이터와의 차이가 너무 커서 예측에 쓰기 어렵다. 회귀선은 이 차이(잔차)를 최소화하는 선을 찾는다.

### 최소제곱법 (Ordinary Least Squares, OLS)

임의의 직선 하나에서 각 데이터 포인트까지의 거리(잔차)를 제곱해서 모두 더한 값이 **가장 작아지는 선**을 찾는 방법이다.

$$\min \sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

제곱을 쓰는 이유는 잔차의 방향(양수/음수)에 관계없이 크기만 보기 위해서다.

### 선형 회귀 모델 수식

$$Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i$$

|기호|이름|의미|
|---|---|---|
|$Y_i$|종속변수|예측하려는 값|
|$\beta_0$|절편 (Intercept)|$x=0$일 때의 $y$ 값|
|$\beta_1$|기울기 (Slope Coefficient)|$x$ 한 단위 증가 시 $y$의 변화량|
|$X_i$|독립변수|예측에 사용하는 값|
|$\varepsilon_i$|오차항 (Random Error)|모델로 설명하지 못하는 부분|

---

## 2. 제곱합 분해 (Sum of Squares)

회귀 분석에서 데이터의 변동을 세 가지로 쪼갠다.

$$SSTO = SSR + SSE$$

|기호|이름|수식|의미|
|---|---|---|---|
|SSTO|전체 제곱합|$\sum(y_i - \bar{y})^2$|전체 데이터의 변동|
|SSR|회귀 제곱합|$\sum(\hat{y}_i - \bar{y})^2$|회귀선이 설명하는 변동|
|SSE|잔차 제곱합|$\sum(y_i - \hat{y}_i)^2$|회귀선이 설명하지 못하는 변동|

- $\bar{y}$: 실제값의 평균
- $\hat{y}_i$: 회귀선이 예측한 값

직관적으로 보면, **SSTO는 전체 파이**, **SSR은 모델이 설명한 조각**, **SSE는 설명 못한 조각**이다.

이미지 예시 수치:

- SSR = 6679.3
- SSE = 1708.5
- SSTO = 8387.8 (SSR + SSE)

---

## 3. 결정계수 ($R^2$)

회귀선이 데이터를 얼마나 잘 설명하는지를 0~1 사이의 수치로 나타낸다.

$$R^2 = \frac{SSR}{SSTO} = 1 - \frac{SSE}{SSTO}$$

- $R^2 = 1$: 회귀선이 데이터를 완벽하게 설명 (모든 점이 선 위에 있음)
- $R^2 = 0$: 회귀선이 데이터를 전혀 설명하지 못함
- 일반적으로 0.7 이상이면 설명력이 좋다고 본다

### 수정된 $R^2$ (Adjusted $R^2$)

변수를 추가하면 $R^2$는 무조건 높아지는 성질이 있다. 유의미하지 않은 변수를 넣어도 올라가기 때문에 변수 수가 많아질수록 $R^2$만으로 판단하면 과대평가가 된다.

수정된 $R^2$는 변수 수에 대한 **패널티**를 적용해 이 문제를 보정한다.

$$R^2_{adj} = 1 - \frac{SSE/(n-p-1)}{SSTO/(n-1)}$$

- $n$: 표본 크기
- $p$: 독립변수 수

모델 비교 시에는 $R^2$보다 수정된 $R^2$를 보는 것이 더 신뢰할 수 있다.

## 4. 계수 가설 검정

회귀계수($\beta_1$)가 실제로 의미 있는 값인지 검정한다.  
"$x$가 $y$에 영향을 준다"는 것을 통계적으로 확인하는 과정이다.

$$H_0: \beta_1 = 0 \quad \text{(x는 y에 영향을 주지 않는다)}$$ $$H_A: \beta_1 \neq 0 \quad \text{(x는 y에 영향을 준다)}$$

### t-통계량

$$t = \frac{\hat{\beta}_1 - 0}{SE(\hat{\beta}_1)} = \frac{m - \mu}{s / \sqrt{n}}$$

t-value와 p-value를 확인해서 $p < 0.05$이면 해당 계수는 유의미하다고 판단한다.

독립변수가 여러 개인 다중회귀에서는 각 계수마다 개별적으로 t-검정을 수행한다.

---

## 5. F 통계량 — 모델 전체의 유의성 검정

계수 가설 검정이 개별 변수의 유의성을 보는 것이라면, F 통계량은 **모델 전체**가 유의미한지를 검정한다.

$$F = \frac{MSR}{MSE}$$

|기호|이름|계산|
|---|---|---|
|MSR|평균 회귀 제곱|$SSR / df_1$ (단순회귀에서 $df_1 = 1$)|
|MSE|평균 잔차 제곱|$SSE / (n-p-1)$|

- F값이 크다 → 회귀선이 설명하는 변동이 설명 못 하는 변동보다 크다 → 모델이 유의미하다
- F분포의 p-value로 최종 판단: $p < 0.05$이면 모델이 통계적으로 유의미하다

```r
# R에서 회귀분석
model <- lm(y ~ x, data = df)
summary(model)
# - Coefficients: 각 계수의 t-value, p-value
# - R-squared: 결정계수
# - F-statistic: 모델 전체 유의성
```

## 6. 모델 평가 체크리스트

회귀 모델을 만들고 나서 순서대로 확인할 사항들이다.

|확인 항목|방법|판단 기준|
|---|---|---|
|모델이 통계적으로 유의한가|F통계량 p-value|$p < 0.05$|
|개별 계수가 유의한가|t-value, p-value|$p < 0.05$|
|설명력이 충분한가|$R^2$, 수정된 $R^2$|높을수록 좋음|
|데이터에 잘 fitting됐는가|잔차 그래프|무작위 패턴이어야 함|
|선형 회귀가 적절한가|상관분석, 산점도|선형 패턴 확인|

## 7. 잔차(Residual) 4가지 가정

회귀 분석의 결과를 신뢰하려면 잔차가 다음 네 가지 조건을 만족해야 한다.  
이 조건이 깨지면 계수 추정이나 가설검정 결과를 신뢰하기 어렵다.

### 정규성 (Normality)

잔차가 정규분포를 따라야 한다.

```r
shapiro.test(residuals(model))   # p > 0.05이면 정규성 만족
qqnorm(residuals(model))         # QQ 플롯으로 시각적 확인
qqline(residuals(model))
```

### 등분산성 (Homoscedasticity)

잔차의 분산이 $x$ 값에 관계없이 일정해야 한다.  
잔차 그래프에서 $x$가 커질수록 잔차가 퍼지는 패턴(나팔 모양)이 보이면 등분산성 위반이다.

```r
plot(fitted(model), residuals(model))  # 잔차 vs 예측값 그래프
```

등분산성이 깨지면 로그 변환이나 가중최소제곱법(WLS)을 고려한다.

### 독립성 (Independence)

잔차들 사이에 패턴(자기상관)이 없어야 한다.  
시계열 데이터에서 특히 문제가 되는데, 이전 시점의 오차가 다음 시점의 오차에 영향을 주는 경우다.

```r
car::durbinWatsonTest(model)  # Durbin-Watson 검정
# 값이 2에 가까울수록 자기상관 없음
```

### 선형성 (Linearity)

$x$와 $y$ 사이에 실제로 선형 관계가 있어야 한다.  
비선형 관계에 선형 모델을 억지로 맞추면 잔차에 곡선 패턴이 나타난다.

```r
plot(df$x, residuals(model))  # x vs 잔차 그래프로 확인
```

## 8. 모델 복잡도와 AIC

### 편향-분산 트레이드오프 (Bias-Variance Tradeoff)

변수를 추가할수록(모델이 복잡해질수록) 다음과 같은 일이 일어난다.

- **편향(Bias)** 감소: 학습 데이터에 더 잘 맞는다
- **분산(Variance)** 증가: 새로운 데이터에 대한 예측이 불안정해진다
- **총 오류(Total Error)**: 처음에는 줄다가, 과적합이 시작되면 다시 늘어난다

```
총 오류
    │ \         /
    │  \  Total Error
    │   \     /
    │    \   /  Variance
    │     \_/
    │      Bias
    └──────────────── 모델 복잡도
```

적절한 복잡도(Optimal Model Complexity) 지점이 총 오류가 가장 작은 곳이다.

### AIC (Akaike Information Criterion)

$$AIC = 2k - 2\ln(L)$$

- $k$: 모델의 파라미터(변수) 수
- $L$: 우도(Likelihood) — 현재 데이터가 이 모델에서 나올 확률

**AIC는 작을수록 좋다.** 여러 모델을 비교할 때 AIC가 가장 낮은 모델을 선택한다.

- $2k$ 항: 변수가 많아질수록 패널티 부여 → 불필요한 변수 추가를 억제
- $-2\ln(L)$ 항: 모델이 데이터를 잘 설명할수록 작아짐

AIC는 절댓값보다 **모델 간 상대적 비교**에 의미가 있다. 음수가 나올 수도 있으며, 음수 자체가 좋다는 의미가 아니라 비교했을 때 더 낮은 쪽이 좋다는 의미다.

```r
AIC(model1)
AIC(model2)
# 더 낮은 쪽이 더 나은 모델
```

## 9. 편향-분산의 시각적 이해 (과녁 비유)

|상태|의미|
|---|---|
|Low Bias + Low Variance|이상적인 모델. 정확하고 안정적|
|Low Bias + High Variance|과적합(Overfitting). 학습 데이터엔 잘 맞지만 새 데이터엔 흔들림|
|High Bias + Low Variance|과소적합(Underfitting). 모델이 너무 단순해서 패턴을 못 잡음|
|High Bias + High Variance|최악의 모델|

## 10. 로지스틱 회귀 (Logistic Regression)

선형 회귀는 $y$가 연속형일 때 쓰지만, **$y$가 범주형(0 또는 1)일 때** 는 로지스틱 회귀를 사용한다.

$$P(y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$

이 함수를 **시그모이드(Sigmoid)** 함수라고 한다. 어떤 입력값에서도 출력이 0~1 사이로 유지되기 때문에 확률로 해석할 수 있다.

|구분|선형 회귀|로지스틱 회귀|
|---|---|---|
|종속변수|연속형|범주형 (0/1)|
|출력|예측값|확률 (0~1)|
|손실함수|최소제곱법(OLS)|최대우도법(MLE)|
|R 함수|`lm()`|`glm(..., family = binomial)`|

```r
model_logit <- glm(y ~ x1 + x2, data = df, family = binomial)
summary(model_logit)
```

## 11. 생존 분석 (Survival Analysis)

로지스틱 회귀에 **시간 개념**을 더한 분석이다.  
"사건이 발생하는가"만이 아니라 "언제 발생하는가"까지 분석한다.

예를 들어 환자가 치료 후 재발하기까지 걸리는 시간, 기계가 고장나기까지의 수명 분석 등에 쓰인다.

중요한 특징은 **중도절단(Censoring)** 을 처리할 수 있다는 점이다. 연구 기간 내에 사건이 발생하지 않은 경우(관찰 종료, 탈락 등)의 데이터도 분석에 포함시킬 수 있다.

```r
library(survival)
fit <- survfit(Surv(time, status) ~ group, data = df)
plot(fit)  # 카플란-마이어 곡선
```

## 12. 전체 흐름 정리

```
데이터 준비
   ↓
탐색적 분석 (산점도, 상관분석)
   ↓
모델 적합 (lm / glm)
   ↓
모델 평가
   ├─ F통계량: 모델 전체 유의성
   ├─ t-value: 개별 계수 유의성
   ├─ R²: 설명력
   └─ 잔차 그래프: 가정 확인
   ↓
모델 선택 (AIC 비교)
   ↓
예측 / 해석
```
