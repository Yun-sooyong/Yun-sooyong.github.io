# 행렬의 정의, 연산 및 응용 분석

## 1. 행렬의 기본 구조

행렬은 데이터를 **행(Row)과 열(Column)의 격자 형태로 배열**하여 특징을 추출하고 변환하는 수학적 도구다.

### 행과 열의 의미

- **행(Row)**: 개별 데이터 포인트, 하나의 관측치(레코드)
- **열(Column)**: 데이터의 특징(Features)이나 속성(Attribute)

예를 들어 학생 성적 데이터라면:

- 행: 학생 1명
- 열: 국어 점수, 영어 점수, 수학 점수

데이터 분석에서는 주로 **열 중심으로 사고**한다. 변수 간 관계나 변수별 통계를 분석하기 때문이다.

### 메모리 관점

컴퓨터 메모리는 본질적으로 1차원 구조다. 2차원처럼 보이는 행렬도 내부적으로는 **1차원 형태로 저장**된다. R에서 `matrix()`로 만들면 기본적으로 열 우선(column-major) 방식으로 저장된다.

---

## 2. 행렬의 곱

행렬의 곱은 단순히 같은 위치의 원소를 곱하는 것이 아니다. **내적(dot product) 연산의 연장선**이다.

### 계산 조건

앞 행렬의 **열 수**와 뒤 행렬의 **행 수**가 같아야 한다.

$$A_{m \times n} \times B_{n \times p} = C_{m \times p}$$

예: `2×3` 행렬과 `3×4` 행렬을 곱하면 `2×4` 행렬이 나온다.

### 연산자 구분 (R 기준)

- `*` : 요소별 곱 (같은 위치의 원소끼리 곱함)
- `%*%` : 행렬곱 (행과 열의 내적)

```r
A %*% B   # 행렬곱
A * B     # 요소별 곱 (크기가 같아야 함)
```

### 의미

앞 벡터가 뒤 벡터를 기준으로 **투영(Projection)**된다고 해석한다. 내적이 이루어지는 순간 **유사도 투영**의 의미를 가진다. 이 개념은 머신러닝에서 특징(feature) 간의 관계를 수치로 표현할 때 핵심이 된다.

## 3. 주요 행렬 연산 법칙

### 전치행렬 (Transpose)

행과 열을 뒤바꾼 행렬이다. $A$의 전치행렬은 $A^T$로 표기한다.

```r
t(M)   # 전치행렬
```

**중요한 성질**: 어떤 행렬 $A$에 대해 $A \times A^T$를 수행하면 결과는 항상 **정방행렬**이 된다.

$$A_{m \times n} \times A^T_{n \times m} = C_{m \times m}$$

이 성질이 중요한 이유는, 비정방행렬도 전치와 곱하면 정방행렬로 만들 수 있어 **역행렬 계산이나 분해 연산**이 가능해지기 때문이다.

### 정방행렬의 제곱 → 대칭행렬

정방행렬을 제곱하면 대칭행렬의 성질을 갖게 된다.

### 대칭행렬의 분해

대칭행렬을 분해하면 **고유축(고유벡터)** 과 **고유치(고유값)** 을 얻는다. 이때 각 고유축은 서로 **직교**한다. 이 성질은 PCA 같은 분석 기법의 기초가 된다.

---

## 4. 정방행렬의 종류와 성질

행과 열의 크기가 같은 ($n \times n$) 행렬 내에서 정의되는 주요 행렬들이다.

|종류|설명 및 특징|
|---|---|
|**단위행렬 (Identity)**|주대각 성분이 모두 1이고 나머지는 0. $A \times I = A$가 성립하며 연산의 크기를 결정함|
|**역행렬 (Inverse)**|행렬에는 나눗셈이 없으므로 역행렬을 곱해 연산. $A \times A^{-1} = I$|
|**대칭행렬 (Symmetric)**|주대각선을 기준으로 상하 원소가 대칭. $A = A^T$|
|**대각행렬 (Diagonal)**|주대각 성분 외의 모든 원소가 0|
|**삼각행렬 (Triangular)**|주대각선 기준으로 위(상삼각) 또는 아래(하삼각)의 원소들이 모두 0|
|**직교행렬 (Orthogonal)**|행벡터와 열벡터들이 서로 직교하며 크기가 1. $A^T = A^{-1}$|

### 단위행렬과 역행렬의 관계

단위행렬은 숫자에서 1과 같은 역할을 한다.

$$A \times I = A$$

역행렬은 숫자에서 $\frac{1}{a}$와 같은 역할을 한다.

$$A \times A^{-1} = I$$

역행렬이 존재하려면 행렬이 정방행렬이어야 하고, **행렬식(determinant)이 0이 아니어야** 한다. 행렬식이 0이면 역행렬이 존재하지 않는 **특이행렬(singular matrix)** 이 된다.

### 직교행렬의 특징

$A^T = A^{-1}$이 성립하기 때문에 $A \times A^T = I$가 된다. 즉, 전치행렬이 역행렬이 된다는 점에서 연산이 매우 효율적이다. 회전 변환이나 PCA의 고유벡터 행렬이 이 성질을 가진다.

## 5. 행렬 분해 (Matrix Decomposition)

데이터의 본질적인 구조를 파악하기 위해 행렬을 쪼개는 기법이다.

### 고유값 분해 (Eigenvalue Decomposition)

주로 **정방행렬**을 대상으로 수행한다.

정방행렬 $A$를 다음처럼 분해한다.

$$A = P \Lambda P^{-1}$$

- $P$: 고유벡터를 열로 가진 행렬 (새로운 축)
- $\Lambda$: 고유값을 대각 성분으로 가진 대각행렬 (각 축의 중요도)

```r
eigen(A)   # 고유값과 고유벡터를 동시에 반환
```

**직관적으로**: 행렬이 데이터에 가하는 변환을 분석했을 때, 방향은 바뀌지 않고 크기만 바뀌는 벡터가 **고유벡터**, 그 크기 변화량이 **고유값**이다.

### 특이값 분해 (SVD, Singular Value Decomposition)

**비정방행렬을 포함한 모든 행렬**에 적용 가능한 일반화된 분해 기법이다.

$$A = U \Sigma V^T$$

- $U$: 입력 공간의 축 (행 방향)
- $\Sigma$: 특이값을 대각 성분으로 가진 행렬 (각 축의 중요도)
- $V^T$: 출력 공간의 축 (열 방향)

```r
svd(A)   # U, D(특이값), V를 리스트로 반환
```

고유값 분해는 정방행렬에만 쓸 수 있지만, SVD는 어떤 크기의 행렬에도 쓸 수 있어서 실제 데이터 분석에서 더 범용적으로 사용된다.

## 6. 고유값 분해와 PCA

### 분해 흐름

```
원래 데이터 축
   ↓
새로운 축으로 회전 (고유벡터)
   ↓
각 축의 중요도 파악 (고유값)
   ↓
중요한 축만 남김
   ↓
차원 축소
```

### PCA (주성분 분석)

PCA는 데이터의 중요한 방향만 남기고 덜 중요한 방향은 줄여서, **차원을 낮추면서도 핵심 정보를 유지**하려는 방법이다.

핵심 흐름은 이렇다.

1. 데이터의 공분산 행렬을 구한다
2. 공분산 행렬을 고유값 분해한다
3. 고유값이 큰 순서대로 고유벡터를 선택한다 (분산이 큰 방향 = 정보가 많은 방향)
4. 선택한 고유벡터들로 데이터를 투영한다

결국은 **복잡한 데이터를 더 단순한 구조로 바꾸는 과정**이다.

```r
prcomp(data, scale. = TRUE)   # PCA 수행
```

## 7. 선형 연립방정식의 활용

행렬은 복잡한 연립방정식을 간단하게 표현하는 데 쓰인다.

$$Ax = b$$

- $A$: 계수 행렬
- $x$: 미지수 벡터 (우리가 구하고 싶은 값)
- $b$: 결과 벡터

역행렬을 구할 수 있다면 다음처럼 $x$를 직접 계산할 수 있다.

$$x = A^{-1}b$$

```r
solve(A, b)   # 연립방정식 풀기
solve(A)      # 역행렬만 구하기
```

### 왜 중요한가

- 머신러닝의 선형회귀 계수를 구하는 과정이 사실 이 연립방정식을 푸는 것이다
- 역행렬이 존재하지 않는 경우(특이행렬)에는 의사역행렬(pseudoinverse)이나 경사하강법을 사용한다

## 8. 데이터 분석에서의 분산 해석

### 분산이 크다

데이터가 넓게 퍼져 있어 수치적으로는 불안정해 보일 수 있다. 하지만 **분산이 크다고 분석 가치가 없다는 뜻은 아니다.**

오히려 그 원인을 밝히고 연구해야 하므로 **분석적 가치가 매우 높다.** 집단 간 차이, 이상치, 패턴 변화, 특이 케이스 등을 찾을 때 분산은 중요한 단서가 된다.

### 분산이 작다

결과가 안정적이고 평균치가 좋지만, 데이터가 이미 밀집되어 있어 **추가로 연구하거나 도출할 새로운 인사이트가 적다.**

### 정리

|상태|의미|분석 관점|
|---|---|---|
|분산이 크다|데이터가 넓게 퍼져 있음|원인 규명이 필요한 고가치 데이터|
|분산이 작다|데이터가 평균 근처에 몰려 있음|안정적이지만 인사이트 도출이 어려움|

즉, **분산이 크면 해석에 더 주의해야 한다**는 의미에 가깝지, 나쁜 데이터라는 뜻이 아니다. PCA에서도 분산이 가장 큰 방향을 첫 번째 주성분으로 삼는다는 점이 이를 잘 보여준다.
