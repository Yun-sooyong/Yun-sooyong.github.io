# 추정과 가설검정: 데이터 기반 의사결정

표본 데이터로 모집단의 진실을 과학적으로 추론하는 과정을 정리한 문서다.  
통계적 추론의 흐름은 다음과 같다.

```
모집단
   ↓ 표본추출 (Sampling)
표본
   ↓ 통계량 계산
통계량
   ↓ 추정 / 가설검정
모수에 대한 결론
```

---

## 1. 왜 통계적 추론이 필요한가

현실에서 모집단 전체를 조사하는 전수조사는 비용과 시간 문제로 대부분 불가능하다.  
그래서 **표본(Sample)** 을 뽑아 전체의 모습을 추론한다. 이 연결 고리가 **추론(Inference)** 이다.

중요한 점은 표본은 확률적으로 추출된 데이터라는 것이다. 같은 모집단에서 표본을 여러 번 뽑으면 매번 결과가 조금씩 달라진다. 통계적 추론은 이 불확실성을 수치로 정량화해서 의사결정에 활용하는 방법이다.

---

## 2. 모수와 통계량

모집단의 특성값을 **모수(Parameter)**, 표본의 특성값을 **통계량(Statistic)** 이라고 한다.  
기호를 구분해서 쓰는 이유는 둘이 다른 대상을 가리키기 때문이다.

|구분|모집단 (Population)|표본 (Sample)|
|---|---|---|
|속성 명칭|모수 (Parameter)|통계량 (Statistic)|
|평균|$\mu$ (뮤)|$\bar{X}$ (엑스 바)|
|분산|$\sigma^2 = \dfrac{\sum(X_i - \mu)^2}{N}$|$S^2 = \dfrac{\sum(X_i - \bar{X})^2}{n-1}$|
|표준편차|$\sigma$ (시그마)|$S$ 또는 `sd`|

### 표본 분산에서 n-1로 나누는 이유

표본 분산의 분모가 $n$이 아닌 $n-1$인 것은 **불편추정량(Unbiased Estimator)** 을 만들기 위해서다.

표본을 뽑으면 표본의 평균($\bar{X}$)은 이미 해당 표본에 맞게 결정된 값이다. 이 $\bar{X}$를 기준으로 편차를 계산하면 모평균 $\mu$ 기준보다 편차가 항상 작거나 같아진다. 그래서 $n$으로 나누면 모분산을 **과소추정**하게 된다.

$n-1$로 나누면 이 과소추정을 보정해서 표본 분산의 기댓값이 모분산과 일치하게 된다.

$$E[S^2] = \sigma^2$$

R에서 `var(x)`, `sd(x)`는 기본적으로 $n-1$ 분모를 사용한다.

## 3. 추정 (Estimation)

### 점 추정 (Point Estimation)

모수를 하나의 값으로 단정하는 방식이다.

- 예: "표본 평균이 87점이므로 모평균은 87점일 것이다"

가장 직관적이지만, 단 하나의 값이라 **얼마나 신뢰할 수 있는지 알 수 없다**는 단점이 있다.

### 구간 추정 (Interval Estimation)

모수가 존재할 범위를 확률과 함께 제시하는 방식이다.

- 예: "모평균은 84~90점 사이에 있을 확률이 95%다"

이 범위를 **신뢰구간(Confidence Interval, CI)** 이라고 한다.

$$\bar{X} \pm 1.96 \times SE$$

여기서 1.96은 정규분포에서 95% 구간에 해당하는 z값이다.

#### 표준오차 (Standard Error, SE)

$$SE = \frac{S}{\sqrt{n}}$$

표준편차가 개별 데이터의 퍼짐을 나타낸다면, 표준오차는 **표본 평균이 얼마나 안정적인지**를 나타낸다.  
표본 크기 $n$이 클수록 SE가 작아지고, 신뢰구간도 좁아진다. 즉, 표본이 많을수록 추정이 더 정확해진다.

|신뢰수준|z값|구간|
|---|---|---|
|90%|1.645|$\bar{X} \pm 1.645 \times SE$|
|95%|1.96|$\bar{X} \pm 1.96 \times SE$|
|99%|2.576|$\bar{X} \pm 2.576 \times SE$|

## 4. 최대우도법 (MLE, Maximum Likelihood Estimation)

관측된 데이터로부터 가장 그럴듯한 모수를 역으로 추적하는 방법이다.

### 직관적 이해

동전을 10번 던져 7번 앞면이 나왔다면, 이 결과가 가장 그럴듯하게 나올 수 있는 앞면 확률 $\theta$는 얼마일까? MLE는 "이 데이터를 만들어낼 확률이 가장 높은 $\theta$"를 찾는 방법이다. 정답은 0.7이다.

### 수식 흐름

**우도 함수 (Likelihood Function)**

$$L(\theta | x) = P(x | \theta)$$

어떤 모수 $\theta$가 주어졌을 때 현재 데이터 $x$가 관측될 확률이다.

**로그 우도 (Log-Likelihood)**

$$\ell(\theta) = \ln L(\theta | x)$$

데이터가 여러 개일 때 우도는 확률의 **곱**이 된다. 곱셈은 계산이 복잡하고 값이 너무 작아지기 때문에 로그를 취해 **덧셈**으로 바꾼다. 로그는 단조증가 함수라 최댓값의 위치가 바뀌지 않는다.

**최적 모수 도출**

로그 우도를 $\theta$에 대해 미분해서 기울기가 0이 되는 지점을 찾는다.

$$\frac{d}{d\theta} \ln L(\theta) = 0$$

이 지점이 우도를 최대로 만드는 최적 모수다.

## 5. 가설검정 (Hypothesis Testing)

### 두 가설의 구분

|가설|내용|비유|
|---|---|---|
|귀무가설 $H_0$|"차이가 없다", "효과가 없다"|법정의 무죄 추정 원칙|
|대립가설 $H_1$|"차이가 있다", "효과가 있다"|연구자가 증명하고 싶은 주장|

가설검정은 귀무가설을 기본값으로 두고, 데이터가 귀무가설을 기각할 만큼 강한 증거인지를 판단하는 과정이다. 유죄를 입증할 증거가 충분해야 무죄 추정을 뒤집는 것처럼, 데이터가 충분히 극단적이어야 귀무가설을 기각한다.

### p-value와 유의수준

**유의수준 ($\alpha$)**: 귀무가설이 맞는데도 실수로 기각할 위험의 한계치. 보통 0.05(5%)로 설정한다.

**p-value**: 귀무가설이 사실일 때, 현재와 같거나 더 극단적인 데이터가 나타날 확률이다.

- $p < 0.05$: "우연히 발생할 확률이 5%보다 낮다" → **귀무가설 기각** (통계적으로 유의함)
- $p \geq 0.05$: "충분히 우연히 일어날 수 있다" → **귀무가설 기각 실패** (유의하지 않음)

주의: "귀무가설 채택"이라는 표현은 엄밀히는 틀렸다. 귀무가설이 옳다고 증명한 것이 아니라, 기각할 증거가 부족하다는 의미다. "기각 실패"라고 표현하는 것이 더 정확하다.

### 가설검정 5단계

```
1단계: 가설 설정
   H0: 모평균 = 85 (차이 없음)
   H1: 모평균 ≠ 85 (차이 있음)
   ↓
2단계: 유의수준 설정
   α = 0.05
   ↓
3단계: 검정통계량 계산
   t = (X̄ - μ) / SE
   ↓
4단계: p-value 계산
   ↓
5단계: 결론 도출
   p < 0.05 → H0 기각
   p ≥ 0.05 → H0 기각 실패
```

### 3-시그마 원칙 (68-95-99.7 법칙)

정규분포에서 평균 기준으로 특정 범위 안에 포함될 확률이다.

|범위|포함 확률|의미|
|---|---|---|
|$\mu \pm 1\sigma$|약 68%|약 1/3은 이 범위 밖|
|$\mu \pm 2\sigma$|약 95%|가설검정 주요 기준선|
|$\mu \pm 3\sigma$|약 99.7%|이 밖이면 사실상 이상치|

95% 신뢰구간에서 1.96을 쓰는 이유가 여기서 나온다. 정규분포에서 $\pm 1.96\sigma$ 안에 정확히 95%의 데이터가 포함된다.

## 6. R 실습

### 기초 통계량 및 신뢰구간 계산

```r
library(tidyverse)

# 데이터 생성
data <- tibble(score = c(85, 90, 78, 92, 88, 84, 95, 80, 89, 91))

# 요약 통계량 + 95% 신뢰구간
stats_summary <- data %>%
  summarise(
    m        = mean(score),
    s        = sd(score),       # n-1 분모 사용
    n        = n(),
    se       = s / sqrt(n),
    lower_95 = m - 1.96 * se,
    upper_95 = m + 1.96 * se
  )

print(stats_summary)
```

### 가설검정 (t-test)

```r
# 단일 집단 t-test: "모평균이 85인가?"
result <- t.test(data$score, mu = 85)
print(result)

# 결과 해석
# p-value < 0.05 → H0 기각: 모평균이 85라고 보기 어렵다
# p-value ≥ 0.05 → H0 기각 실패: 모평균이 85라는 가설을 기각할 근거가 없다
```

t-test를 쓰는 이유: 모표준편차 $\sigma$를 모르는 상황에서 표본 표준편차 $S$를 사용할 때는 정규분포 대신 **t분포**를 사용한다. 표본 크기가 작을수록 t분포의 꼬리가 두꺼워져 더 보수적인 판단을 하게 된다.

### 정규분포 시각화

```r
x <- seq(70, 100, length = 100)
y <- dnorm(x, mean = 85, sd = stats_summary$s)

plot(x, y, type = "l", col = "blue", lwd = 2, main = "가설검정 분포도")
abline(v = 85, col = "red", lty = 2)                  # 귀무가설 평균선
abline(v = result$estimate, col = "darkgreen", lwd = 2) # 관측된 표본 평균
```

## 7. 해석 시 주의할 점

### 평균만 보면 안 된다

표준편차와 신뢰구간(Error Bar)을 항상 함께 확인해야 한다. 평균이 같아도 퍼짐이 다르면 데이터의 성격이 완전히 다를 수 있다.

### p-value의 한계

표본 크기 $n$이 매우 크면 아주 작은 차이도 통계적으로 유의하게($p < 0.05$) 나올 수 있다.  
예를 들어 신약의 혈압 감소 효과가 0.1mmHg밖에 안 되는데 $n$이 100만 명이면 p-value가 0.0001이 나올 수 있다. 하지만 이 차이가 임상적으로 의미 있는 것은 아니다.

그래서 p-value만 보는 것이 아니라 **효과 크기(Effect Size)** 를 함께 봐야 한다.

|지표|의미|한계|
|---|---|---|
|p-value|우연히 일어날 확률|n이 크면 사소한 차이도 유의하게 나옴|
|효과 크기 (Cohen's d 등)|실질적인 차이의 크기|p-value와 함께 봐야 완전한 해석 가능|

### 전체 흐름 정리

```
모집단
   ↓ 표본추출
표본
   ↓ 통계량 계산 (X̄, S)
통계량
   ↓ MLE / 신뢰구간 추정
모수 추정
   ↓ 가설검정 (p-value)
의사결정
```
