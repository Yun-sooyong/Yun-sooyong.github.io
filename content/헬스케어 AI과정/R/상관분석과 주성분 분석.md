# 상관분석과 주성분 분석 (PCA)

두 변수 사이의 선형적 관계를 파악하는 **상관분석**과, 이를 확장해 데이터의 구조를 파악하고 차원을 축소하는 **PCA**의 핵심 내용을 정리

---

## 1. 공분산 (Covariance)

두 변수가 **같은 방향으로 함께 움직이는지**를 나타내는 척도다.

$$s_{xy} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{n-1}$$

### 계산 원리

편차의 곱을 사용하는 이유가 직관적이다.

- $x$가 평균보다 크고 $y$도 평균보다 크면 → 곱이 양수
- $x$가 평균보다 크고 $y$는 평균보다 작으면 → 곱이 음수
- 이 부호들의 합이 양수면 같은 방향, 음수면 반대 방향

### 한계

공분산은 부호로 방향은 알 수 있지만, **크기가 단위에 따라 달라진다.**  
키(cm)와 몸무게(kg)의 공분산과, 키(m)와 몸무게(kg)의 공분산은 값이 다르다. 그래서 두 집단의 관계 강도를 공분산만으로 비교하기는 어렵다.

---

## 2. 상관계수 (Correlation Coefficient)

공분산을 각 변수의 표준편차의 곱으로 나눠 **표준화**한 값이다.

$$r = \frac{s_{xy}}{\sigma_X \cdot \sigma_Y} = \frac{cov(X, Y)}{\sigma_X \sigma_Y}$$

단위를 제거했기 때문에 항상 $-1 \leq r \leq 1$ 범위에 들어온다.

### 해석

|$r$ 범위|의미|
|---|---|
|$r = 1$|완전한 양의 선형 관계|
|$0.7 \leq r < 1$|강한 양의 관계|
|$0.3 \leq r < 0.7$|중간 정도의 양의 관계|
|$-0.3 < r < 0.3$|관계가 거의 없음|
|$-0.7 < r \leq -0.3$|중간 정도의 음의 관계|
|$r = -1$|완전한 음의 선형 관계|

### 기하학적 의미

상관계수는 두 변수(열 벡터) 사이의 **코사인 유사도**와 같은 의미를 가진다. 두 벡터가 이루는 각도가 작을수록(같은 방향) $r$이 1에 가까워지고, 직각이면 0, 반대 방향이면 -1이 된다.

---

## 3. 상관계수의 종류

데이터 특성에 따라 적합한 상관계수를 선택해야 한다.

|구분|Pearson|Spearman|Kendall|
|---|---|---|---|
|분석 대상|연속형 (등간/비율)|순위형 (서열/이산)|순위형 (서열/이산)|
|방법론|모수적 (정규분포 가정)|비모수적|비모수적|
|측정 핵심|선형 관계의 강도|단조적 관계(순위)의 일치|일치/불일치 쌍의 비율|
|이상치 영향|민감함|덜 민감함|덜 민감함|
|특이사항|가장 많이 사용|비선형 관계 포착 가능|소표본에서 더 신뢰적|

```r
cor(x, y, method = "pearson")   # 기본값
cor(x, y, method = "spearman")
cor(x, y, method = "kendall")
```

### 언제 뭘 쓸까

- 데이터가 연속형이고 정규분포를 따르면 → **Pearson**
- 순위 데이터이거나 분포를 모르거나 이상치가 많으면 → **Spearman**
- 표본이 작고 정확한 순위 관계가 필요하면 → **Kendall**

---

## 4. 상관 행렬 (Correlation Matrix)

$n$개의 변수가 있을 때 모든 변수 쌍 간의 상관계수를 담은 $n \times n$ 행렬이다.

### 주요 성질

- **정방 대칭 행렬**: $r_{xy} = r_{yx}$이므로 대각선 기준으로 대칭
- **대각 성분은 항상 1**: 자기 자신과의 상관관계

```
     X1    X2    X3
X1 [ 1.00  0.85  0.32 ]
X2 [ 0.85  1.00  0.41 ]
X3 [ 0.32  0.41  1.00 ]
```

```r
cor(df)                        # 상관 행렬 계산
corrplot::corrplot(cor(df))    # 히트맵 시각화
```

### 수리적 생성 흐름

$$R = \frac{1}{n-1} Z^T Z$$

1. **표준화**: 각 변수를 Z-score로 변환해 단위를 제거한 표준화 행렬 $Z$ 생성
2. **행렬 곱**: $Z^T \times Z$ 로 변수 간 내적 계산
3. **평균화**: 자유도 $(n-1)$로 나눔

Z-score 표준화로 단위를 제거했기 때문에 공분산 행렬이 아닌 상관 행렬이 나온다.

---

## 5. 다중공선성 (Multicollinearity)

상관 행렬은 PCA나 회귀분석 전에 **다중공선성 확인**에 필수적이다.

다중공선성은 독립 변수들 사이의 상관관계가 너무 강할 때 발생한다.  
예를 들어 키와 체중이 둘 다 독립 변수인 회귀 모델에서, 둘의 상관이 0.95라면 사실상 같은 정보를 두 번 쓰는 것이다.

이 경우 회귀계수가 불안정해지고 해석이 어려워진다. PCA는 이 문제를 해결하는 데 활용된다.

```r
# 분산팽창계수(VIF)로 다중공선성 확인
car::vif(lm(y ~ x1 + x2 + x3, data = df))
# VIF > 10이면 다중공선성 문제 가능성
```

## 6. 주성분 분석 (PCA)

### 목적

여러 변수를 서로 독립적인 새로운 축(주성분)으로 변환해 **차원을 줄이면서 핵심 정보는 유지**하는 방법이다.

### 핵심 아이디어

데이터가 가장 많이 퍼져 있는 방향(분산이 가장 큰 방향)을 첫 번째 주성분으로 삼는다.  
그 다음으로 분산이 큰 방향이면서 첫 번째 주성분과 **직교**하는 방향을 두 번째 주성분으로 삼는다.  
이 과정을 반복한다.

```
원래 데이터 (p개 변수)
   ↓ 공분산/상관 행렬 계산
   ↓ 고유값 분해
고유벡터 (새로운 축의 방향)
고유값 (각 축이 설명하는 분산의 크기)
   ↓ 고유값 큰 순서로 주성분 선택
   ↓ 데이터 투영
축소된 표현 (k개 주성분)
```

---

## 7. 고유값 분해 (Eigenvalue Decomposition)

상관 행렬 또는 공분산 행렬을 분해해서 **고유값**과 **고유벡터**를 얻는다.

$$R \cdot v = \lambda \cdot v$$

- $v$: 고유벡터 — 새로운 축의 **방향**
- $\lambda$: 고유값 — 해당 축이 설명하는 **분산의 크기**

각 고유벡터는 서로 **직교(Orthogonal)** 한다. 즉, 주성분들은 서로 완전히 독립이다.

```r
# 고유값 분해
eigen(cor(df))

# PCA 수행 (권장)
pca <- prcomp(df, scale. = TRUE)
summary(pca)       # 각 주성분이 설명하는 분산 비율
pca$rotation       # 로딩 행렬 (고유벡터)
pca$x              # 스코어 행렬
```

## 8. 로딩과 스코어

### 로딩 (Loading)

각 원본 변수와 주성분 축 사이의 **상관관계(가중치)** 다.  
로딩을 보면 각 주성분이 어떤 변수들의 조합인지 해석할 수 있다.

예를 들어 1번 주성분의 로딩이 `키: 0.8, 몸무게: 0.75, 나이: 0.1`이라면, 이 주성분은 **신체 크기** 관련 요인이라고 명명할 수 있다.

### 스코어 (Score)

기존 관측치를 새로운 주성분 축 위에 투영한 **좌표값**이다.

$$X \times V = Z$$

- $X$: 원본 데이터 행렬
- $V$: 고유벡터 행렬 (로딩)
- $Z$: 스코어 행렬

스코어 행렬의 열들은 서로 **상관계수가 0**이다. 다중공선성이 완벽히 제거된 상태가 된다.

---

## 9. 주성분 수 결정

몇 개의 주성분을 선택할지 결정하는 방법들이다.

### 누적 분산 설명 비율

전체 분산의 일정 비율(보통 70~80% 이상)을 설명하는 주성분 수까지 선택한다.

```r
summary(pca)
# Cumulative Proportion 행에서 0.8 이상이 되는 지점 확인
```

### 스크리 플롯 (Scree Plot)

고유값을 내림차순으로 그렸을 때 **기울기가 급격히 완만해지는 지점(Elbow)** 에서 자른다.

```r
screeplot(pca, type = "lines")
```

### Kaiser 기준

고유값이 1 이상인 주성분만 선택한다. 고유값 1은 원래 변수 하나가 설명하는 분산의 양이므로, 그보다 적게 설명하는 주성분은 의미가 없다는 논리다.

---

## 10. 전체 흐름 정리

```
원본 데이터
   ↓
표준화 (scale)
   ↓
상관 행렬 계산 (cor)
   ↓
다중공선성 확인
   ↓
고유값 분해 (eigen / prcomp)
   ↓
주성분 수 결정 (스크리 플롯, 누적 분산)
   ↓
스코어 행렬 생성 (X × V)
   ↓
회귀분석 / 머신러닝 입력으로 활용
```

상관분석은 단순한 수치 비교를 넘어, 데이터의 구조를 파악하고 차원을 줄이기 위한 첫 단추다.  
PCA로 얻은 스코어 값들은 서로 독립적이므로, 이후 분석 모델의 노이즈 없는 입력 변수로 활용할 수 있다.
