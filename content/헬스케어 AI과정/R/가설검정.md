# 가설검정: 분포의 이해와 의사결정

데이터 분석의 핵심은 우리가 발견한 차이가 **진짜**인지 아니면 단순히 **우연**인지 판단하는 것이다.  
이 문서는 가설검정의 오류 개념부터 주요 분포(카이제곱, t, F)와 각 분석 절차를 정리한다.

---

## 1. 가설검정의 두 가지 오류

통계적 결정에는 항상 틀릴 가능성이 존재한다. 이 리스크를 확률로 정량화해서 관리해야 한다.

|결정 \ 실제|$H_0$ 참|$H_1$ 참|
|---|---|---|
|**$H_0$ 기각 실패**|옳은 결정|**제2종 오류 ($\beta$)** — 차이가 있는데 놓침|
|**$H_0$ 기각**|**제1종 오류 ($\alpha$)** — 차이 없는데 있다고 함|**검정력 ($1-\beta$)** — 실제 차이를 찾아낼 확률|

### 제1종 오류 ($\alpha$)

귀무가설이 참인데 잘못 기각하는 오류다. "없는 효과를 있다고 결론 내리는" 경우다.  
유의수준 $\alpha$는 연구자가 허용하는 제1종 오류의 최대 한계치다. 보통 0.05나 0.01로 설정한다.

### 제2종 오류 ($\beta$)

귀무가설이 거짓인데 기각하지 못하는 오류다. "있는 효과를 놓치는" 경우다.

### 검정력 ($1-\beta$)

실제로 차이가 있을 때 그것을 올바르게 탐지할 확률이다.  
검정력은 표본 크기가 클수록, 효과 크기가 클수록 높아진다.

### 두 오류의 관계

제1종 오류와 제2종 오류는 **트레이드오프** 관계다.  
$\alpha$를 낮추면(엄격하게 기각) 제1종 오류는 줄지만 제2종 오류($\beta$)는 늘어난다.  
그래서 연구 목적에 따라 어느 쪽 오류를 더 통제할지 결정해야 한다.

---

## 2. 유의수준과 p-value

### 유의수준 ($\alpha$)

연구자가 사전에 설정하는 기준값이다. "이 확률보다 낮게 나오면 우연이 아니라고 보겠다"는 기준이다.

### p-value (유의확률)

귀무가설이 참일 때, 현재 데이터 이상으로 극단적인 결과가 나타날 확률이다.

- $p < \alpha$: 우연히 일어날 확률이 기준보다 낮다 → **귀무가설 기각**
- $p \geq \alpha$: 충분히 우연히 일어날 수 있다 → **귀무가설 기각 실패**

p-value는 "귀무가설이 맞을 확률"이 아니다. "귀무가설이 맞다고 가정했을 때 이런 데이터가 나올 확률"이다. 이 차이가 중요하다.

---

## 3. 분포와 자유도

분포는 우리가 계산한 통계량이 얼마나 극단적인 위치에 있는지 알려주는 기준표다.  
**자유도(Degree of Freedom, $df$)** 는 이 기준표의 모양을 결정하며, 데이터가 많아질수록 분포는 더 좁고 정밀해진다.

자유도는 쉽게 말해 **데이터에서 자유롭게 변할 수 있는 값의 수**다.  
예를 들어 평균이 고정된 상태에서 $n$개의 값이 있으면, 마지막 하나는 나머지가 결정되면 자동으로 정해진다. 그래서 자유도는 $n-1$이 된다.

|분포|자유도|정규분포로의 수렴|
|---|---|---|
|카이제곱 ($\chi^2$)|$df = k-1$|$df$가 커질수록 대칭형에 가까워짐|
|t-분포|$df = n-1$|$df$가 커질수록 표준정규분포($Z$)로 수렴|
|F-분포|$df_1, df_2$ 두 개|두 자유도에 의해 모양이 결정됨|

## 4. 카이제곱 분석 ($\chi^2$ Analysis)

**범주형 변수** 사이의 관계를 검정한다.  
"기대 빈도($E$)와 실제 빈도($O$)가 얼마나 다른가"를 수치화하는 것이 핵심이다.

### 검정 통계량

$$\chi^2 = \sum \frac{(O - E)^2}{E}$$

- $O$: 실제 관측 빈도
- $E$: 귀무가설(독립)을 가정했을 때의 기대 빈도

편차를 제곱하는 이유는 방향(양수/음수)에 관계없이 크기만 보기 위해서다.  
$E$로 나누는 이유는 기대 빈도가 클 때와 작을 때의 차이를 동일한 기준으로 비교하기 위해서다.

### 기대 빈도 계산

$$E_{ij} = \frac{(\text{행 합계}) \times (\text{열 합계})}{\text{전체 합계}}$$

### 분석 흐름

```
1. 가설 설정
   H0: 두 변수는 독립이다 (관계 없음)
   H1: 두 변수는 독립이 아니다 (관계 있음)
   ↓
2. 기대 빈도 계산 및 χ² 통계량 산출
   ↓
3. 자유도 계산: df = (행 수 - 1) × (열 수 - 1)
   ↓
4. p-value와 α 비교 → 결론 도출
```

```r
# R에서 카이제곱 검정
chisq.test(table(df$변수1, df$변수2))
```

### 주의사항

기대 빈도가 5 미만인 셀이 전체의 20% 이상이면 카이제곱 검정의 신뢰성이 떨어진다.  
이 경우 피셔의 정확 검정(Fisher's Exact Test)을 사용한다.

```r
fisher.test(table(df$변수1, df$변수2))
```

## 5. t-분포 분석 (t-test)

**연속형 변수의 평균**을 비교할 때 사용한다.  
모표준편차 $\sigma$를 모르는 상황에서 표본 표준편차 $S$를 쓰기 때문에 정규분포 대신 t-분포를 사용한다.  
표본이 작을수록 t-분포의 꼬리가 두꺼워져 더 보수적인 판단을 하게 된다.

### t값 계산

$$t = \frac{\bar{X} - \mu}{SE} = \frac{\bar{X} - \mu}{S / \sqrt{n}}$$

### t-test의 종류

|유형|상황|R 코드|
|---|---|---|
|단일 표본 t-test|표본 평균이 특정 값과 같은지|`t.test(x, mu = 값)`|
|독립 표본 t-test|두 독립 집단의 평균 비교|`t.test(x, y)`|
|대응 표본 t-test|동일 집단의 전후 비교|`t.test(x, y, paired = TRUE)`|

### 분석 흐름

```
1. 유형 선택
   독립표본 / 대응표본 / 단일표본
   ↓
2. 정규성 검토
   shapiro.test(x)  →  p > 0.05이면 정규성 만족
   ↓
3. (독립표본의 경우) 등분산 검토
   var.test(x, y)  →  p > 0.05이면 등분산
   ↓
4. t값 및 p-value 계산
   ↓
5. p < α 이면 "두 집단 평균은 다르다"
```

```r
# 독립 표본 t-test
t.test(score ~ group, data = df)

# 등분산 가정 여부에 따라 var.equal 옵션 조정
t.test(score ~ group, data = df, var.equal = TRUE)
```

## 6. F-분포 분석 (ANOVA)

**세 집단 이상의 평균 차이**를 한 번에 검정할 때 사용한다.  
세 집단을 t-test로 둘씩 비교하면 비교 횟수만큼 제1종 오류가 누적되어 신뢰성이 떨어진다. ANOVA는 이를 한 번의 검정으로 해결한다.

### F값의 의미

$$F = \frac{\text{집단 간 분산 (Between-group variance)}}{\text{집단 내 분산 (Within-group variance)}}$$

- **집단 간 분산**: 각 집단의 평균이 전체 평균으로부터 얼마나 멀리 떨어져 있는가
- **집단 내 분산**: 같은 집단 안에서 개별 데이터가 얼마나 퍼져 있는가

F값이 크다는 것은 집단 간 차이가 집단 내 변동보다 크다는 뜻이다. 즉, 집단 간 차이가 우연이라고 보기 어렵다는 의미다.

### 분석 흐름

```
1. 가설 설정
   H0: 모든 집단의 평균이 같다
   H1: 적어도 하나의 집단 평균이 다르다
   ↓
2. F값 계산 (집단 간 분산 / 집단 내 분산)
   ↓
3. p-value 확인 → 하나라도 다른지 판단
   ↓
4. p < α 이면 → 사후 검정(Post-hoc)으로 어떤 집단이 다른지 파악
```

```r
# 일원배치 ANOVA
result <- aov(score ~ group, data = df)
summary(result)

# 사후 검정 (Tukey HSD)
TukeyHSD(result)
```

### 사후 검정 (Post-hoc Test)

ANOVA는 "적어도 하나가 다르다"는 것만 알려준다. **어떤 집단끼리 다른지**는 사후 검정으로 추가 분석해야 한다.

|방법|특징|
|---|---|
|Tukey HSD|모든 집단 쌍을 비교. 가장 많이 사용|
|Bonferroni|유의수준을 비교 횟수로 나눠 엄격하게 보정|
|Scheffe|가장 보수적. 복잡한 비교에 적합|

## 7. 분석 방법 선택 가이드

|구분|카이제곱 ($\chi^2$)|t-분포|F-분포 (ANOVA)|
|---|---|---|---|
|데이터 유형|범주형|연속형|연속형|
|집단 수|-|2집단 이하|3집단 이상|
|주요 질문|두 변수가 관련 있는가|두 평균이 다른가|여러 평균 중 다른 게 있는가|
|판정 기준|$p < \alpha$|$p < \alpha$|$p < \alpha$|
|R 함수|`chisq.test()`|`t.test()`|`aov()`|

### 선택 흐름

```
데이터가 범주형인가?
   ├─ YES → 카이제곱 검정
   └─ NO (연속형)
         ↓
      비교할 집단이 몇 개인가?
         ├─ 1개 (기준값과 비교) → 단일 표본 t-test
         ├─ 2개 → 독립/대응 표본 t-test
         └─ 3개 이상 → ANOVA → (유의하면) 사후 검정
```
